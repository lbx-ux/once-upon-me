# 故事只有一种结构：一棵树。独读版是它没有分支的退化情形

产品定义里有两种形态（睡前线性 / 白天分支），工程上最自然的写法是两套结构、
两条流水线、两个阅读器。本项目**不这么写**：
`engine/tree.ts` 只有一种 `StoryTree`，`form: 'solo' | 'shared'` 只影响两件事——
提示词里那一段形态规则，和校验时"独读版不许有选择点 / 共读版必须有选择点"这一条。

这不是"顺手复用"，是让那句判据在代码里成立：
**去掉互动，绘本仍成立；去掉绘本，互动不成立**——所以它们是同一个东西的两种形态，
不是两个产品。如果两种形态各写一套，"平台而非聚合"就只剩一句口号，
而评委要看的恰恰是这个区别（技术方案创新 8 分）。

判据反过来也管住了实现：`buildTree('solo', …)` 会**拒绝**带 choice 的表，
`buildTree('shared', …)` 会拒绝一棵没有分支的树。
也就是说"我们其实做了两个产品"这件事，在类型与校验层就发生不了。

代价说清：独读版也要走一遍树的校验与路径计算，多几毫秒 CPU 和一层
`linearOrder()` 的抽象；共读版的 bug 有可能传染给独读版。
这两条我们主动付——因为不这么写，就得在答辩时承认"这是两个功能"。

- Status: accepted
- Considered Options: 两套结构各写一条流水线（起步快，但把产品切成两个功能，
  且 20 页正文要在两处各写一遍校验）；用嵌套 JSON 树表达分支（模型写嵌套结构的
  失败率明显高于扁平表 + `from` 引用，少一个闭合括号整本作废，
  而 §9.2 判据 1 测的恰恰是结构正确率）
- Consequences: ① 引擎与 UI 的 seam 落在**事件协议**上（`engine/events.ts`）：
  过程要能被界面、MCP、日志三个消费者读，一次性返回结果就没有这个载体；
  ② `BookRequest.form` 是入参不是两个入口函数，UI 那边不许出现
  `runSoloBook()` / `runSharedBook()` 这种分裂；
  ③ 分支的**合并**（两条分支走回同一页）当前不支持，W3 若要合并需扩展
  `from` 的语义——那时这份 ADR 要重新读一遍

## Comments

**2026-10-18（W3 落地）：上面 ③ 那句"若要合并"有了结论——不扩。** 这份 ADR 的
决定本身一个字没改（一棵树、形态是入参、`buildTree` 双向拒），改的是那条"待办"的身份：
它从"以后可能扩"变成"**结构上无法表达，所以不扩**"。三条理由：

1. **不是难，是无法表达。** `engine/tree.ts` 的三条规则——每节点最多一个父、
   选择点恰好两子、非选择点不得有第二个孩子——合起来意味着"某个节点由两条支共同
   接上"没有合法写法：汇合节点要么需要两个父（撞第一条），要么得挂回选择点
   （撞第二条）。要接纳它就得同时改 `from` 的语义与"一条路 = 一串 nodeId"
   （`pathFromRoot` 一族）这个不变式，那是**另一份 ADR**，不是顺手一改。
2. **推论是钱。** 既然一条支必须自带到结尾的全部页，**每加一层分支就多付一整条尾巴**：
   路长 8 页时 1 层 ≈11 张图、2 层 ≈14（那个孩子永远读不到 43% 的书）、3 层 ≈22（64%）。
   汇合本来能省下的正是"结尾那几页"，但它换来的是"两条支必须讲回同一条线"——
   而共读版要的恰恰相反：两支各自收出一个结尾，只在**同一个落点与同一种情绪**上呼应
   （那是提示词的活，`prompts/story-plan.ts` 的 `FORM_RULES.shared`；结构管不了它）。
3. **选择的上界不是页数给的，是年龄给的。** `domain.ts` 里 `StoryChoice` 那条注释写着
   「两个选项（孩子不识字，两个已经够）」。多做几层不等于多做几次选择，
   等于把同一个选择摊到更多页上去付费。

所以落地口径收窄成：**恰好一个选择点，两支各自收尾**
（README §一、GLOSSARY 的「共读版」与「分支」、docs/known-tradeoffs.md 那笔账）。
判据在 `buildTree` 里是**会红的那种**（多于一个选择点、两支深度差 > 1、
选择点在最后一页——三条反例都会拒绝并让重试提示点名）。

★ 顺带记一处**这份 ADR 曾经说错过**的地方：旧版 `FORM_RULES.shared` 里那句
"两条分支都要能走回同一个结尾附近"读起来像结构约束，而结构上做不到（见第 1 条）。
现在它是一句**叙事上的近似**，`tree.ts` 文件头那条 ★★ 就是防下一个人把它读成承诺。
