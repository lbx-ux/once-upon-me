# 生产链路允许依赖海外模型，因为「演示能用」由预生成资产保证、不由供应商 SLA 保证

在线演示是官方规则 11.4 的可选加分项，但它有一条硬要求：**公网可访问、评审期间保持可用**。
评审期在 2026 年 12 月到 2027 年 1 月，跨年，且评委在哪儿、网络什么状况都不知道。

所以本项目不把「演示当天模型能不能调通」当作可用性的前提：
**一本已经生成好的书是资产，不是一次调用**。演示路径里评委看到的每一页插画、
每一段朗读、整段生成过程回放，都来自落盘的成品与事件流日志；
只有评委**自己现场发起的一次创作**才真的打供应商接口，而那一次允许慢、允许排队、
失败也有降级文案（这是「AI 交互体验 3 分」里错误边界那条的正经用法）。

**推论：海外模型可以进候选集**（现有出图链路已经是海外模型，见
[tech-selection.md §7](../tech-selection.md)）。这条决定换来的是选型自由度，
代价是要多做一件平时可以偷懒的事——**每个演示场景都必须有一条不依赖网络的成功路径**，
并且现场要有一本预生成的成品书兜底。如果哪天有人提议"演示就直接现场生成吧"，
请把这一条读一遍。

- Status: accepted
- Considered Options: 全链路只用国内可达模型（牺牲一致性最强的候选，且现有 26 张成图要全部重出）；海外模型 + 自建中转（多一台境外服务器要维护，收益只是"现场也能实时生成"，而现场实时生成本来就不是演示的必要条件）
- Consequences: 预生成资产要有**版本与失效管理**——模型换代后旧资产仍然是合法交付物，
  但必须能说清每一张图是用哪一版模型、哪一条提示词生成的（现成的先例：
  `docs/cover-art-prompts.md` 与 `demo-book-art-prompts.md` 已逐张记录提示词与验收判据）
