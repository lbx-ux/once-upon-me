# 模型与密钥由**站长**分配：用户不再自带 key

2026-10-16 用户定的口径：**把前端用户自己输入 api-key 的模块取消了**——
密钥由站长（部署者）分配，按能力授权给每个账号。

这份 ADR **推翻 [ADR-0008](0008-model-and-key-provided-by-user.md)**，所以先说清楚
推翻的是什么、以及**什么没有被推翻**。

## 之前是怎么定的，为什么改了

ADR-0008 的口径是"用户自己填模型 + 自己提供 API key"，落在界面上就是那个设置抽屉：
四组输入框（LLM / IMAGE / VISION / TTS 各一套 key + baseUrl + model）。

那条决定的理由当时是成立的，而且与项目立场一致（平台而非聚合、模型零硬编码）。
问题出在它**假设了用户是自己那张账单的主人**——而这个产品的实际形态不是那样：
绘本是一整条流水线，一本 20 页的书要打几十次付费接口（实测出图 ≈154 s/页、
0.2 元/张）；让一个家长为了给孩子做一本书去注册一家模型供应商、充值、填三个 key，
那道门槛与"做一本绘本"这件事本身没关系。

所以改成：**站长配一次密钥，按账号发能力**。四个开关（文字 / 图像 / 视觉 / 语音）
由管理页勾，用户那侧只需要"申请一次"（见下面的代价）。

> ★ 2026-10-18：**"按账号发能力"这一半被推翻了**——权限收成一位「有没有创作权」，
> 注册即给上，不再有申请。密钥由站长配这一半（下面「改了什么」的前两条）一字未动。
> 见 [ADR-0010](0010-permission-is-one-bit.md)。

## 改了什么

- **密钥只有服务端一个来源**：`src/lib/settings/server-env.ts` 的 `serverEnv()`。
  它按请求现读，**没有模块级缓存**——这一条是"管理页改完立刻生效、不用重启"的前提。
- **两个落点，一条纪律**：`.env.local`（开发）或 `models.runtime.json`
  （管理页写出来的）。两个都在 `.gitignore` 里。生产建议
  `MODEL_CONFIG_FILE=/etc/xiaozhujue/models.json` 把它挪出仓库目录。
- **"用户自带 key"那条路整条删掉**，不是留着不用：请求体里的 `env` 字段退场，
  设置抽屉那半格拆掉，`SettingsProvider` 只剩音色那一半（改名 `VoiceProvider`）。
  留着一条没人用的入口，下一个人会以为它还在生效。
- **权限每次都问后端**（`GET /api/auth/me`），不从票里读：站长勾掉一个开关之后，
  那个人**下一次点「开始创作」**就该看见变化，而不是等 7 天票过期。

## 代价与遗留（都写在这里，因为它们是真的）

- **ADR-0008 那三条纪律一条都没丢**：不落盘、不进日志、不进录制。
  ★ 换的只是"**谁持有**密钥"，不是"密钥怎么对待"。管理页写出来的那份
  `models.runtime.json` 确实落盘了——落的是**站长自己**的密钥，
  而那一份本来就以 `.env.local` 的形式躺在他自己的机器上。
- **多了一个单点**：站长不配，全站都不能生成。所以"没权限 / 站里没配"这两件事
  在界面上必须**分开说**（`lib/voices/state.ts` 的 `narrationBlockOf` 是同一个形状：
  `no-permission` 找站长、`server-not-configured` 等站里配好），
  合成一句"暂时用不了"就把"该做什么"丢了。
- **配额是手工的**：目前只有"四个开关"这一档粗粒度授权，没有按次/按量的限额。
  站长的账单风险靠"只给信得过的人开"来管。要做限额，那是下一轮的表与计数。
  ★ 2026-10-18：这一档**更粗了**——只剩"开 / 关"一位，而且是注册即开
  （[ADR-0010](0010-permission-is-one-bit.md) 把这条记作它的代价之一）。
- **管理员能换模型意味着它能换掉所有人正在用的那个**：语音克隆出来的音色绑死在
  创建它时的模型上（实测跨模型 400 `[411]`），所以管理页换语音模型会让用户手里
  那些克隆音色**当场失效**。这一条在管理页那一栏上有警告，
  见 `lib/settings/model-config.ts` 里 `speech` 那一项的 `warn`。

## 没有变的

- 音色仍然由用户自己选（含自己录的那一条）——变的是它**存在哪**：
  2026-10-17（工单 16）从浏览器 localStorage 搬到了账号上（`voices` 表）。
- 引擎仍然不认任何供应商的名字：模型名、key、baseUrl 依然全部从调用方注入
  （`registry.ts` 的 `Env` 是参数），只是那个调用方从"用户填的表单"变成了
  "站长的服务端环境"。
