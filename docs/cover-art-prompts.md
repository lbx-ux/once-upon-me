# 首屏轨道 12 张绘本封面 —— 出图提示词

> 用途：`src/components/hero/HeroOrbit.tsx` 环上那 12 张卡片所用的封面插画。
> 产物：`public/art/{key}.webp`（1280×720）。JPG 源图 → WebP 的转换脚本见 [`scripts/make-webp.py`](../scripts/make-webp.py)。
> 选用的风格库模板：**`illustration-art-style`（插画与艺术风格）**，场景标签 `story` + `creative`。
> 关联模板：书面名排版参考 `poster-layout-system`，但本版**不在图里放字**（理由见文末「为什么画面里不放书名」）。

---

## 一、这批图要同时满足的三个约束

下面每一条都来自已经定稿的技术实现，不是审美偏好：

| 约束                                                           | 来源                                  | 对提示词的要求                                                             |
| -------------------------------------------------------------- | ------------------------------------- | -------------------------------------------------------------------------- |
| **卡片只有 224–318px 宽，后排还要糊 5.2px、压到 28% 不透明度** | `hero-orbit.css` 的卡片宽度与景深模糊 | 一张卡**只能有一个视觉焦点**，主体轮廓要清楚；不能靠小字和细密纹理传达信息 |
| **12 张卡在同一个圆环上长期并排出现**                          | 首屏轨道本身                          | 必须有"系列感"：同一画风、同一地平线高度、同一光源方向、同一背景复杂度     |
| **首屏底色是 `#f7f7f8` 极简浅色 + 点阵网格**                   | 首屏视觉语言（浅底 + 点阵网格）       | 整组用**高明度、低饱和**的浅色调；深色卡片最多留一张做节奏                 |

再加一条题材要求：**这 12 张是"孩子喜欢什么"，不是"故事讲什么道理"**。所以每张画的是孩子的爱好现场，不是"勇气""分享"这类抽象概念的图解——价值导向要落在**画面正在发生的事**里，不是贴在标题上。

## 三、12 张卡的内容

每条的三个字段分别替换骨架里的 `【主体与场景】`，并补一句色彩重音。

### 1. 🦕 恐龙 → `dino.webp`｜「发现」

**主体与场景**：清晨的蕨类丛林里，一个扎双马尾的小女孩蹲在地上，和一只温柔的长颈龙一起低头看一朵从蕨叶间冒出来的小白花；长颈龙把脖颈弯下来，眼神温和；远处有薄雾和几道光柱。恐龙不是追人的猛兽，是"一起发现一件小事"的同伴。
**色彩重音**：蕨绿与晨雾白打底，女孩的橙色外套作重音。
**落点**：好奇，与比自己大得多的生命温柔共处。

### 2. 🎨 画画 → `paint.webp`｜「我画的」

**主体与场景**：木质地板上的低位平角，一个短发小男孩趴着，专心给画纸涂色；纸上是一个歪歪扭扭的太阳、一栋房子和三个手拉手的火柴人（代表一家人）；身边散着蜡笔和一个旧铁皮饼干盒；窗外斜进午后的光。
**色彩重音**：木色与奶油白打底，蜡笔的彩色作重音。
**落点**：创造的快乐，画里画的就是家人。

### 3. 🚀 火箭 → `rocket.webp`｜「出发」

**主体与场景**：客厅地毯上，一个女孩戴着自己用纸箱做的头盔、坐在纸箱火箭里，双手举高做升空姿势；地毯花纹在她眼里变成了环形山的星空；一只猫在旁边好奇地看；背景是家里的书架和盆栽。
**色彩重音**：纸箱牛皮色与浅蓝"星空"打底，暖黄灯光作重音。
**落点**：想象力与勇气。用纸箱而不是真火箭——安全、可模仿、是家里能发生的事。

### 4. 🐣 小鸟 → `bird.webp`｜「轻轻的」

**主体与场景**：春日午后的大树下，一个孩子盘腿坐在草地上，摊开手掌一动不动，一只雏鸟停在他手心里低头啄食；旁边低枝上鸟妈妈安静地看着；孩子屏住呼吸，嘴角带着笑。
**色彩重音**：新绿与米白打底，阳光斑驳处作暖色重音。
**落点**：爱护小动物、耐心与温柔。不掏鸟窝、不抓鸟、不握紧。

### 5. ⭐ 星星 → `star.webp`｜「一起看」

**主体与场景**：黄昏的院子里，一位父亲和一个孩子裹在同一条格子毯里坐在躺椅上，抬头看天边第一批亮起来的星星；孩子伸手指向天空；旁边小桌上有两杯热饮；远处是居民楼的安静剪影和暖黄的窗。
**色彩重音**：橘粉暮色与浅紫打底，毯子的格纹红作重音。
**落点**：亲情与陪伴。**做成黄昏而不是深夜**——保持整组的浅色调，深夜版对首屏太沉。

### 6. 🌙 月亮 → `moon.webp`｜「睡前」

**主体与场景**：夜晚的儿童卧室，孩子已经钻进被窝，只露出脑袋和一双还没闭上的眼睛；妈妈坐在床边小凳上，翻开一本绘本读着；床头小夜灯在墙上投出一块月亮形状的光斑；一只旧玩偶熊被搂在怀里。
**色彩重音**：月白与浅蓝打底，小夜灯的暖橘作重音。
**落点**：亲子共读的安全感——这张画的就是产品本身。这是全组唯一一张夜景。

### 7. 🐋 鲸鱼 → `whale.webp`｜「你好，大家伙」

**主体与场景**：晴朗平静的海面上，一个孩子坐在白色小木船里（**穿着橙色的儿童救生衣**），一只巨大的鲸鱼从船边温和地浮出水面，喷出的水雾里挂着一道小彩虹；远处几只海鸟；孩子一手扶着船舷，张着嘴笑。
**色彩重音**：海蓝与白打底，救生衣橙和彩虹作重音。
**落点**：对自然的敬畏与善意。救生衣是刻意加的——画面里要有安全示范。

### 8. 🏰 城堡 → `castle.webp`｜「我们一起」

**主体与场景**：黄昏的海滩上，两个孩子蹲在一起堆沙堡，沙堡有塔楼和一面用手帕做的小旗；旁边放着水桶、小铲子和一双拖鞋；海浪在远处轻轻推上来；两人正一起把最后一块沙放上塔尖。
**色彩重音**：沙金与海蓝打底，晚霞粉橙作重音。
**落点**：合作与分享。城堡只是孩子的沙堡，不带王权或征服的意味。

### 9. ☁️ 云 → `cloud.webp`｜「像什么？」

**主体与场景**：正午的草坡上，一个孩子仰面躺在野餐垫上，手枕在脑后看天；天上的云恰好排成一只恐龙和一艘船的轮廓；一只小狗趴在旁边也跟着抬头；旁边有野餐篮和几个苹果。
**色彩重音**：天蓝与草绿打底，奶白的云作重音。
**落点**：想象力与闲适。云要"恰好像"，不要画成写实的恐龙形状。

### 10. 🌸 花 → `flower.webp`｜「发芽了」

**主体与场景**：春日阳台上，一位头发花白的奶奶和一个孩子一起蹲在花盆前；孩子握着小小的喷水壶给刚冒出的绿芽浇水，奶奶的手轻轻扶着他的手背；旁边一排在开的小花和几个陶土盆；阳光斜照进来。
**色彩重音**：新绿与陶土暖褐打底，花瓣的粉白作重音。
**落点**：孝亲、陪伴、生命与耐心。祖辈角色在整组里只出现在这一张——要有，但不必每张都是父母。

### 11. 🐢 乌龟 → `turtle.webp`｜「慢慢来」

**主体与场景**：午后的池塘边，一个孩子蹲在岸边的石头上，专注地看着一只乌龟慢慢爬过石板；孩子也学它把动作放得很慢，脸上是安静的笑；池塘里有浮萍和睡莲，一只蜻蜓停在草叶尖上。
**色彩重音**：苔绿与池水青打底，阳光金作重音。
**落点**：耐心，尊重每个生命自己的节奏。孩子**在岸边石头上**，不涉水、不伸手进水里。

### 12. 🎈 气球 → `balloon.webp`｜「分你一个」

**主体与场景**：阳光下的公园草地上，几个孩子围在一起；其中一个把手里的一只红气球递给还空着手的同伴；其他孩子各自拿着不同颜色的气球；背景是树、长椅和一位推着婴儿车的家长；所有人都在笑。
**色彩重音**：晴空蓝与草绿打底，彩色气球作重音。
**落点**：分享与友谊。动作方向是"递出去"，不是争抢，也没有谁在哭。

## 六、怎么保持 12 张的一致性

单张好看不难，12 张摆在一起不散才是这批图的真正难点。做法：

1. **先出 2 张定调**（建议先做 `dino` 和 `moon`——一张白天一张夜里，能一次性暴露色温和明度问题），确认画风后再批量出剩下 10 张。
2. **用参考图**：GPT-Image-2 支持带参考图。把已确认的图作为风格参考一起传，比反复改文字描述有效得多；提示词里明确写「保持参考图的画风、纸质纹理和轮廓线粗细不变」。
3. **固定那段【风格】文字**：一个字都不要改。改一个字，第 7 张和第 3 张就会明显不是一套。
4. **出图后并排检一遍**：地平线是否都在同一高度、光源是否都来自左上、轮廓线粗细是否一致、背景复杂度是否一致、每张是否只有一个焦点。
5. **优先修不合适的**，别重开：同一张多出几版挑一版，比重新描述重来快。

## 七、落地规格

| 项         | 值                                                                                                   |
| ---------- | ---------------------------------------------------------------------------------------------------- |
| 文件名     | `public/art/{dino,paint,rocket,bird,star,moon,whale,castle,cloud,flower,turtle,balloon}.webp`        |
| 尺寸       | 出图后统一裁成 **1272 × 716**（16:9）；卡片显示宽度最大 318px，2× 屏需 636px，1272 有充足余量        |
| 格式与体积 | WebP，质量 78，单张目标 **≤ 130KB**；12 张合计 ≤ 1.5MB，配 `loading="lazy"` 可保住首屏 < 2s 的验收线 |
| 裁切       | 卡片 CSS 是 `object-fit: cover`，轻微裁切不损构图；但主体必须留在中央 8% 安全边距内                  |
| 接入       | `items={WORKS.map(w => ({ src: \`/art/${w.slug}.webp\`, alt: \`《${w.title}》\` }))}                 |
| `alt`      | 写成「《小明的恐龙工厂》」这样的真书名，屏幕阅读器与 SEO 才拿得到内容                                |

### 为什么画面里不放书名

原则是："一张卡 = 一本成品绘本的封面（带孩子的名字）"。**名字不要烘焙进图里**，理由有三条：

1. **224px 宽 + 5.2px 模糊下，书名根本读不出来**——后排卡片压到 28% 不透明度，字会先糊成一团脏点，反而毁掉画面。
2. **中文文字是文生图的稳定失分项**，容易出现错字、缺笔和乱码，而绘本封面恰恰最不能出错。
3. **名字是变量，画是常量**。名字放进 DOM 覆盖层（或只在卡片转到最前面时浮出书名），换一个孩子的名字不用重新出图——12 张图一次生成，服务所有用户。

只改骨架里的 `【风格】`，其余一律不动。

**变体 A · 现代扁平**（最推荐备选）

> 现代扁平插画：干净的矢量色块 + 细腻颗粒噪点，无轮廓线或极细轮廓线；几何化的可爱人物造型（圆头、简化的手脚）；柔和的投影；高明度低饱和的粉彩色板。
> _优点_：在 224px 小尺寸和 5.2px 模糊下最清晰，和 hero 的极简浅色 + 点阵网格最搭。_代价_：绘本的纸张温度少一些。

**变体 B · 3D 软陶**

> 3D 软陶渲染：哑光黏土质感，圆润饱满的造型，柔和棚拍光，浅景深，轻微的角色倾斜。
> _优点_：可爱，适合后续做角色周边或公仔。_代价_：小尺寸旋转时细节最容易糊成一团，且"渲染感"偏商业。

**变体 C · 彩铅为主**

> 全彩铅手绘：保留明显的排线笔触和纸张纹路，水彩只在需要大面积铺色的地方打底，轮廓线更粗、更松弛。
> _优点_：最"手作"，最能和 AI 生成感拉开距离。_代价_：排线在小尺寸下会变成噪点，需要把笔触画得更粗更少。

## 九、配套：整站配色要不要一起换

紫色 `#7657ff` 偏科技感，和亲子场景冲突。这批图一旦落地，**建议同批把强调色换成暖橙或草绿**——否则一组暖色绘本卡片配紫色按钮，画面会分成两半。

改动只有一处：`src/app/globals.css` 里 `:root` 的 `--accent` 和 `--accent-rgb`（两个必须同时改，后者供 `rgba()` 使用）。全站组件样式都从这一处取色，改完即生效。

**已执行**：换成陶土橙 `#c2410c`（`--accent-rgb: 194, 65, 12`）。选法不是凭口味——把 12 张封面转进 HSV，统计有饱和度像素的色相直方图，约 72% 落在 0–75°（橙红 15° / 橙 30° / 黄 60° 三座峰），紫色所在的 251° 附近几乎没有像素。陶土橙色相 17° 压在最大的峰上，对页面底色 `#f7f7f8` 的对比度 4.84:1，高于原紫的 4.28:1，正文级 AA 也过。次选琥珀 `#b45309`（25°，4.69:1）更柔，草绿 `#4d7c0f`（85°，4.66:1）偏"自然成长"叙事。

## 十、派生：`public/art-cards/`（不是新出图）

工作台的**主题墙**要用这 12 张图的一格一张小图（`/home` 那面墙、以及书架的主题格）。
它不是新画的，是从上面这 12 张**同一张**派生的：

```bash
python -I scripts/make-webp.py public/art public/art-cards --preset theme-card
```

| 项     | 值                                                                               |
| ------ | -------------------------------------------------------------------------------- |
| 预设   | `theme-card`：16:9 / 目标宽 320 / 单张上限 18 KB                                 |
| 产出   | `public/art-cards/{key}.webp`，12 个文件，合计 **0.13 MB**，实测平均 11 KB       |
| 裁切   | **不裁**。源与预设同为 16:9，这一步是恒等变换（与 `book-spread` 那档同一条道理） |
| 文件名 | 只由主题 `key` 决定，与 `artPath()` 同一条约定（对不上就是一张裂图）             |

取路径走 `src/lib/themes.ts` 的 `themeCardPath(key)`。
**不走 `/api/assets?w=`**：静态 `public/` 走不到那条通路（Next 直接发盘上的字节，
查询串它看不懂，挂 `?w=` 会静悄悄回原图，见 README §五「缩略档」那条）。所以预生成。

★ 图上墙时**不加 `loading="lazy"`**：墙的第一行在 900px 高的窗口里就落在首屏，
对首屏内的图用 lazy 实测会让 12 张里 11 张不加载（工单 03 的 Comments）。
