## 一、这批图的难处：画的是**机制**，不是爱好

首屏那 12 张画的是「孩子喜欢什么」——恐龙、火箭、鲸鱼，天然有主体、有动作。
这一批要画的是**产品机制**：角色一致性、声音克隆、两种形态、Agent 流水线、无头引擎。

机制是抽象名词，抽象名词画出来就是信息图。所以这一批的第一条规矩沿用
`cover-art-prompts.md` §一 那句：**价值导向要落在画面正在发生的事里，不是贴在标题上。**
每一条都翻译成"谁在什么地方正在做什么"：

| #   | 机制            | 画成什么现场                                                                                         |
| --- | --------------- | ---------------------------------------------------------------------------------------------------- |
| H1  | 角色一致性      | 摊开的书上有四扇小窗，每扇里是**同一个孩子**在四个不同场景                                           |
| H2  | 父母的声音      | 孩子靠在枕头上听书，床头手机亮着，一条暖色弧线从手机连到他                                           |
| H3  | 两种形态        | 同一条草坡路，左半是暮色里的一条直线，右半在树下分成两个岔口                                         |
| H4  | 多 Agent 流水线 | 一间水彩作坊，长桌上排开一条线：草图→上色→戴眼镜的纸片小工匠拿放大镜检查                             |
| H5  | 无头引擎        | 夜里的空桌角：一台木压书架夹着**合上的**半成品书，曲柄**自己在转**，藤篮里堆着一叠成品页（v2，见下） |

**H4 与 H5 最大的风险是"科技感"跑偏**：一画流水线就容易出屏幕、发光、机器人、赛博朋克，
而这个世界里所有工具都应该是**纸、木、铅笔、水彩碟**。这两条的负面清单单独加严。

### 这批图共用的画面约束（比首屏多出来的部分）

| 约束                           | 为什么                                                                                 | 来自哪条已付过的学费                                           |
| ------------------------------ | -------------------------------------------------------------------------------------- | -------------------------------------------------------------- |
| **四边出血，不留白边**         | 卡片插画区是 `object-fit: cover` 铺满的，白边会被读成"图片加载失败"                    | 云批次六张里五张中招，见 `demo-book-art-prompts.md` §一        |
| **右下角避开高对比硬边**       | 那里压着编号角标；角标自带半透明底片，中低对比的主体压得住，怕的是深色硬边或高饱和高光 | 本组件新加（★ 本条初稿写过"不放主体"，是把机制想错了，见 §四） |
| **视觉重心在垂直中线 ±8% 内**  | 卡片上下结构（图 / 字），图的重心偏上或偏下都会让整卡看起来要倒                        | 沿用首屏 §一                                                   |
| **不出现任何文字、字母、数字** | 界面上的字全是真 HTML，图里有字就是两套字打架                                          | 沿用 `cover-art-prompts.md`                                    |
| **单张一个暖色重音**           | 五张会在同一屏并排出现，重音多了就吵                                                   | 沿用首屏风格段                                                 |

### ★ H1 有一条自找的苦头，是故意的

H1 要在**一张图里画四次同一个孩子的脸**。多脸正是角色一致性最容易崩的地方——
而这一条论证的恰恰就是"每一页都是同一个他"。

**所以这张崩了不许将就**：换脸就重出，不出第二张将就的版本。
这张图本身就是这个产品那条生死线的试纸。若一次过不了，先按
`demo-book-art-prompts.md` §三 那个 `character-design-sheet` 模板出一张设定表当参考图，
再带着参考图重出 H1。

## 二、共用骨架（每条都用这一段）

把 `【主体与场景】` 换成第三节对应那条，就是一张完整的提示词。
风格段与负面清单**逐字保留**，不要凭记忆重写。

```
儿童绘本插画，横版，一张完整画面（不是拼贴、不是多格分镜、不是画框样机、不是信息图）。

【主体与场景】
（替换为第三节对应的一条）

【人物】
东亚面孔的儿童，日常衣着，健康、有活力、表情自然；神态专注或开心，不做夸张变形。
画面里始终有成年人陪伴的痕迹（一盏亮着的窗、一只搭在椅背上的外套、桌对面的杯子），
但成年人本人不出镜。

【构图】
平视、略低机位（从孩子的视线高度看世界）；主体位于画面中央水平带，
视觉重心落在下三分之一，且在垂直中线 ±8% 内；地平线统一放在画面高度约 62% 处。
★ 右下角约 12% × 12% 那块区域尽量避免深色硬边与高饱和高光：那里会压一枚编号角标。
   这条是"尽量"而不是"必须"——角标自带半透明底片，中低对比的景物压上去照样清楚（见 §四）。

【风格】
温暖的手绘绘本风：水彩铺色打底 + 细彩铅轮廓线收形，可见纸质纹理，笔触松弛但不潦草。
高明度、低饱和的粉彩色板，整张只用一个暖色重音。阴影柔和无硬边。统一光源来自左上方。

★ 画面必须铺满整张画布，是"出血"画法：四边不得出现白边、纸边、画框、装裱、渐隐或任何留白。
   天空与地面一直画到画面最外缘的每一个像素，边缘处的颜色与纹理要有水彩的颗粒，不许平涂留白。
   "安全边距"只指重要内容离画面边缘保持距离，不是在边缘留空白——边缘要画满景物。

【文字】
画面内不出现任何文字、字母、数字、签名或水印。

【输出】
横版，16:9，1280×720。

【约束】
不要任何文字/字母/数字/水印/签名；不要品牌 Logo、卡通 IP 角色、商标或商品包装；
不要恐怖、阴森、暴力、受伤、哭泣、争吵、或被冷落孤单的形象；
不要危险动作（明火、高处无防护、深水涉水、无成年人看护的独处险境）；
不要写实到失真的人脸；不要深色压抑、赛博朋克、霓虹或高饱和撞色；
不要杂乱堆砌的背景细节；不要多格分镜、拼贴、样机、画框或阴影底板；
不要强透视导致的形变；不要电子屏幕、发光 UI、机器人、电路、齿轮链条的金属质感。
```

> 末行比首屏那批多了一句 **"不要电子屏幕、发光 UI、机器人、电路、齿轮链条的金属质感"**。
> 首屏画的是孩子的爱好，用不上这句；这一批五条里有两条（H4、H5）天生在描述"系统"，
> 不加这句，模型一定会给你一台发蓝光的服务器。这一句是这批图最要紧的一道闸。

## 三、5 张

### H1 · `character-lock.webp`｜角色一致性

```
【主体与场景】
一片午后草坡，一块红白格纹野餐垫。垫子前方摊开一本很大的绘本，书页朝观众立起来，
像四扇并排的小窗；四扇窗里画的是**同一个孩子**在四个完全不同的场景：
骑在一只温和的长颈恐龙背上、探出火箭舷窗、与一头鲸鱼并肩浮在浅蓝的水面、站在一座沙堡门前。
四扇窗外的孩子穿同一件衣服、同一张脸、同一撮翘起来的头发，
神态随场景变化（惊喜、专注、平静、大笑），但五官与比例严格一致。
真正的孩子本人坐在书前的野餐垫上，抬头看着这四扇窗，膝上摊着一本合上的小本子。
旁边趴着一只小狗，也抬头看。
```

- ★ 这一条的成败只看一件事：**四张脸是不是同一个人**。不是就重出（见 §一）。
- 四扇窗是"书页"而不是"画框样机"：窗框就是书页的边缘，不要加木框或投影底板。

### H2 · `thirty-seconds.webp`｜父母的声音

```
【主体与场景】
夜晚的孩子卧室，暖黄的台灯。一个孩子靠在床头，膝上摊开一本绘本，
神情安稳、微微笑着在听——**不是孤单地等**。
床头柜上一部手机屏幕朝上亮着，屏幕里不画任何 UI，只画一团柔和的暖光。
从这团暖光到孩子的耳朵之间，有一条极淡的、像声波又像纸飞机的暖橙色弧线，
弧线上落着两三只很小的纸飞机。
窗外是远处的屋顶与一盏亮着的窗（有人在灯下做事），窗玻璃上有淡淡的月色。
被子、书页、台灯是画面里唯一的三个暖色重音。
```

- ★ 负面清单里 **"不要被冷落孤单的形象"** 在这一条上最难守：
  一旦孩子被画得小、被画在画面角落、或窗外那盏灯显得遥远冷清，就废掉重出。
  判据是"第一眼读起来是被陪伴着"，不是"读起来让人心疼"。
- 手机只给一团光，不画屏幕内容——画了 UI 就变成产品截图，且违反"不出现文字"。

### H3 · `two-forms.webp`｜一个引擎，两种形态

```
【主体与场景】
一整片连续的草坡，一条土路从画面下方正中往远处延伸。
**左半是暮色**：月亮刚升起来，那条路笔直地通向远处一扇亮着灯的窗，
路边是已经收好的野餐垫与一只藤篮，气氛是"要睡觉了"。
**右半是白天**：同一条路在一棵大树下分成两条岔路，一条尽头是一朵形状像恐龙的云，
另一条尽头是一朵形状像帆船的云；路边散落着风筝与一只滚开的球，气氛是"还在玩"。
两半之间**不许有分割线、不许有明暗突变**——同一座山、同一棵树、同一片草地自然过渡，
暮色那一侧只是光线更柔更暖。
```

- 沿用 `demo-book-art-prompts.md` §一 的**中缝**教训：这条提示词写的是"左右两半"，
  模型很容易真画一条竖线。若出现接缝，把"两半"改成"画面的左边/右边"再重出。
- 一张图里同时有白天与夜晚是这一条的立论本身（同一本故事的两种形态），
  不是构图失误，所以过渡必须自然到"第一眼不觉得奇怪"。

### H4 · `agent-pipeline.webp`｜多 Agent 流水线

```
【主体与场景】
一间明亮的、像手工教室的房间，一长条木桌从画面近处斜向远处，桌上是一条**纸的流水线**：
最近处是一叠铅笔分镜草图（画着格子与火柴人式的构图示意），
中段是一排正在上色的水彩页，两三只小小的、由纸折成的工匠（没有脸，只有折痕）
正拿着比它们还大的画笔涂色；
再往后，一只戴圆眼镜的纸片工匠举着一页对着窗口的光在**检查**，
旁边摊着一张画了几个圈和勾的记录纸（勾与圈是手绘符号，不是字母数字）；
最远处的绳子上用木夹晾着一排已经合格的画页，随风轻轻摆。
桌角散落铅笔屑、水彩碟、洗笔的罐子。窗外是白天的草坡。
```

- ★ 这一条最容易被画成"科技架构图"。所有元素必须是**纸、木、布、铅笔、水彩**，
  不许出现屏幕、发光、机器人、电路、金属齿轮（共用骨架末行已写死）。
- 记录纸上的符号只许是圈和勾。一旦出现可读的字母或数字，这张废掉重出。

### H5 · `headless-engine.webp`｜无头引擎

```
【主体与场景】
一本竖立摊开的绘本放在一只**木盒**上，盒身没有任何标签或文字，只看得见木纹与铜包角。
盒子侧面伸出一段手摇曲柄，顶端系着一根垂下来的缎带（像八音盒那样），
盒身的一道缝里正送出一张刚画好的水彩画页，画页还带着一点微微卷起的纸边。
盒子的另一面露出两三颗**木齿轮**，齿轮的齿是手绘的、不太规整。
桌面上散落着几张已经吐出来的画页、一支铅笔、一块橡皮。
背景是安静的画室一角，光从左上方来。
```

- 这一条要的是"引擎在界面之下、自己能出成品"，
  所以**书在上、盒在下**的位置关系不能反：反了就变成"盒子撑着一本书"，读不出谁生产谁。
- 齿轮要木头的、手绘的。金属齿轮 + 曲柄 = 蒸汽朋克，是这批图最容易掉进去的另一个坑。

### H5 v2 · `headless-engine.webp`｜无头引擎（2026-10-18 重写，**已替换落盘**）

> ★ **盘上那张 `headless-engine.webp` 现在（2026-10-18 21:14 起）就是这一版出的。**
> 这份文档不改写历史：v1 的文字留在上面，这一节是它的替代品；
> v1 出的那个文件备份在 `.out/hl-v2/headless-engine-v1-backup.webp`（一次性的，不入库）。

**为什么重出（这是一次实测，不是口味）**：用户截了首页轮播，说第 1 张和第 5 张
**是同一张图**。量下来确实是同一个画面——同一个孩子盘腿坐在红白格纹野餐垫上，
面前是同一本立起来的、四格的折页书（恐龙 / 火箭 / 鲸鱼 / 沙堡），旁边同一只狗。
两个文件的 md5 不同（`c6d0d155…` / `72fb0e16…`，都是 2026-10-12 20:24），
**是两次独立生成，各自长成了同一张画**。

**为什么会撞**：v1 的提示词写的其实是"书压在木盒上、盒侧有曲柄"，
而 §四 2026-10-12 那条验收记录自己就写着它出成了「孩子在一座木头戏台后面翻一本摊开的书」
——**v1 当时就没被照着画，而验收记的是"通过"**。根子在共用骨架的 `【人物】`：
它要求画面里有个孩子，而 H1 与 H5 的场景里又都有一本大书，"孩子 + 一本大书"
就是那个默认落点，模型两次都掉进去了。

**为什么撞了这么久没人发现**：01 与 05 在序列里隔着三张，不并排。
但轮播是**循环**的——05 的下一张就是 01，接缝处正好相邻（用户那张截图就是这个接缝）。
**所以这套图要按"接缝邻居"排一遍（01-02…05-01），不是只看序号顺序。**

**这一版改的不是辞藻，是三个轴一起换**：

| 轴       | v1（撞车的那版）   | v2                                     |
| -------- | ------------------ | -------------------------------------- |
| 人       | 孩子在画面里翻书   | **画面里没有人**（这正是这一条的立论） |
| 书       | 摊开的、书页朝观众 | **合上的、只订好一半**，书脊朝外       |
| 时间光线 | 白天的画室         | 夜里，灯还亮着，窗外不是黑             |

改的是**主体是"没人看着它也在干"**：v1 描述的是"一台机器"，人站在旁边；
v2 描述的是"一台机器，而人已经走了"。`【人物】` 那一段因此**故意**不画人——
这是本节唯一偏离共用骨架的地方，而这个偏离就是根因修复本身。

```
【主体与场景】
夜里一张木桌的一角，台灯还亮着——**画面里一个人都没有**，只有刚离开的痕迹：
一把推开的小椅子、搭在椅背上的小围裙、桌上那杯还冒着热气的牛奶。
桌子正中是一台**木制的小压书架**：两片厚木夹板被一根粗木螺杆拧紧，
夹着一本**合上的、只订好一半**的小书，书脊朝外，露出一截缎带书签。
夹具侧面伸出一段**手摇曲柄**，曲柄末端系着一根缎带，缎带被带得斜斜扬起——
看得出**它此刻正在转，而没有任何手在摇**。
压书架下方的一道缝里正送出一张刚画好的水彩画页，纸边微微卷起。
```
