# 品牌标记 —— 出图提示词与裁切依据

> 用途：首屏品牌锁定 `小主角 · Once Upon Me` 最左边那枚标记（`src/app/page.tsx` 的 `<img className="mark">`）。
> 产物：`public/brand/mark.webp`（560×560，23.8 KB）。
> 模板：`illustration-art-style`（插画与艺术风格），场景标签 `story` + `creative` —— 与 12 张封面同一个模板，见 [cover-art-prompts.md](cover-art-prompts.md)。

---

## 一、提示词

出图时把 12 张封面中人物画得最干净的一张作为**风格参考图**一起传，并写明：保持参考图的画风、纸质纹理、轮廓线粗细与上色方式不变。

```text
为儿童绘本产品「小主角 · Once Upon Me」画一枚品牌小标识插画：
一个孩子背对着我们，站在一本摊开的书正中央，像站在一座小岛上。
书平放在画面下方，两页微微翘起，书脊朝上，孩子就踩在书脊上，
个头很小，占画面高度约四分之一，头略微抬起，正望着前方看不见的远处。
只画这一个孩子和这一本书，不要第二个人、不要道具、不要背景场景。

构图：正方形 1:1。摊开的书占据画面下方三分之一，左右几乎顶到边，
形成一条稳定的水平基座；孩子严格居中，站在书脊的顶点。
头顶上方留出画面高度约 40% 的空白，这片空白是"故事还没开始"的呼吸。
背景是一整块极浅的暖米色（接近 #FBF3E7），平涂，无渐变、无纹理、无场景元素。

风格：手绘水彩儿童绘本插画，纸张纹理轻微可见，轮廓线用细而肯定的暖棕色（不要纯黑），
高明度、低饱和的暖色系，平涂为主加一层极淡的水痕。
书页是奶白偏暖，书脊和封面用陶土橙 #C2410C，孩子的衣服用深暖棕 ——
全图饱和度最高的是那抹陶土橙，它是视觉锚点。
气质安静、温柔、有纸感，不商业、不塑料。

文字：画面里不出现任何文字、字母、数字、标点、logo、水印或签名。
书页上不画任何文字，用极淡的横向浅灰线条暗示行距即可。

输出：1:1 正方形，1024×1024，PNG，背景不透明。

禁止：紫色与蓝紫色系；看到孩子的正脸或侧脸（必须是纯背影）；3D 渲染感；
黏土人/盲盒质感；赛璐璐动漫大眼；写实摄影；描边发光；投影；渐变背景；
装饰性星星、云朵、气泡；书本立体化成道具或宝箱；人物比例过大压过书；
手指脚趾畸形；画面被裁切。
```

选背影而不是正脸，有两个理由：一是文生图里**脸是最不稳的一环**，背影直接绕开五官畸形的风险；二是"孩子站在摊开的书上"就是产品的字面承诺——他走进故事里，成为主角。

## 二、为什么落盘的图被裁过

模型按提示词留了头顶 40% 的呼吸空间，那是**海报构图**；但标记在页面上只有 `.78em` 见方——品牌字号 `clamp(40px, 6.4vw, 84px)`，也就是**最窄屏 31px、宽屏 65px**。原图直接缩放的话实测：

|               | 主体占宽 | 主体占高 | 主体面积 | 65px 下孩子实际大小           |
| ------------- | -------- | -------- | -------- | ----------------------------- |
| 原图整方块    | 89%      | 50%      | 9%       | 约 12px，几乎只剩一条橙色横杠 |
| 裁到 560 见方 | 100%     | 91%      | 24%      | 约 40px，书和人分得清         |

所以落盘的是原图中央 `x 231–791 / y 381–941` 这块 560×560，**以孩子为中心**、左右保住大半个摊开的书面。重做命令：

```bash
python -c "from PIL import Image; Image.open('theme.jpg').convert('RGB').crop((231,381,791,941)).save('mark.webp','WEBP',quality=86,method=6)"
```

保留 560 的原生分辨率、没往下缩到 256：标记在页面上最大才 65px，256 本已绰绰有余，但 560 也只 23.8 KB，日后当 favicon 或开屏图复用时不必回源重出。

## 三、配套的两处样式决定

在 `src/components/hero/hero-orbit.css` 的 `.hero__brand .mark` 上：

- **投影从中性墨色来**（`0 8px 22px rgba(19,19,28,.14)`），不用强调色光晕。标记原本是实心陶土橙方块，橙光晕是同一色的延伸；换成浅纸色的图之后，橙光晕会在纸色方块外糊出一圈脏边。
- **`background: #f6eddc`** 取图片自己的纸色，加载那一帧不闪一块别的颜色。

强调色本身（`--accent`）为什么从紫换成陶土橙 `#c2410c`，依据写在 [cover-art-prompts.md §九](cover-art-prompts.md)。

## 四、favicon 用的是另一块取景

`src/app/icon.ico`（16 / 32 / 48 三帧，7.3 KB）。走 Next 的 metadata 文件约定——文件放在 `src/app/` 下就自动挂进 `<head>`，`layout.tsx` 里不用声明任何东西。

它**不是**上面那张 560 裁切的缩小版。把 560 那块直接缩到 16px，实测只剩一块浅色斑——书变成一条细线，孩子变成一个点。所以 favicon 另取一块**以孩子为中心的 400 见方**（相对 `mark.webp` 的 `x 80–480 / y 80–480`），加 22% 圆角与透明四角。重做：

```bash
python scripts/make-favicon.py
```

四种取景在 16px / 32px、深浅两种标签栏底色上并排比过：紧裁 400 是唯一还能读出"一个孩子站在书上"的那档；再紧到 300 就只剩一个深色点，丢掉书这条橙色基座；不裁（560）则整块发糊。

> Next 给这个文件生成的 `<link>` 上写的是 `sizes="16x16"`，但 ICO 里确实带 16/32/48 三帧，浏览器会自己挑合适的——那行声明是 Next 的默认值，不用改。
