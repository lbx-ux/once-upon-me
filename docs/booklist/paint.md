## 一、这本书

### 主角锚点 · 小树（封面与八张跨页**一字不改**）

```
小树，约 5 岁的东亚小男孩：乌黑的短发，额前一层碎刘海，发梢有点翘；圆脸、
深棕色的大眼睛、眼距略宽；笑起来眼睛先弯；鼻子一个小圆点，嘴小。
穿一件**浅米色短袖 T 恤**（胸前没有任何图案）、深蓝色长裤，光着脚。
身高约 4 个头身，手脚圆润短小。
以上任何一项都不得改动：不换发型、不换发色、不换衣服颜色、不长高、不穿鞋。
```

### 妈妈锚点 · 妈妈（只出现在 P8，同一人）

```
妈妈，约 35 岁的东亚女性：黑发松松地在脑后挽一个低髻，几缕碎发落在耳前；
穿**米白色的家居开衫**与深灰色长裤；笑起来眼睛弯弯的、眼下有一点点纹路。
她在这本书里只做两件事：接住那张纸、把它贴上冰箱门——姿态安静，不俯视、不指点。
```

### 场景基调

**家里的客厅一角，下午**：木地板上一块从窗户斜进来的方形光斑，光里有细小的浮尘；
旁边是矮矮的木茶几、一条地毯的边、一盆绿植的叶子边缘；背景是浅色的墙，
墙上再远一点是冰箱的侧面。**没有电视、没有平板、没有玩具广告、没有任何带字的物件。**

★ 这一本的可信度全在**那张纸**上：纸上是一支蜡笔一笔一笔**攒出来**的画，
每一页都比上一页多一样东西（顺序见下面那张表），**前后不许跳、不许回退**。
纸上的画是**蜡笔的、歪的、孩子的手笔**——**绝不是写实的家人肖像**（这一条是这本书的落点，
也是 `paint.ts` 文件头写死的那句）。孩子的手是**右手**，蜡笔握得很低。

## 三、封面 `cover.webp`（完整可复制）

**参考图**：P0 + `public/art/paint.webp`　**输出**：先出 2:3（1024×1536），居中裁到 3:4

```
儿童绘本的竖版封面插画，一张完整画面（不是拼贴、不是多格分镜、不是书的样机）。

【主体与场景】
下午的客厅地板上，小树盘腿坐在那块方形光斑里，一只手把那张画举起来、举到胸前，
另一只手还捏着一支红色蜡笔；他正低头看自己画的画，嘴角有一点想笑又没笑出来的样子。
周围的地板上散着几支蜡笔与一只开着盖的旧铁皮盒，光里有细小的浮尘。
纸上看得见：太阳、一栋房子、三个手拉手的小人——**蜡笔的、歪的、孩子画的**。

【构图 · 竖版封面专用】
- 竖构图：小树与那张纸占画面中央偏下，两者合起来占画面高度约 60%；
  纸斜对着镜头，让纸上的三样东西都看得清。
- 小树的脸在画面垂直约 55% 处、纸在垂直约 66% 处；视觉重心落在垂直 60% 附近。
- 小树与那张纸离画面上下边各留出 8% 的余地（成品会上下各裁掉约 5%），左右边各留出 8%。
- ★ 画面四周**铺满、出血**：地板、光斑与浮尘一直画到最外缘的每一个像素，四边不得出现白边、
  纸边、画框、装裱、留白或渐隐到白。"安全边距"只指主体离边有距离，**不是在边上留空白**
  ——边缘要画满景物（上缘是光斑与地板缝，下缘是地毯的边与散落的蜡笔）。
- ★ 整幅是一张连续的画面：封面虽然是单页，也不许出现任何竖向的分格线或纸张边缘。
- 略高的俯视（能看到地板上摊开的纸），但桌上的东西不透视变形。

【人物】（逐字贴 §一 的「主角锚点」）

【风格】（逐字贴 §二 的「风格段」）

【文字】画面内不出现任何文字、字母、数字、签名或水印（书名由前端叠字）。
★ 纸上也不许出现任何字：那三个小人是**火柴人**，不许给他们写名字、标数字、画箭头。

【输出】竖版，2:3（1024×1536）。

【约束】（逐字贴 §二 的「负面清单」与「三条硬约束」，再补一条本书专用：）
★ 纸上那三个小人必须是**蜡笔画出来的火柴人**：歪的头、一条线的身子、四条线的手脚，
头比身子大；**不许**画成写实的家庭成员、不许有五官细节、不许上色成"插画"那种完成度。
```

### P1 · 跨页 1 `p1.webp`｜「下午的光」

```
儿童绘本内页插画，横版开页跨页，一张完整画面横跨左右两页（不是拼贴、不是多格分镜、
不是书的样机）。

【主体与场景】
下午的客厅地板，一块方形光斑从窗户斜进来落在木地板上，光里有细小的浮尘。
小树趴在光斑里，肚子贴地、两肘撑着，一只手拿蜡笔、另一只手压着一张**还空白的白纸**；
他刚起手，正在挑颜色，脸侧着、眼睛看着散在旁边的蜡笔。
蜡笔散了一地（七八支，长短不一），旁边是那只**旧铁皮饼干盒**，盖子开着、里面还有半盒。
画面里没有别人。

【构图 · 开页跨页专用】
- 画面水平 50% 处是书脊：小树在**水平约 28%**（整块在左页），头朝左、脚朝右；
  光斑与散开的蜡笔一直铺到**水平约 72%**，右边的地板上再放那只开盖的铁皮盒与几支蜡笔。
- ★ 小树的脸与身体主干不得进入水平 46%–54%。这一条优先于"画面居中"这个默认构图习惯。
- 视觉重心落在画面垂直中线 ±5% 内（地板的水平接缝在垂直约 68%）。
- ★ 左右两缘要**画满**、不许留白：左缘让木地板与光斑的近景一直延到画面外，
  右缘让地毯的边与几支蜡笔贴住边；两缘的地板纹理都要有水彩颗粒。
- ★ 中央**不得有接缝**：光斑铺过水平 50% 的那一段必须连续，不许出现竖向折痕或明暗突变。
- 略高的俯视（能看到地板上摊开的纸），但纸的透视不许变形。

【角色锁定】（逐字贴 §一 的「主角锚点」）
【纸上】此时**还是白纸**：顶多有一道起手时留下的浅痕，不许有太阳、房子或小人。
【风格】【文字】【输出】横版 3:2。【约束】（逐字贴 §二）
```

### P2 · 跨页 2 `p2.webp`｜「一个太阳」

```
【主体与场景】
镜头拉近到地板上那张纸：**一个蜡笔画的太阳**刚刚画完，圆得有点歪，
光是一圈往外散的短线（**大约十二根**，长短不一，有两根画出了纸的边）。
小树的右手还捏着那支黄色蜡笔停在太阳旁边，是"刚收笔"的那一下；
他的上身与侧脸在画面左侧，低头看着自己画的太阳，嘴角已经翘起来了。

【构图】
- 画面水平 50% 处是书脊：小树在**水平约 24%**（整块在左页，只到肩膀），

- ★ 小树的脸与身体主干不得进入水平 46%–54%；纸可以跨中缝，那三个"人"还都没画出来。

【纸上】太阳只有**一个**，一圈短线；**没有**房子、没有小人、没有地面线。
【角色锁定】【风格】【文字】【输出】横版 3:2。【约束】（逐字贴 §二）
```

### P3 · 跨页 3 `p3.webp`｜「一栋房子」

```
【主体与场景】
小树趴在纸前面画房子：**一栋方方正正的房子**刚画好，**门开得很大**（差不多有一半墙那么宽），

- 略高的俯视能看到整张纸上的两样东西。
【纸上】太阳（左上空着的位置）＋ 房子；**没有**小人、没有地面线。
```

### P4 · 跨页 4 `p4.webp`｜「三个小人」

```
【主体与场景】
纸的中间，**三个手拉手的小人**刚画完：蜡笔画的火柴人，头比身子大、一条线的身子、
四条线的手脚；**手拉得很长**，三条手臂连成一条几乎水平的波浪线，把小人的手都连在一起。
一个高、一个矮一点、中间那个最矮。小树正把蜡笔从中间那个小人的手上移开，

【构图】
- 画面水平 50% 处是书脊：小树在**水平约 26%**（整块在左页），纸在**水平 36%–90%**，

【纸上】太阳 ＋ 房子 ＋ **三个手拉手、手特别长的小人**；**没有**地面线、**没有**笑线。
```

### P6 · 跨页 6 `p6.webp`｜「红色用完了」

```
【主体与场景】
这一页的镜头落在那只**旧铁皮饼干盒**上：盒盖仰在一旁，盒里躺着十几截蜡笔，
长的短的都有、有的只剩一个头；小树的右手伸进盒子里翻找，指头刚捏住**半截红色蜡笔**，
把它拎起来一点点。他的脸在画面左侧、侧着、微微皱眉——是"红色没了"的那一点点为难。
纸与盒之间散着几截用过头的蜡笔头、一小片卷起来的蜡笔皮屑。

【构图】
- 画面水平 50% 处是书脊：小树在**水平约 28%**（整块在左页，只到肩膀与手），
  铁皮盒在**水平 58%–84%**（整块在右页），盒里的蜡笔与那半截红色是这一页的视觉重心。
- ★ 小树的脸与身体主干不得进入水平 46%–54%。这一条**优先**于"把盒子摆在正中"的构图习惯。
```

因为它的每一拍动作都很小——**翻页快的时候，一段 14 秒正好是一幅画看完的时间**。

封面与封底**不配音**：书还没打开，没有哪一页在念。

★ **念这三句的语气**：这一本是"孩子在做事"的书，不是一个故事。念的人**不要讲故事腔**，
要像**蹲在旁边看孩子画画的那个人**：句子之间留得住，逗号处真的停一下；
引号里那两句（P3「谁都能进去。」、P8「这是我们。」）是**孩子说的**，
念得短、平、不打弯，**不要念成感慨**。

★ 通篇**没有加一个标点**：上面每一段里只有 `／`、`／／` 与重音是记号，
其余逐字与 §五 各段 = `paint.ts` 的正文一致（记号不印在纸上）。

### P1 ·「下午的光」→ `p1.m4a`

```
下午的光从窗户斜进来，／ 落在**地板上**。／／
小树趴在那一块光里画画，／ 蜡笔**散了一地**。／／
旧铁皮盒里／ 还装着**半盒**。／／
```

> 三句就是三个镜头：光、孩子、盒子。最后一句压轻一点，"半盒"是这一页的钩子
> （P6 要用到它）。

### P2 ·「一个太阳」→ `p2.m4a`

```
他先画了一个太阳，／ 圆得**有点歪**。／／
太阳的光，／ 是一圈往外散的**短线**。／／
他数了数：／ 一共有**十二根**。／／
```

> "有点歪"要念得**高兴**，不是挑错。"十二根"这三个字放慢——那是孩子真的数过一遍。

### P3 ·「一栋房子」→ `p3.m4a`

```
他又画了一栋房子，／ 门开得**大大的**。／／
窗户是两个方块，／ 屋顶上还有个**烟囱**。／／
「谁都能进去。」／ 他说。／／
```

> 引号那一句是孩子的话：**短、平、认真**，别笑场、别念成大人逗孩子。

### P4 ·「三个小人」→ `p4.m4a`

```
然后他又画了**三个小人**，／ 手拉着手。／／
一个高，／ 一个矮一点，／ 中间那个**最矮**。／／
他把他们的手画得**特别长**。／／
```

> "特别长"是这一页要孩子笑出来的地方，稍微扬一点；前面"一个高，一个矮一点"
> 三个短句一顿一顿地念，像在纸上点名。

### P5 ·「是爸爸和妈妈」→ `p5.m4a`

```
一个是爸爸，／ 一个是妈妈，／ 中间那个是**他自己**。／／
他在三个人脚下画了一条线，／ 那是**地面**。／／
「这样他们就不会掉了。」／／
```

> 这一页是全书的**落点**：念到"他自己"要停半拍。最后一句不解释、不加语气，
> 平平地让它落地——孩子说的就是孩子说的。

### P6 ·「红色用完了」→ `p6.m4a`

```
红色蜡笔用完了，／ 纸上只剩**一小截**。／／
他在旧铁皮盒里翻出半截，／ **接着画**。／／
盒子里／ 还有一股**饼干的味道**。／／
```

> 最后一句离题一点点——就是要离题：孩子的注意力就是这样拐弯的。
> 念这句的时候把速度放下来，像真的闻到了一下。

### P7 ·「一条笑线」→ `p7.m4a`

```
他给每个人都画上／ 一条弯弯的**笑线**。／／
爸爸的、／ 妈妈的，／ 一个也不漏。／／
最后他在自己脸上，／ 画得**最大**。／／
```

> 声音到这里可以暖起来一点点。"一个也不漏"念得像在数人；"最大"两个字稍微重。

### P8 ·「这是我们」→ `p8.m4a`

```
画完了，／ 小树把纸**举起来**给妈妈看。／／
「这是我们。」／ 他说。／／
妈妈把画贴在了冰箱门上，／ 用一颗**磁扣**。／／
```

> 收尾三句一句比一句轻。念完**别急着停**，让"磁扣"那一下留 1 秒——
> 这本书最后要的就是那一下"啪"贴上去之前的安静。

### 时长都短于 §五 那张表，而且**那张表本身按现在的声音永远达不到**

八段 11.0–12.7 秒，**全部短于 §五 写的 13–16 秒**（也短于 [`README.md`](README.md) §四 的 14–21 秒）。
根因不在录音：§五 那档时长按 **3.2 字/秒** 估，而三本书 24 段实测的语速是
**3.6–4.7 字/秒**（paint 3.87、dino/moon 3.9–4.5）。版面又把每页压在 **≤60 字**
（§四 那条"为什么每页就 42–60 字"），于是 60 ÷ 3.9 ≈ **15.4 秒是天花板**，
"14–21 秒"与"42–60 字"这两个约束**不可能同时满足**。
→ 待定的规格决策（是出图的人定）：**A** 把规格改成按字数、时长只做旁证；
**B** 让 TTS 放慢到 3.2 字/秒；**C** 承认 11–13 秒是这一套的实际时长，把 §五 与 §四 的表重写成 11–15 秒。
现在 §五 的表照旧不改，**别把"表里的数"当成已经达到的事**。
