## 一、这本书

★ **这一本是两个人一起做一件事**，所以每一页都要看得见"两个人各自在做的那一下"——
谁在拍、谁在挖、谁在提水。★ **不许出现"一个人在堆、另一个人在看他堆"**：
那正是这本书要反对的构图（`castle.ts` 文件头：一个人堆到一半会塌，四只手一起就不会）。

★ **城堡是孩子的沙堡，不是王权。**（`cover-art-prompts.md` §三第 8 条写死）：
**没有王冠、没有纹章、没有士兵、没有大炮、没有炮台、没有吊桥铁闸**；
那面"小旗"是**一块花手帕系在一根小棍上**——不是旗帜（★ 旗面上**不许有图案、字母、
条纹徽记**，因为手帕的碎花不是徽章）。

★ **潮水是这本书的时钟**：它**一点点**推上来，最后把城堡舔掉。
"一点一点化掉"是这个故事的下半段，所以**水线的高度必须逐页对得上**
（下面那张状态表里写死了每页水线到哪）——★ 不许在 P3 就把水推上来，也不许 P8 还停在原地。

### 主角锚点 · 阿布（封面与八张跨页**一字不改**）

```
阿布，约 5 岁的东亚男孩：乌黑的短发（短、不遮耳）、圆脸、深棕色的大眼睛、眼距略宽；
笑起来眼睛先弯。穿**浅蓝色的短袖 T 恤**（胸前没有任何图案）与**深蓝色的短裤**；光着脚。
身高约 4 个头身，手脚圆润短小；右手拿一把**蓝色手柄的小塑料铲**。
以上任何一项都不得改动：不换发型、不换发色、不换衣服颜色、不长高、不穿鞋。
```

### 主角锚点 · 小南（封面与八张跨页**一字不改**）

```
小南，约 5 岁的东亚女孩：乌黑的头发在脑后扎一个**短短的马尾**（素色皮筋，没有蝴蝶结），
圆脸、深棕色的大眼睛、眼距略宽。穿**浅黄色的短袖连衣裙式上衣**（胸前与裙摆上没有任何图案）
与浅色短裤；光着脚。身高约 4 个头身，**与阿布一样高**（★ 不许把她画矮或画小）。
右手拿一把**浅绿色手柄的小塑料铲**。
```

★ 两个孩子的**身高、头身比例、手脚大小要保持一致**——这一条最容易松：
模型很愿意把女孩画小半头。九张并排时这一点一眼就看得出来。

### 道具锚点（八张里同样点东西，位置可动、样子不许变）

```
小水桶：一个**浅红色的素色塑料小水桶**，一个提梁，桶身上**没有一个字、没有图案、没有贴纸**。
小铲子：两把，蓝色手柄（阿布）与浅绿色手柄（小南），勺子大小，手柄上是素色塑料。
花手帕：一块**浅蓝底带白色小碎花**的手帕，四边有细锁边；★ 上面没有字、没有字母、没有徽记。
小棍：一根普通的细木棍（约一支铅笔长），素色。
贝壳：一枚**米白色的小扇贝**（约指甲盖大），素色。
拖鞋：一双**素色的小拖鞋**——★ 只在 P1 的画面角落里，交代"他们是从哪儿来的"；
　　　　P2 起画面里不再需要它（不必每张都画）。
```

**黄昏的海滩**：天是**粉橙到浅蓝**的渐变（晚霞在右上方），海面反着一点晚霞的暖色；
沙滩是浅金色的、有细细的沙粒质感与一小片一小片的湿沙反光；
海浪线在画面上方（远景），随着页数一点点推上来。
**没有别的孩子、没有大人、没有遮阳伞、没有躺椅、没有垃圾、没有别的沙堡、没有任何带字的物件。**

### P1 ·「各挖各的」→ `p1.m4a`

```
阿布和小南一人一个坑，／ 各挖各的。／／
谁也没说话，／ 只有铲子**刮沙子**的声音。／／
阿布那边堆了一座塔。／／
```

> 前两句要念出**各干各的**那种安静的别扭（两个人都在，但没在一起）。
> "刮沙子"要轻、要有质感。最后一句平铺直叙，为下一拍的"塌了"埋下东西。

### P2 ·「塌了」→ `p2.m4a`

```
阿布堆的那座塔，／ 堆到一半就**塌下来**。／／
沙子顺着坡滑下去，／ 塔尖**没了**。／／
他愣愣地坐着，／ 铲子插在沙里。／／
```

> "塌下来"不要夸张（不许爆破音），它就是"滑下去"。
> 最后一句是全页的重点：**慢、空、什么都不加**——"铲子插在沙里"念完停满 1 秒。

### P3 ·「一起来」→ `p3.m4a`

```
小南也蹲下来：「我们一起堆一座吧。」／／
她把水桶倒过来，／ 拍出一个**圆圆的底**。／／
阿布把铲子拔出来，／ 挪了过去。／／
```

> 台词念得**随口、不劝说**（她就是提了一句）。
> 后两句是两个动作，节奏要**一前一后**（拍、然后挪），别连成一串。

### P4 ·「塔立起来了」→ `p4.m4a`

```
四只手一起，／ 塔就**一层一层**地立了起来。／／
你拍一下，／ 我拍一下，／ 谁也没有抢。／／
塔尖上，／ 他们放了一枚**贝壳**。／／
```

> "四只手一起"要念得**有点分量**（这是这本书的题眼）。
> "你拍一下，我拍一下"两个短句一顿一顿，像真的轮着来。最后"贝壳"放轻、放慢。

### P5 ·「护城河」→ `p5.m4a`

```
他们绕着城堡，／ 挖了一圈**深深的**护城河。／／
挖出来的沙子，／ 堆在城堡四周当城墙。／／
小南通到水里去提了半桶海水。／／
```

> 前两句是"施工"，念得有节奏、有点忙（两句都往上走一点）。
> 最后一句放平、放慢——是这一页的收束，也给下一拍留出空。

### P6 ·「一面小旗」→ `p6.m4a`

```
一块花手帕系在小棍上，／ 成了一面**小旗**。／／
小南把它插在**最高的**那座塔上。／／
风一吹，／ 手帕鼓起来一下。／／
```

> "成了一面小旗"要念出**成就感**（但别欢呼）。最后一句最轻、最短，
> "鼓起来一下"要像真的看见手帕鼓了一下就过去了。

### P7 ·「潮水来了」→ `p7.m4a`

```
潮水慢慢推上来，／ 护城河一下子**灌满了水**。／／
城墙上的沙，／ 一点一点被**舔掉**了。／／
两个人靠在一起，／ 看它慢慢化。／／
```

> 这一页的速度要**比前面慢一档**（水在推）。"舔掉了"三个字要轻、不能凶。
> 最后一句念得**安静、不解释**——他们只是看着，不要念成"他们很难过"。

### P8 ·「让它慢慢化」→ `p8.m4a`

```
阿布说：「我们明天再堆一个更大的。」／／
小南点点头，／ 把手从沙上松开。／／
城堡慢慢地化，／ 两双脚印留在旁边。／／
```

> 台词要念得**平常、笃定**——不是"安慰"，是"打算"。
> "把手从沙上松开"要慢，两个字之间留一点空。最后一句念完**留满 1 秒**：
> 这本书结束在一个还留着脚印的沙滩上，不在难过的情绪里。
