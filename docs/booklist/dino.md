## 一、这本书

### 主角锚点 · 小果（封面与八张跨页**一字不改**）

```
小果，约 5 岁的东亚小女孩：乌黑的头发扎成两条双马尾，发梢微微翘起；圆脸、
深棕色的大眼睛、眼距略宽；笑起来脸颊有一对浅梨涡；鼻子一个小圆点，嘴小。
穿一件**橙色外套**（这是全书唯一的暖色重音）、深色长裤、白色小布鞋。
身高约 4 个头身，手脚圆润短小。
以上任何一项都不得改动：不换发型、不换发色、不换外套颜色、不长高、不换鞋袜。
```

### 长颈龙锚点 · 它（同一只，八张跨页**一字不改**）

```
一只温和的植食长颈龙：脖子长而圆润，身体厚实像一堵缓坡，四条腿粗短；
皮肤是柔和的苔绿偏灰，腹部更浅、近似米白，背脊上有几块更深的圆斑；
眼睛小而温和，没有露出牙齿，脚上没有尖爪。
它是"一起发现一件小事"的同伴，**不是追人的猛兽**：站姿安静，动作慢，
目光始终看向小果或者那朵花。
```

### 场景基调

清晨的**蕨类丛林**：成片的蕨叶、粗壮的树干、低处一层薄薄的白雾、几道从左上斜下的光柱。
地面是深绿与褐色的落叶层。**没有现代物件**（没有栅栏、路牌、垃圾、建筑）。

```

不是书的样机）。

【主体与场景】
清早的蕨类丛林边，小果背着一只小布包，顺着一条窄窄的小路往里走，身体朝着画面右侧，

- ★ 中央**不得有接缝**：小路与光柱铺过水平 50% 的那一段必须连续，

### P3 · 跨页 3 `p3.webp`｜「一样高」

```
【主体与场景】
长颈龙把长长的脖子整个弯下来，头低到小果面前，两只眼睛和小果的眼睛**在同一高度**。
它的一只眼睛离她很近，睫毛与眼周的水彩能看清，**睫毛上沾着一小粒灰**（正文里点名的
那个细节，要小、要看得见、不显眼）；小果仰着头，鼻尖几乎要碰到它的鼻尖，
但**没有碰到**——中间还留着一条窄窄的缝。她的眼睛睁得很大，笑出梨涡。
背景是虚一点的蕨叶与雾，光柱落在两个脑袋之间。

【构图 · 开页跨页专用】
- 小果在**水平约 30%**，长颈龙的头在**水平约 40%**（**都在左页**，
  这样"一样高"的对照关系完整地留在左页上，翻到书上看是对着的一对）。
- 长颈龙的脖子从右页弯过来、跨过水平 50%，但那条脖子是**一条连续的长弧**，
  中央只许穿过脖子，不许把它的头压在中缝上。
- 两个脑袋的连线几乎水平，落在画面垂直约 46% 处；视觉重心垂直中线 ±5%。
- 左缘让蕨叶与雾延到画面外；右缘让脖子与背后的树干延到画面外。
- ★ 中央**不得有接缝**：那条跨过中央的长脖子必须粗细与深浅不变、连续不断
  （这一张最容易在中央断成两截）。
```

小果蹲在它旁边看得入神，两只手放在膝盖上，没有去摘；长颈龙把脖子弯下来，

一颗被放大的小东西，和两个安静的大身影。光柱落在花瓣上，那一点白是画面最亮的地方。

【构图 · 开页跨页专用】

### P6 · 跨页 6 `p6.webp`｜「软软的桥」

```
【主体与场景】
长颈龙把长长的脖子弯成一座缓坡一样的桥：脖子从身体肩部伸出来，以一道**平滑上扬的弧**
直接连到头部，像天鹅或长颈鹿的脖子那样自然上弯——中间不碰落叶层，
长颈龙的头就落在这道弧的末端，回头看着小果。
弧线又圆又软，看上去一点也不陡。小果正踩在这条"桥"上往上走，一只手扶着，
一只脚抬起来、踩在下一道弧上，回头朝画外笑了一下——是"我在上面啦"的那一拍。
脖子上的皮肤被踩出浅浅的凹陷（**看得出来是软的**），被她踩过的地方有一条浅浅的痕。
阳光从左上照进来，把脖子的上缘染成暖金色。

【构图 · 开页跨页专用】
- 小果在**水平约 30%、垂直约 44%**（整块在左页）。
- 长颈龙的身体在**左缘**（约占左侧三分之一）：厚实身躯、圆斑背脊、浅色肚皮、
  两条粗短的腿站在落叶层上——**身体必须在画面里，且体量压得住脖子**，
  否则整条脖子读起来像一根孤零零的管子（2026-10-16 用户定）。
- 脖子作为一条**平滑上扬的连续弧**：从身体肩部伸出、持续上扬连到头部，**中间不触地**
  （2026-10-16 用户定：不要"先深陷到地面再扬起"——那像滑梯/蛇，不像脖子；
  也不要长距离平趴）。整条脖子从根到尖逐渐变细；跨过中央那段仍须粗细与深浅不变、
  连续不断，中央线上不许出现任何折角、断口或明暗突变。
- 长颈龙的头在**水平约 60%、垂直约 25%**，回头看她。
  ★ **颈长以"可亲"为准，不要横跨大半个画面**（2026-10-16 用户定"脖子太长了"：
  从旧稿"伸到画面右上角"缩短约三分之一；再出此页按此长度，勿退回长颈版）。
- 视觉重心垂直中线 ±5%。

## 五、配音稿（一张图一段，共 8 段）

★ **念的必须就是下面【印的正文】，一个字都不许改**——屏上写的就是耳朵里听的
（理由见 [`demo-narration-script.md`](demo-narration-script.md) §一 第 1 条）。
记号：`／` 短停 0.4 秒 · `／／` 长停 1 秒 · **粗体**重音 · `——` 拖住别收。

| 文件     | 印的字数 | 目标时长   | 上限  |
| -------- | -------- | ---------- | ----- |
| `p1.mp3` | 49       | 15 秒      | 18 秒 |
| `p2.mp3` | 48       | 15 秒      | 18 秒 |
| `p3.mp3` | 49       | 15 秒      | 18 秒 |
| `p4.mp3` | 50       | 16 秒      | 19 秒 |
| `p5.mp3` | 57       | 18 秒      | 21 秒 |
| `p6.mp3` | 47       | 15 秒      | 18 秒 |
| `p7.mp3` | 56       | 18 秒      | 21 秒 |
| `p8.mp3` | 44       | 14 秒      | 17 秒 |
| **合计** | **400**  | **126 秒** | —     |

一本约 **2 分 6 秒**。★ 每段 18–21 秒上下，比"一段十来秒"的那种翻页节奏稳得多：
一段十五秒刚好是**孩子看完这一幅画**的时间，念完不用等，也不催。

封面与封底**不配音**：书还没打开，没有哪一页在念。

### P1 ·「走进林子」→ `p1.mp3`

```
清早，／ 小果顺着一条小路／ **走进林子**。／／
蕨叶比她高得多，／ 叶尖上挂着**露水**。／／
林子里很安静，／ 只听见她自己的**脚步**。／／
```

> 三段一层一层往里走：先"进了林子"，再"看见蕨叶与露水"，最后"听见安静"。
> 音量一句比一句轻 —— 这一页只有一件事：她进去了。

★ **这一段要重录**（2026-10-16 发现）：已交付的 `p1.mp3`（14.9 秒）念的是**长一版**的句子
（"走进了蕨叶搭成的林子"，第一行 23 字）。23 字超过「每行 ≤22 字」那条版面容量
（22 字是 19px 下正好一行的上限，超了会折行、把三行顶成四五行），**屏上印不下**，
所以以代码（也就是上面这一块）为准。重录照上面念即可，约 12–15 秒。
其余七段与代码逐字一致，不用动。

### P2 ·「好大一只」→ `p2.mp3`

```
林子中间，／ 站着一只**好大**的动物。／／
它正低头吃蕨叶，／ **一只脚就有她半个身子高**。／／
「你好呀。」／ 小果抬起头说。
```

> 「好大」要**真的放大**，「一只脚就有她半个身子高」再补一刀——大小关系是这一页的全部。
> 然后收回来念小果那句：高高的、轻轻的，像孩子对着一只比自己大十倍的东西说话。

### P3 ·「一样高」→ `p3.mp3`

```
它把**长长的脖子**，／ 慢慢慢慢地弯下来。／／
弯到眼睛和小果的眼睛**一样高**。／／
小果仰着头，／ 看见它睫毛上沾着**一粒灰**。／／
```

> 「慢慢慢慢地」是四个字踩四下——它弯得很慢，念快了这个动作就没了。
> 「一样高」放平、放慢，它是这一页唯一的画面事实；最后那粒灰是**孩子的视角**，别念得太清楚。

### P4 ·「它不走开」→ `p4.mp3`

```
它低下头，／ 朝她**摊开的手掌**轻轻喷了口气。／／
小果的刘海被吹起来一点点，／ 她**笑了**。／／
它身上有一股**晒过太阳**的味道。
```

> 最后一句是全书唯一一次出现"家里的味道"，**暖一点、慢一点**，念完停住。
> 它是"想象其实来自生活"的落点。

### P5 ·「一朵小白花」→ `p5.mp3`

```
蕨叶底下，／ 冒出来一朵**很小很小**的**五瓣**白花。／／
花瓣上有一粒露水，／ 是整片林子里**最亮**的地方。／／
小果蹲下来看，／ 两只手放在**膝盖上**。／／
```

> 「很小很小」要把音量收小，像怕把它吹跑；「最亮」再放出来一点。
> 最后一句的重点在「膝盖上」——手是放着的，**没有去摘**。这一层意思靠语气给，不要加词。

### P6 ·「软软的桥」→ `p6.mp3`

```
长颈龙把脖子弯成一座**软软的桥**。／／
小果踩着它往上走，／ 脚底下**陷下去一点点**。／／
她回头笑：／ 「我**在上面**啦。」／／
```

> 「陷下去一点点」要念得**有弹性**，像踩在一床被子上。
> 最后那句是喊过来的，可以从画外给一点距离感。

### P7 ·「上面有雾」→ `p7.mp3`

```
从**那么高**的地方往下看，／ 整片林子都变小了。／／
低处的雾一片一片，／ 光柱从雾里**穿过去**。／／
小果坐得**稳稳的**，／ 两只手撑着它的肩膀。／／
```

> 「那么高」往上抬一点，但**不能念出危险感**——画面下方一直看得见地面，声音也要落得下来。
> 「稳稳的」三个字是给大人听的安心话，放慢，别用力。

### P8 ·「明天还来」→ `p8.mp3`

```
它们一起看着那朵小白花，／ **谁也没有动**。／／
又有一两片蕨叶，／ 慢慢慢慢地落下来。／／
小果想：／ **明天还来**。／／
```

> 全篇最静的一段。最后四个字**几乎不用力气**，念完停住，不要再补一句。
> 这一页是睡前那一拍，念到这儿孩子差不多就睡了。
