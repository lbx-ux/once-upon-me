## 一、这本书

★ **这一本的落点不在"小鸟可爱"，在那个动作上：手是摊平的。**
`bird.ts` 文件头写死了这一条——**不掏鸟窝、不抓鸟、不握紧**；
八张图里孩子的手**始终是摊平的**，小鸟**始终是自己走过来的**。
所以这一本最容易画错的**不是**构图，而是**手**：一只手蜷起来兜住鸟，这本书就教错了动作，
画得再好看也没用。§四 每一条里都单独立了一段【手】，就是这一条。

### 主角锚点 · 豆豆（封面与八张跨页**一字不改**）

```
豆豆，约 5 岁的东亚小孩：乌黑的短发，额前一层碎刘海，发梢有点翘；
圆脸、深棕色的大眼睛、眼距略宽；笑起来眼睛先弯；鼻子一个小圆点，嘴小。
穿**米白色长袖上衣**（胸前没有任何图案）＋**浅绿色小背心**，深蓝色长裤；光着脚。
身高约 4 个头身，手脚圆润短小；**手掌摊平时五指是并拢摊平的，不是蜷起来的**。
以上任何一项都不得改动：不换发型、不换发色、不换衣服颜色、不长高、不穿鞋。
```

★ **这本书不强调性别**（`cover-art-prompts.md` §五 那条：小鸟、云、鲸鱼、乌龟都不作性别强调）：
发型与衣服上**不许有任何性别标记**——不画耳环、不画蝴蝶结、不画卡通图案、不画"男孩样/女孩样"的版型。
但**正文里用的是「他」**（`bird.ts` 已交付，§五 逐字照念，别为了图改字）。

### 小鸟锚点 · 那只雏鸟（P2 起出现，同一只）

```
一只刚出窝的雏鸟，麻雀或山雀一类：**灰褐色的背与翅膀、浅米色的胸口与肚子**，
短短的尖喙、圆而黑亮的眼睛、**尾巴很短**，头顶与背上还翘着一层没褪干净的绒毛。
两条细腿、三只前趾一张后趾的小爪子。**体型约一个鸡蛋大**（跟掌心那几粒米比一比就知道）。
★ 它**不是**小鸡：不许画成黄色的、圆滚滚的小鸡崽，不许有橙色的大脚掌；
也**不是**鹦鹉、文鸟或任何卡通鸟，不许有冠、有长尾羽、有彩色斑纹。
```

### 鸟妈妈锚点 · 鸟妈妈（**只在 P7、P8 入画**）

```
同一**种**鸟的成鸟：与那只雏鸟**同色系**（灰褐的背、浅米色的胸），但**大一号**、
羽毛收得平整干净、尾巴比雏鸟长一点，眼睛黑亮、神情安静。
★ 站在**低枝**上看着，**嘴上什么都不衔**（不衔虫、不衔草、不衔食物）——它是来看，不是来喂的。
```

★ 鸟妈妈**P1–P6 一次都不许出现**，连远处树上的一个小黑点都不给。
它第一次露面是 P7 那一拍（正文「低枝上，鸟妈妈安安静静地看着」是新信息）；
如果前面几张就有它，P7 就没事了。

### 场景基调

**春日午后，一棵大树底下的草地**：豆豆盘腿坐在树荫的边缘，
一块从树叶缝里漏下来的光斑落在他手背上；四周是浅绿的草、几片飘落的叶子、
树根隆起的一小块；头顶是一条**低低横伸出来的粗枝**（P7 起鸟妈妈落在那上面）。
**没有公园长椅、没有垃圾桶、没有健身器材、没有鸟食袋、没有任何带字的物件。**

★ **画面里永远没有鸟窝**（连树洞里露出一角草都不许）——这一条是"不掏鸟窝"的另一半：
观众看见鸟窝，就会等着孩子去掏它。★ 也**不许有第二只以上的鸟群**：全篇只有这两只鸟。

### 那棵树（八张里是同一棵，别换地方）

```
树干在**水平约 74%–88%**（整块在右页），树皮是灰褐色、有竖向的浅裂纹；
一条**低枝**从右上角斜伸进来，占**水平约 58%–94%、垂直约 10%–24%**——
★ 这条枝**不要跨过水平 50% 的中缝**（它整个待在右页，省得 ② 那把尺子把它报成折痕）。
```

### P2 · 跨页 2 `p2.webp`｜「一只小鸟」

```
还是那一块树荫。草地上，**一只灰褐色的雏鸟落在离豆豆两步远的地方**——
```

### P1 ·「一动不动」→ `p1.m4a`

```
大树底下，／ 豆豆盘着腿坐在草地上。／／
他**一动不动**，／ 连手指头也没有动一下。／／
风把树叶吹得**沙沙**响。／／
```

> 三句三个信息：地方、人、风。最后一句放轻、放慢——那是这本书的**底色**（安静）。
> ★ 别在"沙沙"上玩声音效果，念成真的听见了就行。

### P2 ·「一只小鸟」→ `p2.m4a`

```
一只小鸟落在草地上，／ 离他**只有两步远**。／／
它还不太会飞，／ 翅膀**一开一合**。／／
豆豆屏住了呼吸，／ 一动也不动。／／
```

> "只有两步远"念得要**具体**（真的两步），不要念成"很近"。
> 最后一句**声音压下去**，像怕说大了把它吓跑——这一句是这一页的全部。

### P3 ·「摊开手掌」→ `p3.m4a`

```
豆豆慢慢把手掌**摊平**，／ 放在膝盖上。／／
掌心里放了几粒米，／ 白白的**一小撮**。／／
他没有伸手，／ 也没有出声。／／
```

> 这一句是这本书的**动作说明**，"摊平"两个字要**慢、清楚**。
> "没有伸手，也没有出声"两个短句一顿一顿地念，像在数他**忍住**的两件事。


### P5 ·「等一下」→ `p5.m4a`

```
豆豆就等着，／ **一动不动**地等着。／／
太阳从树叶的缝里漏下来，／ 落在他**手背上**。／／
小鸟又往前**跳了一下**。／／
```

> 最静的一段：整段的速度放到全书**最慢**，中间那一句"漏下来"要**很轻**。
> ★ 这一页别加任何情绪——它是"等"本身，念得平，画里才有时间过。

### P6 ·「啄了一下」→ `p6.m4a`

```
小鸟跳到他手心里，／ 轻轻**啄了一下**。／／
有点痒，／ 像被一根草**挠了挠**。／／
豆豆没敢笑，／ 怕把它**吓跑了**。／／
```

> 这一页可以**暖起来一点点**（终于来了）。"啄了一下"轻，"挠了挠"稍微扬。
> 最后两句要念出**忍着**的那股劲儿——但**不许笑场**。

### P7 ·「妈妈在看着」→ `p7.m4a`

```
低枝上，／ 鸟妈妈**安安静静**地看着。／／
它没有叫，／ 只是把翅膀**收拢了一点点**。／／
豆豆也朝它**点了点头**。／／
```

> 这一页的语气是**放心**，不是警惕。"安安静静"念得稳；"收拢了一点点"要**小**、要**轻**。
> 最后一句念得像两个人（一人一鸟）互相明白了一下。★ 别念成"感动"。

### P8 ·「飞走了」→ `p8.m4a`

```
小鸟吃饱了，／ **扑棱棱**飞回树上。／／
它落在鸟妈妈旁边，／ 抖了抖身上的**羽毛**。／／
豆豆把手掌**一直摊到最后**。／／
```

> "扑棱棱"三个字**短、有动感**，是全书唯一一处有声音形状的词；后面两句一句比一句轻。
> 最后一句是**整本书的收**：**慢、轻**，"最后"两个字落地之后就别再加东西——
> **留满 1 秒再停**。
