## 一、这本书

★ **这本书不开花。** 全书的落点是"等"（`flower.ts`：埋下去的那颗种子，在土里悄悄忙着呢），
所以八张图里**主角那个盆从头到尾只有那个绿点**——两片卷在一起的小叶子，
到 P8 也只是"还卷着的两片"。
★ **不许**在最后一张给他开一朵花、不许出现花苞、不许"明显长大了"。
旁边**别的盆**里可以有一排在开的小花（那是奶奶早先种的，`cover-art-prompts.md` 说好了），
★ 但那些花与主角这个盆**不是一回事**：主角的盆里**始终只有那一个绿点**。

★ **成人只有奶奶一个**（祖辈在整组 12 本里只出现在这一本，也是这一本的分量所在）。
★ 还有一条**动作上的**约束：奶奶的手**从不指点、不抓孩子的手腕**——
P8 那一拍她的手掌是**扶在小苗的手背上**的（不是握着、不是替他把着）。
这一条与「小鸟」那本的"手掌摊平"同一类：**画面里的动作本身就是这本书要教的东西**。

★ **P3 是这一本的诚实处**：正文说的是"一天，两天，三天，盆里还是安安静静的一盆土"。
★ 这一页**什么都不能多**——盆里就是土，连一点绿意都不许偷偷加上。
"等"这件事在这本书里是要**看得见地什么都没发生**。

### 主角锚点 · 小苗（封面与八张跨页**一字不改**）

```
小苗，约 5 岁的东亚小孩：乌黑的短发（齐耳，发梢自然垂着、不扎起来），
圆脸、深棕色的大眼睛、眼距略宽；笑起来眼睛先弯；鼻子一个小圆点，嘴小。
穿**米白色的长袖上衣**（胸前没有任何图案）＋一条**浅蓝色的小围裙**
（围裙上**没有一个字、没有一个图案**）；深蓝色的长裤；一双**素色的小袜子**。
身高约 4 个头身，手脚圆润短小。
以上任何一项都不得改动：不换发型、不换发色、不换衣服颜色、不长高、不换袜子。
```

### 奶奶锚点 · 奶奶（这本书里唯一的成人，八张都在）

```
奶奶，约 70 岁的东亚女性：头发**花白**、在脑后挽一个低低的髻，几缕碎发落在鬓角；
额头与眼角有细细的纹路，眼睛很亮、看着东西的时候很专注；嘴角有一点自然的上扬。
穿一件**浅灰色的对襟上衣**（中式立领、前襟有素色的盘扣——★ 衣上一个字都没有）
与深色的长裤；脚上一双**素色的布鞋**。
她的手背有细细的纹路、指节略粗（做惯了活的手）。
★ 她在整本书里只做两件事：**弄土**与**浇水**——姿态安静、不指点、不催促；
★ 她的手**从不指着孩子、从不抓孩子的手腕**（P8 是**扶在手背上**）。
```

### 道具锚点（八张里同样东西，位置可动、样子不许变）

```
主角花盆：一个**赤褐色的素面陶土盆**（盆沿圆润、有一点点用旧了的磕痕），
　　　　　盆里是深褐色的松土。★ 盆身上**没有一个字、没有图案、没有贴纸**。

　　　　★ 壶上没有一个字；★ 对小苗来说**有点沉**（他要两只手才提得动）。

旁边那一排花：三四个**别的陶土盆**（与主角盆同款但大小不一），里面是几株**在开的小花**

```

### 场景基调

**春日上午的阳台**：地面是浅色的水磨石/瓷砖（有一点点旧的纹理），
一道**斜斜的阳光**从左上照进来，在花盆与地板上落下一块亮斑；
阳台有一排矮矮的栏杆，栏杆外面是**模糊的远景**（只给一点点树影与天光，不给细节）；
栏杆下沿搁着几个空的小陶盆。
**没有晾晒的衣服、没有洗衣机、没有扫帚拖把、没有花肥袋子、没有任何带字的物件。**

【构图】

### P1 ·「埋一颗种子」→ `p1.m4a`

```
奶奶把一颗小小的种子，／ 埋进陶土盆里。／／
土是松松的，／ 用手指一按就是**一个小坑**。／／
小苗蹲在旁边，／ 看得**认真**。／／
```

> 三句是三个动作：埋、按、看。前两句念得**轻**（都是手上的小动作），
> 最后"认真"两个字要放慢——那是这一页的表情。

### P2 ·「每天浇水」→ `p2.m4a`

```
小苗每天来浇一次水，／ 一次只浇**一点点**。／／
喷水壶很沉，／ 他要**两只手**才提得动。／／
壶嘴里出来的水，／ **细细的**。／／
```

> "一点点""两只手""细细的"——这一整页都在说"小"。★ 念的时候要**收着**，
> 尤其是"很沉"：不是辛苦，是"他还小"。

### P3 ·「土还是土」→ `p3.m4a`

```
一天，／ 两天，／ 三天，／ 盆里还是安安静静的一盆土。／／
没有绿，／ 也没有一点点动静。／／
小苗把脸凑近去看。／／
```

> ★ "一天，两天，三天"要**一天一停**（每个数之间停够），念完"三天"再停一下，
> 然后平铺直叙地念"盆里还是安安静静的一盆土"——**别把这句话念出失落**，
> 它只是事实。最后一句要轻，像脸真的凑过去了。

### P4 ·「它睡着了？」→ `p4.m4a`

```
小苗小声问：「奶奶，它是不是睡着了？」／／
奶奶把手上的土拍干净，／ 笑了笑。／／
「它在下面忙着呢。」／／
```

> 问句要**小声、当真**（他是真的在问）。中间那句是动作，念得慢一点。
> 最后那句是奶奶的**第一句**：★ 短、稳、带一点点笑意——**不许拖长音、不许上扬**，
> 它是一句实话，不是哄。

### P5 ·「下面忙着呢」→ `p5.m4a`

```
「先长根，再长叶，急不来的。」／／
奶奶说，／ 根要在土里**绕好几圈**。／／
小苗听完，／ 又给它浇了一点点水。／／
```

> 奶奶这句话要念得像**在说一件她亲眼见过的事**（节奏稳，"急不来的"四个字轻轻落地）。
> "绕好几圈"要慢、要有画面感。最后一句放轻、放暖，是孩子听完之后的反应。

### P6 ·「一个绿点」→ `p6.m4a`

```
今天早上，／ 土里冒出来一个小小的**绿点**。／／
两片叶子卷在一起，／ 还没有打开。／／
「奶奶！快来看！」／／
```

> ★ 前两句**不许激动**（"一个小小的绿点"要念得**小**）；
> 最后那句才是这一页唯一的"大声"——它是**喊**的，但要短（两个字的重音就够了），
> 喊完立刻收住，像孩子喊完就跑了。

### P7 ·「一起蹲下来」→ `p7.m4a`

```
奶奶和小苗一起蹲下来看，／ 谁也没出声。／／
阳光落在那一小块新绿上，／ **亮亮的**。／／
风一吹，／ 它晃了一下。／／
```

> 整段是**最静的一页**：速度放到全书最慢，"谁也没出声"之后要停够。
> 最后"晃了一下"要轻得像真的只是晃了一下——念完留半秒。

### P8 ·「扶着手背」→ `p8.m4a`

```
奶奶的手扶着小苗的手背，／ 一起浇水。／／
最后一点水，／ **慢慢地**渗进土里。／／
「我们一起等它开花。」／／
```

> "扶着手背""一起"要念得**平**（不是感人，是自然）。
> "慢慢地"三个字拖住，让水真的渗进去。最后那句奶奶的话是**全书的落点**：
> ★ 念得**慢、稳、不带期许的语气**——她说的是一件**将要发生的平常事**。
> 念完**留满 1 秒**再停。
