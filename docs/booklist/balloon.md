## 一、这本书

★ **这一本只有一个动作，而它的方向不能画反**（`balloon.ts` 文件头写死）：
**递出去**，不是抢。所以：

1. ★ **气球的线永远是"从拿着气球的那个人这一侧，指向没气球的那个人那一侧"**——
   P1–P4 红线在小灯手里；P5 那一下是**线正在从一只手交到另一只手里**；
   **P6 起红线在小妹妹手里**。★ 线的方向反了，这一页就读成"抢"。
2. ★ **没有人在哭、没有人在抢、没有人松手**。全篇的情绪是**平的、暖的**，
   一个孩子把东西给别人，**不是牺牲**，也不需要谁夸他（所以**没有人鼓掌、没有大人点头**）。
3. ★ **气球不许飞走**：每一只气球的线上都有一只小手（P5 那一下是两只手同时在线上）。

★ **数得出来，是这本书的诚实处**：孩子数得清气球，才看得出"他给出去了一只"。
所以下面状态表里把**气球数写死了**：
**P1–P6 画面里正好三只（红、黄、绿）**——这三色就是正文写死的那三色；
**P7–P8 正好七只**（新来的孩子又带来了四只：蓝、紫、橙、粉）。

小灯，约 5 岁的东亚男孩：乌黑的短发（短、不遮耳），圆脸、深棕色的大眼睛、眼距略宽；
笑起来眼睛先弯；鼻子一个小圆点，嘴小。
穿**浅蓝色的短袖 T 恤**（胸前没有任何图案）与**深蓝色的短裤**；

★ 前四页他手里牵着一根**红气球**的线（线绕在食指上）。

所以念的人要像**站在草地边上看着、什么都不评价的那个人**：
句子之间留得住，★ **"给你"这两个字尤其不许重**（重了就成了"他好乖"）。

P8 最后一句（"红的已经在别人手里了"）念得**平**——★ 不许念成感慨、
★ 不许念出留恋，它是这一本最轻的收尾。念完留满 1 秒再停。

### P1 ·「每人一只」→ `p1.m4a`

```
公园的草地上，／ 每个孩子手里都有**一只气球**。／／
红的、黄的、绿的，／ **一根线一只**。／／
小灯手里那只，／ 是**红的**。／／
```

> 前两句是交代，"红的、黄的、绿的"要**一个一个念过去**（像数过）。
> 最后一句平铺直叙——★ 平平地落下"是红的"，这一本后面所有的事都从这只红的开始。

### P2 ·「只有她空着手」→ `p2.m4a`

```
只有一个小妹妹空着两只手，／ 站在旁边看。／／
她不说话，／ 只把两只手**背在身后**。／／
她看起来比小灯**矮一个头**。／／
```

> ★ "空着两只手"要念得**不心疼**（这一句最容易念出同情，别）。
> "背在身后"要轻。最后一句要有那种"确实矮一点"的平常观察。

### P3 ·「低头看看」→ `p3.m4a`

```
小灯低头，／ 看了看自己手里那只**红气球**。／／
线在他手指上绕了两圈，／ 缠得**有点紧**。／／
他把线解开来。／／
```

> 前两句是**看**（慢、轻）。"绕了两圈""有点紧"要念得像真的在解一根线。
> 最后一句短促、干脆——解开了就不再多说。

### P4 ·「走了三步」→ `p4.m4a`

```
他朝着小妹妹走过去，／ **一步一步地**走。／／
第一步有点慢，／ 第三步**快了一点**。／／
他站到她面前，／ 停了下来。／／
```

> 前两句是脚步的节奏（"一步一步"要分开念）。★ 最后一句要**真的停一下**——
> 那个停顿就是"站到她面前"这一下的重量，也是全书最要紧的一秒。

### P5 ·「给你」→ `p5.m4a`

```
「这个给你。」小灯把气球线递了过去。／／
小妹妹抬起头，／ 先看了看他，／ 又看了看气球。／／
她的两只手，／ **慢慢**从背后拿了出来。／／
```

> ★ 台词念得**短、平、随口**（★ 不许温柔、不许带笑、不许加重"给你"）。
> 中间那一句的"先看了他，又看了看气球"要念出**顺序**（真的先看他）。
> 最后"慢慢从背后拿出来"是这一页的动作，念得慢、轻，念完留半秒。

### P6 ·「飘了一点」→ `p6.m4a`

```
小妹妹抓住线，／ 气球轻轻地**往上飘了一点**。／／
她笑了，／ 笑得眼睛**弯起来**。／／
小灯站在旁边，／ 也跟着笑了。／／
```

> 这一页可以**暖起来、快一点**（终于接住了）。
> "往上飘了一点"要念得轻，像线在手里轻轻一扯。最后两句都是笑，念得短一点、松一点。

### P7 ·「凑在一起」→ `p7.m4a`

```
别的小朋友也围了过来，／ 气球**凑在一起**。／／
七只气球挤在一块，／ **谁也没有松手**。／／
有个孩子说：「我们的最高。」／／
```

> "凑在一起""挤在一块"要念得**热闹**一点（这是全书最热闹的一页）。
> ★ "谁也没有松手"要念得**稳**（它是这一页的安心处）。最后那句台词是孩子随口比的，念得**短、俏**。

### P8 ·「一片彩色的天」→ `p8.m4a`

```
大家一起抬头看，／ 脖子都仰得**酸了**。／／
那几只气球飘在绿树上面，／ 像一小片**彩色的天**。／／
小灯想：／ 红的**已经在别人手里了**。／／
```

> 前两句是仰头看的那一下（"脖子都仰得酸了"可以微微带一点好笑）。
> ★ 最后一句是**全书的收**：念得**淡、平、轻**——他只是想了一下，
> **不是舍不得、不是懂事**。念完**留满 1 秒**再停。
