## 一、这本书

### 主角锚点 · 囡囡（封面与八张跨页**一字不改**）

```
囡囡，约 5 岁的东亚小女孩：齐耳短发，额前一排整齐的刘海；圆脸，
深棕色的大眼睛、又大又亮；穿月白色的小睡衣，袖口有一圈淡蓝的边。
怀里总搂着一只旧玩偶熊（锚点见下）。
身高约 4 个头身，手脚圆润短小。
以上任何一项都不得改动：不换发型、不换发色、不换睡衣颜色、不长高、不换熊。
```

### 妈妈锚点 · 妈妈（同一人，八张跨页**一字不改**）

```
囡囡的妈妈，三十岁上下：深棕色的长发松松地挽在脑后，几缕碎发垂在耳边；
穿浅米色的家居服，袖口松松地挽起；神情温和，嘴角总带一点笑。
她是本书设定里的第二位主角，坐在床边的小凳上念书。
以上不得改动：不换发型、不换家居服、不画成背影之外的样子。
```

### 玩偶熊锚点 · 它（同一只，八张跨页**一字不改**）

```
一只旧的浅棕色玩偶熊：比囡囡的头大一圈，圆耳朵、圆肚子，缝线的眼睛；
**右边的耳朵磨得发白**（正文里点名了它，九张里都要看得见）。
它不是新玩具：绒毛压得有点塌，是一被抱了很多年的样子。
```

### 场景基调

夜晚的儿童卧室：月白与浅蓝的夜色，窗帘拉着，缝里漏进一线月光；
床头小夜灯是一盏**月亮形状**的小夜灯，亮着暖橘的光——它是每一张里**唯一的暖色重音**，
在床头墙上照出一块**月亮形状**的光斑（每一张都在，形状不变）。
被子是米白色的，"晒过太阳的暖意"靠灯光照出来，**不靠被子的颜色**。
床头柜上有一本合上的绘本和一杯水；地面一小块地毯。
**没有屏幕、没有现代电子玩具**；房间安静、不拥挤。

### 共用段的替换（**只有这一本用**，§四 的【风格】与【约束】都要带上）

总纲 §二 那两段共用文字里，**只有这两句换掉**，其余一字不改：

```
「统一光源来自左上方，色温暖白。」替换为：
  夜晚的卧室有两处光：床头月亮形小夜灯的暖橘（画面里唯一的暖色重音，光从床头一侧来），
  与窗帘缝里进来的月白。夜色一律是月白与浅蓝，不许深黑、不许压暗到看不清脸——
  每一张里囡囡脸上的细节都要看得清。

「不要第二个孩子（除本书设定里写明的那一位），也不要成人的手或身体入画。」替换为：
  不要第二个孩子，也不要除妈妈以外的任何成人入画；
  妈妈是本书设定里的第二位主角，她的手只在翻书与掖被角时出现。
```

### P1 · 跨页 1 `p1.webp`｜「钻进被窝」

```
【主体与场景】
洗好澡的囡囡钻在被窝里，只露出一个脑袋，齐耳的刘海还带着一点洗过的湿意（不要滴水）；
她拍拍枕头，眼睛望着房门的方向——是"等着妈妈进来"的那一拍。
被窝从画面左侧铺进来，被子蓬松，米白色；床头的月亮形小夜灯亮着暖橘的光。
情绪：安静、满足、一点点期待。

【构图 · 开页跨页专用】
- 画面水平 50% 处是书脊：囡囡的脑袋在**水平约 34%、垂直约 52%**（整块在左页）；
  月亮形小夜灯在床头柜上**水平约 80%、垂直约 55%**（右页）；
  墙上那块月亮形光斑在**水平约 62%、垂直约 30%**（每一张都在，形状不变）。
- ★ 囡囡的脸与身体主干不得进入水平 46%–54%。这一条优先于"画面居中"这个默认构图习惯。
- 视觉重心落在画面垂直中线 ±5% 内。
- ★ 左右两缘要**画满**、不许留白：左缘让被子与床沿一直延到画面外，
  右缘让床头柜与窗帘贴住边；两缘的夜色都要有月白的水彩颗粒。
- ★ 中央**不得有接缝**：被子与床沿铺过水平 50% 的那一段必须连续，
  不许出现竖向折痕或明暗突变。
- 平视、略低机位。
```

### P2 · 跨页 2 `p2.webp`｜「读哪一本」


### P3 · 跨页 3 `p3.webp`｜「书里的月亮」

```
【主体与场景】
翻开的那本绘本摊在被子上，书页上画着一轮又圆又亮的月亮，挂在山坡上——
**是绘本里的画**，要画得像一本小孩绘本里的插图，不是写实月亮。
囡囡趴在床沿，伸出一根手指，轻轻摸了摸纸上的月亮；

【构图 · 开页跨页专用】

  她的手指从书页下缘伸上来，指尖在**水平约 33%**。

- 视觉重心垂直中线 ±5%。
- 左缘让囡囡与枕头延到画面外；右缘让被子与墙上那块光斑的边缘延到画面外。
- ★ 中央**不得有接缝**。
```

## 五、配音稿（一张图一段，共 8 段）

★ **念的必须就是下面【印的正文】，一个字都不许改**——屏上写的就是耳朵里听的
（理由见 [`demo-narration-script.md`](../demo-narration-script.md) §一 第 1 条）。
记号：`／` 短停 0.4 秒 · `／／` 长停 1 秒 · **粗体**重音 · `——` 拖住别收。

| 文件     | 印的字数 | 目标时长   | 上限  |
| -------- | -------- | ---------- | ----- |
| `p1.m4a` | 47       | 15 秒      | 18 秒 |
| `p2.m4a` | 43       | 14 秒      | 17 秒 |
| `p3.m4a` | 50       | 16 秒      | 19 秒 |
| `p4.m4a` | 52       | 17 秒      | 20 秒 |
| `p5.m4a` | 45       | 15 秒      | 18 秒 |
| `p6.m4a` | 46       | 15 秒      | 18 秒 |
| `p7.m4a` | 49       | 16 秒      | 19 秒 |
| `p8.m4a` | 42       | 14 秒      | 17 秒 |
| **合计** | **374**  | **122 秒** | —     |

一本约 **2 分 2 秒**。★ 这一本比 dino 那本更轻：整体音量再收小一档，
最后三页几乎是对着睡着的人念的——声音是这一本的主角。

封面与封底**不配音**：书还没打开，没有哪一页在念。

### P1 ·「钻进被窝」→ `p1.m4a`

```
洗好澡，／ 囡囡钻进被窝，／ 只露出一个**脑袋**。／／
被子**晒过**，／ 闻起来有**太阳的味道**。／／
她拍拍枕头，／ 等着妈妈进来。／／
```

> 三句一层一层安静下来：先"钻进被窝"，再"太阳的味道"，最后"等着"。
> 音量一句比一句轻——这一页只有一件事：她准备好了。

### P2 ·「读哪一本」→ `p2.m4a`

```
「妈妈，／ 今天读哪一本呀？」
妈妈从床头拿起一本，／ 坐在床边的**小凳**上。
书页翻过去，／ **沙**的一声。
```

> 那句问话是撒娇的、拖着尾音的；「沙的一声」要念得**很轻很轻**，
> 像真的翻了一页——声音是这一页的道具。

### P3 ·「书里的月亮」→ `p3.m4a`

```
书里画着一轮月亮，／ **又圆又亮**，／ 挂在山坡上。／／
囡囡伸出一根手指，／ **摸了摸**纸上的月亮。
纸是滑滑的，／ **一点也不烫**。
```

> 「摸了摸」放慢，手指真的落下去了；「一点也不烫」是小孩子认真的发现，
> 念出一点小小的得意，不要笑场。

### P4 ·「墙上的光」→ `p4.m4a`

```
床头的小夜灯，／ 在墙上照出一块**月亮形状**的光。
囡囡把玩偶熊举起来，／ 让月亮落在它头上。
「它也有一顶**月亮帽子**。」
```

> 「月亮帽子」是这一页的笑点，念出一点骄傲；最后那句是孩子的悄悄话，
> 音量收小，像怕把光吹灭。

### P5 ·「搂紧一点」→ `p5.m4a`

```
囡囡把那只旧玩偶熊／ 往怀里**搂紧**了一点。
熊的一只耳朵／ 已经**磨得发白**。
妈妈说：／ 它陪你睡了好多年啦。
```

> 「磨得发白」放慢——旧的东西要有旧的声音；妈妈那句话要**暖**，
> 念完停住，不要接下一页。

### P6 ·「月亮回家了」→ `p6.m4a`

```
妈妈轻轻地念：／ 「**月亮**，回家啦。」
声音越来越轻，／ 像风从窗帘边走过。
囡囡的眼睛，／ **慢慢慢慢地**合上。
```

> 全书最轻的一页。「月亮，回家啦」几乎是对月亮说的悄悄话；
> 「慢慢慢慢地」五个字踩五下，越念越轻——眼睛合上，声音也合上。

### P7 ·「眼睛慢了」→ `p7.m4a`

```
囡囡还想再听一页，／ 可是眼睛**不听话**了。
她含含糊糊地说：／ 「再……一页。」
妈妈「嗯」了一声，／ 又翻了一页。
```

> 「再……一页」要念得含含糊糊、眼皮打架的声音，省略号真的拖住；
> 妈妈那声「嗯」要**软**，一个字就够。

### P8 ·「晚安」→ `p8.m4a`

```
妈妈关上大灯，／ 只留床头那一盏**小的**。
那块月亮形状的光，／ 还**安安稳稳**地贴在墙上。
「晚安。」
```

> 最后一段几乎不用力气。「晚安」两个字念完就停，**不要再补一句**——
> 这一页是睡着的，声音落在光斑上。
