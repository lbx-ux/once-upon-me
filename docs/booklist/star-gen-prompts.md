# 《等星星亮起来》(star) · 出图提示词包

> 用途：本文件是 `star` 这本样书的 **9 张出图提示词**（封面 `cover` + 跨页 `p1`–`p8`），
> 供接入任意文本生图工具（GPT-Image2 / Midjourney / miora 等）后一次性出图使用。
> 出图后请用 `scripts/make-webp.py` 转 WebP（见 `scripts/gen-star-webp.sh`）。
>
> 每个提示词都是 **自包含** 的：风格段、负面清单、三条硬约束、角色锚点都已内联，
> 直接整段复制即可。比例与落盘命名见文末「出图与落盘」。

---

## 共用基底（每一张都内联了它的压缩版）

- **风格**：温暖手绘绘本风。水彩铺色 + 细彩铅轮廓，可见纸质纹理，笔触松弛但不潦草。高明度、低饱和粉彩，每图只一个暖色重音。柔和无硬边阴影。统一左上暖白光源。与同系列 12 张封面同一画师、同一套颜料。
- **负面清单**：不要任何文字/字母/数字/水印/签名/Logo/品牌/卡通 IP/商品包装；不要恐怖、阴森、暴力、哭泣、被冷落孤单的形象；不要写实人脸；不要深色压抑、赛博朋克、霓虹、高饱和撞色；不要杂乱背景、多格分镜、拼贴、样机、画框或阴影底板；不要画成「一本打开的书」（无书脊/纸边/桌面/底板）；不要真实品牌物件、屏幕、手机、玩具广告；不要第二个孩子，也不要成人的手或身体入画（本书写明的爸爸局部除外）。
- **三条硬约束**：① 满版出血——画面四边到最外缘每个像素都画满景物（天空/草/物一直画到边），无白边、无画框、无渐隐到白，边缘要有水彩颗粒；② 一张连续画面——水平 50% 处不得有任何竖向接缝/折痕/装订沟/分格线，左右两半无缝拼合；③ 主体（孩子的脸与身体主干，以及爸爸的侧脸/肩膀）不得落在水平 46%–54% 这条书脊带上（每张都写死主体水平位置）。
- **角色 · 小禾**：约 5 岁东亚小女孩，乌黑短发齐耳（自然垂、不扎），圆脸、深棕大眼、眼距略宽，小圆点鼻、小嘴，约 4 头身、手足圆润短小。穿**米白长袖上衣**（无图案/无字）与深蓝长裤、素色袜子。
- **角色 · 爸爸**：约 35 岁东亚男性，黑短发、发际线干净，温和四分之三侧脸、下巴一点短胡渣；穿浅灰长袖家居上衣（无图案）与深灰长裤。**绝不给正脸**——最多四分之三侧脸（被毯子/孩子脑袋/肩膀挡掉一部分）再加手臂手部。他只做三件事：搬躺椅、裹好毯子、伸手让孩子靠。
- **本书基调**：这是**黄昏不是深夜**，整组保持**浅色调**——天是橘粉→浅紫→淡蓝的渐变，只有 P7 之后星星才渐渐多。任何一张都不许黑到要开灯。**星星是小亮点**（亮心带柔光，大小疏密不一），绝不是五角星、绝不加星芒、绝不连成星座、绝不大月亮。

## 封面 `cover` · 竖版 2:3（出图后脚本裁到 3:4）

```
儿童绘本竖版封面插画，一张完整画面，不是拼贴、不是多格分镜、不是书的样机。

【风格】温暖手绘绘本风；水彩铺色 + 细彩铅轮廓，可见纸质纹理，笔触松弛不潦草；高明度低饱和粉彩，每图一个暖色重音；柔和无硬边阴影；左上暖白光源；与同系列 12 张封面同一画师同一套颜料。

【场景】黄昏的院子里，小禾和爸爸裹在**同一条红白格纹毯**里，肩挨肩坐在木框帆布躺椅上，只露出两个脑袋。小禾仰着头、伸出一根手指指向上偏左的天空；爸爸顺着她的手指往上看（只给四分之三侧脸、被毯子挡掉一部分）。天上是橘粉到浅紫的黄昏色，最上面那一颗星刚刚亮起（只有一颗，很小很亮）。躺椅旁矮桌上放着两个素色陶瓷杯，杯口淡淡热气。栅栏外是几棵树剪影与远处居民楼轮廓，楼上窗一块一块亮着暖黄。

【构图 · 竖版封面】竖构图：两个人与躺椅占画面中央偏下，毯子以下约占 55% 高度；小禾脑袋在左、爸爸脑袋在右，两脑袋靠在一起。小禾的脸在画面垂直约 46%；那颗星在垂直约 12%、水平约 44%（星星与小禾眼睛间留一条干净空白让“看”成立）。两人离上下边各留 8% 余地、左右各留 8%。画面四周铺满出血：天、树影、草地一直画到最外缘每个像素，四边无白边、无画框、无渐隐到白。整幅是一张连续画面，不许出现任何竖向分格线或纸张边缘。天上渐变不许在画面中央出现一条竖直色带或明暗分界。

【人物】小禾：约5岁东亚小女孩，乌黑短发齐耳，圆脸深棕大眼，小圆点鼻小嘴，4头身，穿米白长袖上衣（无图案）深蓝长裤素色袜。爸爸：约35岁东亚男性，黑短发，四分之三侧脸（被毯子挡掉一部分）下巴短胡渣，浅灰长袖上衣深灰长裤；绝不给正脸。

【文字】画面内不出现任何文字、字母、数字、签名、水印（书名由前端叠字）。

【约束】这是黄昏：天要亮要浅，不许深夜、不许满天星、不许月亮；天上只有那一颗星，是小亮点不是五角星、不加星芒；爸爸不给正脸；躺椅、毯子、陶瓷杯上没有一个字。
```

【构图 · 开页跨页】画面水平 50% 处是书脊：小禾在水平约 26%（整块在左页，坐小躺椅上）；两把躺椅占水平约 20%–46%（小的）与约 56%–84%（大的）——中央约 46%–56% 留一段空草地，中缝上只有草地、草影与栅栏。小禾的脸与身体主干不进 46%–54%；爸爸也一样，爸爸在水平约 62%–72%（整块在右页，侧身弯腰搭毯子，不给正脸）。左右两缘画满不许留白：左缘草地与院子阴影延到画面外，右缘木栅栏与一棵树根贴住边。中央不得有接缝：草地与栅栏铺过 50% 的那段必须连续；栅栏竖木条不许在中央形成贯穿竖线（中缝那段木条与左右连成一片、别加深边）。平视略低，天占上方约 45%。

## 跨页 `p6` ·「指给他看」（3:2）

```
儿童绘本内页插画，横版开页跨页，一张完整画面横跨左右两页，不是拼贴、不是多格分镜。

【风格】温暖手绘绘本风；水彩铺色 + 细彩铅轮廓，可见纸质纹理；高明度低饱和粉彩；柔和无硬边阴影；左上暖白光源。

【场景】小禾一只手从毯子里伸出来，食指指向上方偏右，一颗一颗地指：这边一颗、那边一颗——天上现在有三颗星（第一颗在最上面，第二颗在它旁边偏右，第三颗更远更小更低一点）。她脸朝右上，嘴角翘着，眼睛亮亮的。爸爸四分之三侧脸跟着她的手指看过去（不给正脸）；毯子下两人肩膀挤在一起。

【构图】画面水平 50% 处是书脊：小禾在水平约 28%（整块在左页，连她抬起的那只手也在左页，手与脸都不过 46%）；爸爸在水平约 70%（整块在右页）；三颗星在右页上方（第一颗约 56%/16%，第二颗约 66%/22%，第三颗约 76%/30%）。小禾的脸与身体主干不进 46%–54%；爸爸也不许；三颗星也都在右页（它们是一组，别让中缝从中间穿过）。中央不得有接缝：天空渐变与毯子跨过 50% 的那段必须连续。平视略低，天占上方约 55%。这一页手指方向很重要：手指、眼睛、三颗星在一条斜线上——孩子看的和指的是同一处。

【爸爸】只给侧脸。【天上】三颗，就是这三颗，不许再多。

## 跨页 `p8` ·「数不清了」（3:2）— 收尾

```
