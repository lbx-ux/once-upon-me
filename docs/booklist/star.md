## 一、这本书

★ **这是黄昏，不是深夜。** 整组要保持**浅色**调（那条判断是首屏 12 张封面时就定下的，  
`cover-art-prompts.md` §三第 5 条与 `star.ts` 文件头都写死了）：八张图的光都在  
"天还没全黑"那一段里，天上是**橘粉 → 浅紫 → 淡蓝**的渐变，  
**只有 P7 之后星星才渐渐多起来**。★ 任何一张都不许黑到需要开灯。

★ **这一本的可信度全在"等"这个字上**，而"等"是**数得出来**的：  
**天上星星的颗数、路灯亮没亮、两个人手里是不是端着杯子**——三件事逐页对得上，  
这个"等"才成立。所以下面那张状态表是这本书的骨架，比构图重要。

### 主角锚点 · 小禾（封面与八张跨页**一字不改**）

```
小禾，约 5 岁的东亚小孩：乌黑的短发（齐耳，发梢自然垂着、不扎起来），
圆脸、深棕色的大眼睛、眼距略宽；笑起来眼睛先弯；鼻子一个小圆点，嘴小。
穿**米白色长袖上衣**（胸前没有任何图案）、深蓝色长裤；一双素色小袜子。
身高约 4 个头身，手脚圆润短小。
以上任何一项都不得改动：不换发型、不换发色、不换衣服颜色、不长高、不换袜子。
```

★ `hero` 那一行写的是「浅色长袖上衣」——"浅色"这个词**九张图里保持不了一致**，  
所以这里把它**定死成米白色**（这是出图文档的活：把形容词换成具体的色）。  
衣服上的**图案、字母、数字一个都不许有**。

### 爸爸锚点 · 爸爸（**只出现手臂、侧脸与肩膀**）

```
爸爸，约 35 岁的东亚男性：黑色短发、发际线干净；侧脸的轮廓温和，下巴有一点短短的胡渣；
穿**浅灰色的长袖家居上衣**（胸前无图案）与深灰色长裤；脚上素色的袜子。
★ 他在整本书里**从不出现完整的正脸**：最多给到**四分之三侧脸**，而且那半张脸还必须
被毯子、被小禾的脑袋或他的肩膀挡掉一部分——他是"陪着的那个人"，不是主角。
他在这本书里只做三件事：搬躺椅、把毯子裹好、伸出手臂让孩子靠着。
```

★ 这一条是**这本书最容易画错的地方**：模型很愿意画一张完整的、正面的、微笑的父亲脸，  
那样这本书就变成"爸爸的书"了。§四 每一条里都单独立了一段【爸爸】，就是这个用途。

### 场景基调

**自家院子的一角，黄昏**：两把**木框帆布躺椅**（一把大的、一把小的），并排朝同一个方向  
（朝着画面上方偏左的天空）；同一条**红白格纹毯**；旁边一张矮矮的小方桌，  
桌上两个**素色的陶瓷杯**（一个略大一个略小，杯里是浅色的热饮）；院子是木栅栏围的，  
栅栏外是**几棵树的剪影**与**远处居民楼的安静轮廓**——楼上的窗**一块一块亮着暖黄**。  
**没有电视、没有手机、没有屏幕、没有任何带字的物件。**

★ **星星的画法**：星星是**小亮点**——一个亮心带一点点柔光，**大小不一、疏密不一**。  
★ **不许**画成五角星形状（那是卡通符号，不是天上的星）、**不许**有长长的星芒、  
**不许**把星星用线连起来（没有星座）、**不许**有明显的大月亮（这一晚说好了先看星星）。

## 五、配音稿（一张图一段，共 8 段）

★ **念的必须就是下面【印的正文】，一个字都不许改**——屏上写的就是耳朵里听的
（理由见 [`demo-narration-script.md`](demo-narration-script.md) §一 第 1 条）。
记号：`／` 短停 0.4 秒 · `／／` 长停 1 秒 · **粗体**重音 · `——` 拖住别收。
★ 引号里的话**不插记号**：逗号自己就是停顿（这一本有两处引号，见 P3、P4）。

| 文件     | 印的字数 | 目标时长   | 上限  |
| -------- | -------- | ---------- | ----- |
| `p1.m4a` | 44       | 14 秒      | 17 秒 |
| `p2.m4a` | 43       | 13 秒      | 16 秒 |
| `p3.m4a` | 43       | 13 秒      | 16 秒 |
| `p4.m4a` | 55       | 17 秒      | 20 秒 |
| `p5.m4a` | 48       | 15 秒      | 18 秒 |
| `p6.m4a` | 49       | 15 秒      | 18 秒 |
| `p7.m4a` | 47       | 15 秒      | 18 秒 |
| `p8.m4a` | 46       | 14 秒      | 17 秒 |
| **合计** | **375**  | **116 秒** | —     |

一本约 **1 分 56 秒**（是 12 本里偏长的一本：这一本"等"的时间本来就长）。

★ 上表的**字数是这么量的**：把下面每一个代码块里的 `／` `／／` `**` 剥掉、去掉空白之后
数字符（标点也算——它与正文是同一份文本），再按 3.2 字/秒折算；并与 `star.ts` 的三行正文
**逐行核过**（同一支一次性脚本）。★ 这只是"我抄的没抄错"，**不能**替你把关念漏。

★ **目标时长是按 3.2 字/秒估的，而实测的语速是 3.6–4.7 字/秒**（三本 24 段的读数，
`ffprobe` 时长 ÷ 印的字数，逐段列在 [paint.md](paint.md) §七）。所以真录出来大概会落在
**9–15 秒**（44 ÷ 3.9 ≈ 11）——**这是正常的，不是没念完**；规格怎么改由出图的人定
（三个选项在 [`README.md`](README.md) §四）。★ **录的时候照上面那张表念，
别为了凑秒数把句子放慢或者自己加字**：字数是版面的硬上限。

封面与封底**不配音**：书还没打开，没有哪一页在念。

★ **念这一本的语气**：这一本写的是**等**，不是"看星星真美"。念的人要像
**院子里也在等的那个人**——语速偏慢、句子之间留得住，
★ **不要在"星星""亮"这些词上加情绪**（一加就变成抒情，这本书就不是它了）。
两处台词（P3 那两句、P4 爸爸那一句）都是**家常话**：念得平、短，
爸爸那句"快了"要**随口**，不许念成安慰。P8 收尾念完留满 1 秒再停。

### P1 ·「搬躺椅」→ `p1.m4a`

```
天还没黑，／ 爸爸把两把躺椅搬到院子里。／／
一把大的，／ 一把小的，／ 摆在一块儿。／／
小禾先爬上去**试了试**。／／
```

> 三句是三个动作，念得像真的在院子里搬东西（"摆在一块儿"稍微用点力）。
> 最后一句"试了试"要短、要带一点点得意。

### P2 ·「一条毯子」→ `p2.m4a`

```
两个人裹进同一条格子毯，／ 只露出脑袋。／／
毯子有点扎，／ 可是很暖。／／
院子里的风，／ 把树叶吹得**很轻**。／／
```

> "有点扎，可是很暖"是这一页的题眼：两句之间的那个转折要**真的停一下**。
> 最后一句放到最轻——它给后面那几页的"等"定音量。

### P3 ·「星星呢」→ `p3.m4a`

```
「爸爸，星星什么时候才出来呀？」／／
「再等等。」爸爸说，「快了。」／／
小禾把脑袋靠在毯子边上。／／
```

> 第一句是孩子的问，**别唱、别撒娇**，就是一个真的问题。
> 第二句是爸爸：**短、平、随口**，"快了"两个字不许加重。第三句念得安静，像把话放下了。

### P4 ·「在路上」→ `p4.m4a`

```
爸爸说：「路灯亮起来的时候，它就在路上了。」／／
话说完没多久，／ 远处的路灯**一盏一盏**亮了。／／
小禾数到第三盏，／ 就数不清了。／／
```

> 第一句里"在路上"这个说法要念得**郑重但不煽情**（这是全书的招牌句）。
> "一盏一盏"要**慢，像一个一个点亮**。最后一句好笑但别笑出来——数不清是这一页的可爱处。

### P5 ·「第一颗」→ `p5.m4a`

```
天还没有全黑，／ 最上面那一颗就亮了起来。／／
很小，很亮，／ 像有人在那里**点了一下**。／／
「找到了！」小禾小声说。／／
```

> ★ 整段**不许往上扬**（这是这本书最容易念错的一页）：它是个安静的发现，不是惊喜。
> "像有人在那里点了一下"要念得**轻而慢**。最后那句是**小声**说的——真的小声。

### P6 ·「指给他看」→ `p6.m4a`

```
小禾伸出手指头，／ **一颗一颗**指给爸爸看。／／
第二颗在旁边，／ 第三颗更远一点。／／
爸爸「嗯」一声，／ 跟着她的手指看。／／
```

> "一颗一颗"要真的分开念（每个字之间停一点点），像手指在点。
> 最后一句里爸爸的"嗯"要念得**很轻、很短、很随便**——那是陪着的样子。

### P7 ·「越来越多」→ `p7.m4a`

```
第二颗，第三颗，／ 越来越多了。／／
热饮冒着白白的气，／ 暖着两个人的手。／／
毯子下面，／ 爸爸的脚**碰了碰**她的脚。／／
```

> 前两句是"数"和"暖"。最后一句是这一页的心：念得**轻、短、不动声色**，
> "碰了碰"三个字一过就走——不许点题、不许念成温情。

### P8 ·「数不清了」→ `p8.m4a`

```
数到后来，／ 怎么数也数不清了。／／
小禾就靠在爸爸身上，／ 一起看着天上。／／
天上的星星，／ 比院子里的灯**还多**。／／
```
