## 一、这本书

★ **这本书的"不打扰"是画在位置上的**（`turtle.ts` 文件头写死）：
孩子**始终蹲在岸边那块石头上**，全书 ★ **不涉水、不伸手进水里、不把乌龟拿起来**。
所以每一条【构图】里都写死了同一个关系：
**石头在左、石板在中间、水在最右**——石头的边缘与水之间**隔着那条石板**，
一眼看得出**他没有走过去**。★ 最后一张也不许他靠近水边（正文里他只是站起来）。

★ **"慢"是靠姿势与构图画的，不是靠运动线。**（这一条与别的本相反地重要）
乌龟从 P2 到 P7 **一共只挪了大约 14% 的画面宽度**（下面状态表里逐页写死了它在哪），
★ 不许在画面上加运动线、速度线、涟漪拖尾、"chua"这类拟声或任何漫画式符号。
慢是一种**看得见的位移很小**。

★ **孩子学它**（P3/P4）是这一本最好笑也最难画的一拍：★ 他的头**真的跟着乌龟转头的方向转**，
而且★ **他不能比乌龟快**——两张里他的动作幅度都要**小到几乎看不出来**。

### 主角锚点 · 小石头（封面与八张跨页**一字不改**）

```
小石头，约 5 岁的东亚小孩：乌黑的短发（短、不遮耳），圆脸、深棕色的大眼睛、眼距略宽；
笑起来眼睛先弯；鼻子一个小圆点，嘴小。
穿**米白色的短袖 T 恤**（胸前没有任何图案）与**浅卡其色的短裤**；光着脚。
身高约 4 个头身，手脚圆润短小；★ 蹲着的时候**膝盖是并拢的**。
以上任何一项都不得改动：不换发型、不换发色、不换衣服颜色、不长高、不穿鞋。
```

★ 「膝盖并拢」是正文写死的（P1「膝盖并得紧紧的」）：这是一个**收着的**坐姿，
与"不打扰"是同一件事。九张里只要有他蹲着的，膝盖就都是并拢的。

### 乌龟锚点 · 那只乌龟（P2 起出现，同一只）

```
一只中华草龟样的小乌龟：壳是**深褐绿色**的，壳上**有几块深浅不一样的斑**
（★ 这是正文点名写死的细节，P2 里就要看得清；斑块的位置、形状、颜色八张里完全一致，
不许变、不许少一块）；壳的边缘有一圈**浅色的边**；头、脖子与四肢是**暗橄榄色**，
爪子上有小指甲；眼睛小、黑亮；★ 没有任何花纹描上去（不许给壳画格子、画名字、画星星）。
体型约一个成人手掌大。
★ 它**不拟人**：不许戴东西、不许笑成卡通脸、不许站起来、不许两只脚立着走。
```

### 那只蜻蜓（只在 P5 出现，同一只）

```
一只蜻蜓：细长的身子（蓝绿或墨绿），两对**透明的翅膀**（看得见细细的翅脉），
停在草叶尖上，翅膀**一动不动**（是"停"的姿态，不是"飞"的姿态）。
★ 它**不是蝴蝶**：不许有宽的彩色翅膀、不许有花纹斑点。
```

### 场景基调

**午后的池塘边**：池塘的水是**青绿色**的（清、但看得见深浅），
水面上有一片片**浮萍**（★ 是一粒粒小圆叶聚成的，不是大荷叶），
远处水面上一两朵**白色的睡莲**（素色，只在远处）；岸边是一条**旧的青石板**
（灰青色、有几道浅裂纹、边角有一点青苔），石板边上有几株草；
岸上（画面左侧）是几块**大石头**，其中一块被太阳晒得暖暖的、孩子蹲在上面。
**没有荷花池的栏杆、没有木栈道、没有垃圾桶、没有别人、没有任何带字的物件。**

★ 光源按 §2.1 从左上照下来，午后的光在水面上有一层**碎碎的反光**（点状，不是大片白）。

## 五、配音稿（一张图一段，共 8 段）

★ **念的必须就是下面【印的正文】，一个字都不许改**——屏上写的就是耳朵里听的
（理由见 [`demo-narration-script.md`](demo-narration-script.md) §一 第 1 条）。
记号：`／` 短停 0.4 秒 · `／／` 长停 1 秒 · **粗体**重音 · `——` 拖住别收。
★ 这一本**通篇没有一个引号**（没有一句人说的话）：所以**不许演**，
念的就是一个在旁边一起等的人。

| 文件     | 印的字数 | 目标时长   | 上限  |
| -------- | -------- | ---------- | ----- |
| `p1.m4a` | 51       | 16 秒      | 19 秒 |
| `p2.m4a` | 44       | 14 秒      | 17 秒 |
| `p3.m4a` | 46       | 14 秒      | 17 秒 |
| `p4.m4a` | 45       | 14 秒      | 17 秒 |
| `p5.m4a` | 49       | 15 秒      | 18 秒 |
| `p6.m4a` | 45       | 14 秒      | 17 秒 |
| `p7.m4a` | 48       | 15 秒      | 18 秒 |
| `p8.m4a` | 43       | 13 秒      | 16 秒 |
| **合计** | **371**  | **115 秒** | —     |

一本约 **1 分 55 秒**。

★ 上表的**字数是这么量的**：把下面每一个代码块里的 `／` `／／` `**` 剥掉、去掉空白之后
数字符（标点也算——它与正文是同一份文本），再按 3.2 字/秒折算；并与 `turtle.ts` 的三行正文
**逐行核过**（同一支一次性脚本）。★ 这只是"我抄的没抄错"，**不能**替你把关念漏。

★ **目标时长是按 3.2 字/秒估的，而实测的语速是 3.6–4.7 字/秒**（三本 24 段的读数，
`ffprobe` 时长 ÷ 印的字数，逐段列在 [paint.md](paint.md) §七）。所以真录出来大概会落在
**9–14 秒**（51 ÷ 3.9 ≈ 13）——**这是正常的，不是没念完**；规格怎么改由出图的人定
（三个选项在 [`README.md`](README.md) §四）。★ **录的时候照上面那张表念，
别为了凑秒数把句子放慢或者自己加字**：字数是版面的硬上限。

封面与封底**不配音**：书还没打开，没有哪一页在念。

★ **念这一本的语气**：★ **这一本是全套里最慢的一本，而它的"慢"要靠停顿，不靠拖音。**
念的人要像**蹲在孩子旁边、一句话都不想多说的人**：句子之间留得住，
逗号处真的停一下，★ **"慢慢""慢吞吞"这些词反而不要拖长**（一拖就成了模仿慢，
这本书要的是念的人自己也不着急）。
P4 那串"一步，两步，三步"要**一步一步地念**（每步之间停够半拍）；
P8 最后一句"慢慢来，也很好"是**全书的落点**：念得**轻、稳、不带劝说的语气**，
念完留满 1 秒再停。

### P1 ·「岸边的石头上」→ `p1.m4a`

```
午后的池塘边，／ 小石头蹲在岸上的**石头上**。／／
石头被太阳晒得**暖暖的**，／ 膝盖并得紧紧的。／／
池塘里有浮萍，／ 绿绿的一片。／／
```

> 三句三个信息：地方、坐姿、水面。整段**越平越好**（这是开场）。
> "暖暖的"念得像手贴在石头上试过一下。最后一句放轻。

### P2 ·「一只乌龟」→ `p2.m4a`

```
一只乌龟，／ 正**慢吞吞地**爬过岸边的石板。／／
它的壳上有几块**深浅不一样的斑**。／／
小石头连眼睛都**不敢眨**。／／
```

> ★ "慢吞吞地"**不许拖音**（一拖就假）：慢是靠两个句子之间的停顿做出来的。
> "几块深浅不一样的斑"要念得像在**看**（一个一个地看过去）。最后一句压到最轻。

### P3 ·「学着它」→ `p3.m4a`

```
小石头也跟着它，／ 把动作放得**很慢很慢**。／／
乌龟怎么转头，／ 他就怎么转头。／／
两个都慢慢慢慢，／ 谁也不着急。／／
```

> 第二句两个"怎么"要对上（它怎么、他就怎么）——那是这一页最好笑的地方，
> ★ 但**不许笑出来**。"慢慢慢慢"四个字**轻轻地念过去**，不要一个字一个字顿。

### P4 ·「走三步」→ `p4.m4a`

```
乌龟走三步，／ 小石头就在心里**数上三步**。／／
一步，／ 两步，／ 三步，／ 停一停。／／
它停下来的时候，／ 他也停下来。／／
```

> ★ "一步，两步，三步"要**一步一停**（每步之间都留半拍），"停一停"之后**再停久一点**
> ——这一段的节奏就是这一页的内容。最后一句跟着那个停，念得又轻又短。

### P5 ·「一只蜻蜓」→ `p5.m4a`

```
一只蜻蜓停在草叶尖上，／ 翅膀也**一动不动**。／／
它也在等，／ 等什么事情**慢慢发生**。／／
池塘的水面上，／ 浮萍**挪了一点点**。／／
```

> 这一页是**陪衬**：蜻蜓、浮萍都只是在等，念得越平越好。
> "挪了一点点"要念得**几乎听不见**——这一句的音量就是那一点点的量。

### P6 ·「到水边了」→ `p6.m4a`

```
乌龟终于爬到了水边，／ 在那里**停了一下**。／／
它把脖子伸出来，／ 闻了闻**水的味道**。／／
小石头把呼吸放得很轻。／／
```

> ★ "终于"两个字要念出来（这一页是全书的"到了"），但**别加重**——
> 它只是走得久。最后一句是全段的收：**把声音收小**，像真的在屏住呼吸。

### P7 ·「圈圈」→ `p7.m4a`

```
它滑进水里，／ 只留下几圈**慢慢散开的**水纹。／／
水面又平了，／ 像什么也没有发生过。／／
小石头想：／ 它一定**游得很快**。／／
```

> 前两句放慢、放轻；"像什么也没有发生过"要念得**平常**（这一句是这本书的语气）。
> 最后一句是**孩子心里想的**：念得像自言自语、带一点点向往——**但不许兴奋**。
> 念完留半秒。

### P8 ·「慢慢回家」→ `p8.m4a`

```
小石头慢慢地笑，／ 慢慢地站起来。／／
裤子后面沾了一点沙子，／ 拍两下就掉下去了。／／
慢慢来，／ **也很好**。／／
```

> 前两句两个"慢慢地"要念得真的慢（但仍是靠停顿，不是拖音）。
> 中间那句念得轻快一点点（拍拍沙子的那两下）。
> 最后一句是**全书的落点**：★ 轻、稳、**不带劝说的语气**——
> 它不是道理，是他刚才真的经历过的四个字。念完**留满 1 秒**再停。
