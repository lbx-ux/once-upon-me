## 一、这本书

### 主角锚点 · 小满（封面与八张跨页**一字不改**）

```
小满，约 5 岁的东亚小女孩：乌黑的短发，头顶扎一个小揪揪（皮筋是素色的，没有蝴蝶结）；
圆脸、大眼睛、眼距略宽，笑起来眼睛先弯；穿**浅色长袖上衣**（奶白或浅黄，胸前无图案）
与**背带裤**（牛仔蓝）；光着脚或穿一双素色小袜子（八张里保持一致）。
身高约 4 个头身，手脚圆润短小。
以上任何一项都不得改动：不换发型、不换发色、不换衣服颜色、不长高、不换鞋袜。
```

### 妈妈锚点 · 妈妈（**只在 P1 入画**，同一人）

```
妈妈，约 35 岁的东亚女性：黑发松松地在脑后挽一个低髻，几缕碎发落在耳前；
穿**浅灰色的长袖家居上衣**与深色长裤；笑起来眼睛弯弯的。
她在这本书里只做一件事：蹲在纸箱另一边，把纸箱推给小满——姿态安静，不俯视、不指点。
```

### 猫锚点 · 猫（出现在 P4、P6、P7、P8）

```
一只橘白相间的短毛猫：橘色背脊与尾巴、白色胸口与四只白爪子、绿眼睛、
鼻头一小块粉色。**颈上什么都没有**——不戴项圈、不挂铃铛、不系绳。
```

★ 「颈上什么都没有」这条是**从恐龙那本的教训来的**：那一本六张图里猫的项圈时有时无，
根因是"锚点从记忆里写、不从文档里抄"。所以这一本把猫**也写成锚点块**，
出图时逐字带上，并把它列进 §六 的并排核对里。

### 场景基调

**自家客厅的一角，白天的下午**：木地板上一块从窗户斜进来的方形光斑，光里有细小的浮尘；
旁边是矮木茶几、一块**圈圈花纹的地毯**、一只**盆栽**、一座**矮书架**、一张沙发。
背景是浅色的墙。★ **没有电视、没有平板、没有玩具广告、没有任何带字的物件**。

★ **这一本的底线：那是纸箱，不是火箭。** 八张图里**一张真火箭、太空、月球、地球、
宇宙飞船、飞行服、头盔面罩（那种带反光面窗的）都不许出现**；星星只许是 P2 里
**用蜡笔画在箱子上的那几颗**。P5–P7 的"升空"是**地毯上的一场想象**：
书架、盆栽、地毯、猫**始终在同一间客厅里**，只是从箱口看出去显得很高、很远。
沙发上、墙上、窗外**不许出现真的夜空**。

★ 这一本的可信度全在两样东西上：**箱子上的画**（P2 两扇圆窗户 + 几颗星星，
之后**一直不许变、不许回退**）与**那顶纸箱头盔**（P3 戴上，P3 起一直戴着，
P8 才摘下来）。两张状态表：

## 三、封面 `cover.webp`（完整可复制）

**参考图**：P0 + `public/art/rocket.webp`　**输出**：先出 2:3（1024×1536），居中裁到 3:4

```
儿童绘本的竖版封面插画，一张完整画面（不是拼贴、不是多格分镜、不是书的样机）。

【主体与场景】
下午的客厅地板上，小满**坐在那只大纸箱里**，两只手举得高高的、脸上是"要出发了"的神情；
她头上戴着那顶**纸箱头盔**（有点大），箱子的正面看得见**两扇蜡笔画的圆窗户**与窗外几颗星星。
箱子周围的地板上散着两支蜡笔与一小片剪下来的瓦楞纸边；光从左上斜进来，光里有细小的浮尘。
猫蹲在箱子边上、抬头看她。

【构图 · 竖版封面专用】
- 竖构图：纸箱与小满占画面中央偏下，箱子合起来占画面高度约 60%；箱子略侧，让正面那两扇窗
  与箱口里的人都看得清。
- 小满的脸在画面垂直约 52% 处、箱口在垂直约 60% 处；视觉重心落在垂直 58% 附近。
- 小满与箱子离画面上下边各留出 8% 的余地（成品会上下各裁掉约 5%），左右边各留出 8%。
- ★ 画面四周**铺满、出血**：地板、光斑与浮尘一直画到最外缘的每一个像素，四边不得出现白边、
  纸边、画框、装裱、留白或渐隐到白。"安全边距"只指主体离边有距离，**不是在边上留空白**
  ——边缘要画满景物（上缘是墙与光斑，下缘是地毯的圈圈花纹与那片瓦楞纸边）。
- ★ 整幅是一张连续的画面：封面虽然是单页，也不许出现任何竖向的分格线或纸张边缘。
- 略高的俯视（能看到箱口里面），但箱子与人不透视变形。

【人物】（逐字贴 §一 的「主角锚点」+「猫锚点」）

【风格】（逐字贴 §2.1 的「风格段」）

【文字】画面内不出现任何文字、字母、数字、签名或水印（书名由前端叠字）。
★ 箱身上也不许出现任何字：**没有快递单、没有印刷字、没有手写的名字**。

【输出】竖版，2:3（1024×1536）。

【约束】（逐字贴 §2.2 的「负面清单」与 §2.3 的「三条硬约束」，再补一条本书专用：）
★ 这是**纸箱**，不是火箭：不许有尾翼、喷口、金属壳、铆钉、舷窗反光、仪表或按钮；
不许出现真的星空、月球、地球；星星只有**箱子正面画着的那几颗蜡笔星**。
```

### P1 · 跨页 1 `p1.webp`｜「一个大纸箱」

```
儿童绘本内页插画，横版开页跨页，一张完整画面横跨左右两页（不是拼贴、不是多格分镜、
不是书的样机）。

【主体与场景】
下午的客厅一角，一只**大纸箱**立在木地板的光斑里——它比小满还高，箱口朝上、盖子已经拆掉。
小满站在箱子的左边，一只手扶着箱壁、仰头看它，像在打量一座刚出现的山；
妈妈蹲在箱子的右边，两只手还搭在箱沿上，刚刚把它推到这一块光里来，正笑着看她。
地板上有拆箱留下的一小片瓦楞纸边与一条素色胶带。画面里只有她们两个人。

【构图 · 开页跨页专用】
- 画面水平 50% 处是书脊：小满在**水平约 24%**（整块在左页）；纸箱占**水平约 38%–64%**，
  **跨过中缝**（箱子是物件，允许压着书脊）；妈妈在**水平约 74%**（整块在右页，蹲姿、侧身）。
- ★ 小满与妈**脸与身体主干都不得进入水平 46%–54%**：中缝上只允许有**箱子**、
  地板与光斑。两个人的脸要分别在 24% 与 74%。
- ★ 左右两缘要**画满**、不许留白：左缘让木地板与光斑的近景一直延到画面外，
  右缘让地毯的边与那条胶带贴住边；两缘的地板纹理都要有水彩颗粒。
- ★ 中央**不得有接缝**：箱子的一个立面可以跨过中缝，但那一段必须连续——
  **箱面上不许出现一条竖着的明暗突变**（那看着就像折痕）。
- 略高的俯视（能看到箱口里面是空的、有一片瓦楞纸底），箱子与人都不透视变形。

【角色锁定】（逐字贴 §一 的「主角锚点」+「妈妈锚点」）
【箱子】此时是**干净的纸箱**：一片素色胶带，**没有**圆窗户、**没有**星星、**没有一个字**。
【风格】【文字】【输出】横版 3:2。【约束】（逐字贴 §2.2 与 §2.3）
```

### P2 · 跨页 2 `p2.webp`｜「先画窗户」

```
【主体与场景】
镜头拉近到箱子的正面：**两扇圆窗户**刚画好（一左一右，圆得有点歪，蜡笔画的，
窗框外面还有一圈被他描粗的边），窗户外面**画了几颗歪歪的蜡笔星星**（五六颗，大小不一）。
小满的右手还捏着那支蜡笔停在左边那扇窗旁边，是"刚收笔"的那一下；
她的上身与侧脸在画面左侧，低头看着自己画的窗户，嘴角已经翘起来了。

【构图】
- 画面水平 50% 处是书脊：小满在**水平约 24%**（整块在左页，只到肩膀），
  箱子正面占**水平约 36%–76%**、**跨过中缝**；**左窗在水平约 40%、右窗在水平约 62%**
  —— 两扇窗这样摆是为了**不让书脊从一扇窗的中间穿过去**（窗是圆的，切开就难看）。
- ★ 小满的脸与身体主干不得进入水平 46%–54%；箱面与那几颗蜡笔星星可以跨中缝。
- ★ 中央不得有接缝：箱面与地板的光斑铺过水平 50% 的那一段必须连续、不许折痕，
  箱面上也不许有一条竖着的明暗突变。
- 平视略低（视线与箱面接近平行），让孩子看到的是"箱子上的窗户"而不是俯视的箱子顶。
【箱子】两扇圆窗户（左右各一）＋几颗蜡笔星星；★ 此后**不再增加、也不再减少**。
【角色锁定】【风格】【文字】【输出】横版 3:2。【约束】（逐字贴 §2.2 与 §2.3）
★ 窗里**不许有玻璃、反光、栏杆或任何东西**——它就是一扇画上去的圆窗户。
```

### P4 · 跨页 4 `p4.webp`｜「三，二，一」

```
【主体与场景】
小满**已经坐进箱子里**了，只有上半身露在箱口上面，**两只手举得高高的**，
是一个准备倒数出发的姿势；头盔还戴着（这一页眉毛露出来，是刚往上推过的那一下）。
猫蹲在沙发边，尾巴一晃一晃地看着她，胡须向前。地板上散着两支蜡笔。

【构图】
- 画面水平 50% 处是书脊：箱子占**水平约 30%–56%**、**跨过中缝**；
  小满的身体在箱子里偏左——**躯干在水平约 34%–44%**，两只举起的手可以贴到 46% 的边上
  （★ **不许越过 46%**）；猫在**水平约 78%**（整块在右页，蹲姿）。
- ★ 小满的脸与身体主干不得进入水平 46%–54%。举手这个动作最容易把手甩进带里，
  所以手的高度**要在她的头顶正上方**，不要往右边伸。
- ★ 中央不得有接缝：箱口边沿与地板跨过 50% 的那一段必须连续，
  **箱口那条横边不许在中央断开**。
- 略高的俯视，能同时看见箱子里的小满与沙发边的猫。
【箱子】两扇圆窗户 ＋ 星星（不变）；这一页看得见箱口与一片瓦楞纸底。
```

## 五、配音稿（一张图一段，共 8 段）

★ **念的必须就是下面【印的正文】，一个字都不许改**——屏上写的就是耳朵里听的
（理由见 [`demo-narration-script.md`](demo-narration-script.md) §一 第 1 条）。
记号：`／` 短停 0.4 秒 · `／／` 长停 1 秒 · **粗体**重音 · `——` 拖住别收。
★ 引号里的话**不插记号**：逗号自己就是停顿（P4「三，二，一。」那一下靠逗号念出来）。

| 文件     | 印的字数 | 目标时长   | 上限  |
| -------- | -------- | ---------- | ----- |
| `p1.m4a` | 48       | 15 秒      | 18 秒 |
| `p2.m4a` | 44       | 14 秒      | 17 秒 |
| `p3.m4a` | 44       | 14 秒      | 17 秒 |
| `p4.m4a` | 42       | 13 秒      | 16 秒 |
| `p5.m4a` | 46       | 14 秒      | 17 秒 |
| `p6.m4a` | 44       | 14 秒      | 17 秒 |
| `p7.m4a` | 50       | 16 秒      | 19 秒 |
| `p8.m4a` | 45       | 14 秒      | 17 秒 |
| **合计** | **363**  | **114 秒** | —     |

一本约 **1 分 54 秒**，与画画那本几乎同长（362 字）。

★ 上表的**字数是这么量的**：把下面每一个代码块里的 `／` `／／` `**` 剥掉、去掉空白之后
数字符（标点也算——它与正文是同一份文本），再按 3.2 字/秒折算。同一天用一支一次性脚本
（`.out/rocket-voicecheck.py`，不入库）把 §五 的八个块与 `rocket.ts` 的三行正文**逐行比过**，
八块全部逐字一致、字数也对上。★ 这只是"我抄的没抄错"，**不能**替你把关念的时候有没有念漏。

★ **目标时长是按 3.2 字/秒估的，而实测的语速是 3.6–4.7 字/秒**（三本 24 段的读数，
`ffprobe` 时长 ÷ 印的字数，逐段列在 [paint.md](paint.md) §七）。所以真录出来大概会落在
**11–14 秒**（46 ÷ 3.9 ≈ 12）——**这是正常的，不是没念完**；规格怎么改由出图的人定
（三个选项在 [`README.md`](README.md) §四）。★ **录的时候照上面那张表念，
别为了凑秒数把句子放慢或者自己加字**：字数是版面的硬上限。

封面与封底**不配音**：书还没打开，没有哪一页在念。

★ **念这三句的语气**：这一本是"一个孩子在客厅里玩箱子"的下午，**不是科幻片**。
念的人**不要起飞、不要轰隆隆**，要像**站在门口看孩子玩的那个人**：
P4 的倒数要数得**慢而认真**（真的在数）；引号里那三句
（P1「这个能不能归我？」、P4「三，二，一。」、P8「小满，吃饭啦。」）——
前两句是**孩子与妈妈的口语**，念得短、平；
最后那句是厨房里隔着一段距离喊出来的，**轻、但听得见**，不要念成命令。

### P1 ·「一个大纸箱」→ `p1.m4a`

```
客厅里多了一个大纸箱，／ 是**冰箱**留下的。／／
它比小满还高，／ 她绕着它**走了两圈**。／／
妈妈问：／「这个能不能**归我**？」／／
```

> 三句三个镜头：箱子、孩子、妈妈。最后那句引号是**妈妈在问**，
> 念得像随口一问，"归我"两个字稍微扬一点。★ 别念成孩子撒娇。

### P2 ·「先画窗户」→ `p2.m4a`

```
小满用蜡笔／ 在箱子上画了**两个圆窗户**。／／
一个画在左边，／ 一个画在右边。／／
窗户外面，／ 她画了几颗**星星**。／／
```

> "两个圆窗户"是这一页的题眼，念清楚；"一个画在左边，一个画在右边"两小句一顿一顿地念，
> 像伸着手指点。最后一句的"星星"放轻——是**画上去的**星星。

### P3 ·「头盔」→ `p3.m4a`

```
她给自己做了一顶**纸箱头盔**，／ 戴得端端正正。／／
头盔有点大，／ 把她的眉毛**盖住了**。／／
她往上一推，／ 正好。／／
```

> 这一页的好笑处全在"有点大"。念"盖住了"的时候**不要笑出来**——
> 孩子自己是很当真的，笑场就没了。最后"正好"两个字要短、要满意。

### P4 ·「三，二，一」→ `p4.m4a`

```
她坐进箱子里，／ 两只手**举得高高的**。／／
猫蹲在沙发边，／ 尾巴一晃一晃地**看着她**。／／
「三，二，一。」／／
```

> 前两句照念，中间那句可以放软一点（那是一只猫在看）。最后那句倒数：
> **一个字一个字地数，每字之间各停半拍**，数完留满 1 秒再收——这一页的收尾就是那 1 秒。

### P5 ·「环形山」→ `p5.m4a`

```
地毯上的花纹，／ 一圈一圈，／ 变成了**环形山**。／／
火箭升起来，／ 地板在下面**越来越小**。／／
她扶着箱子边，／ 往外看。／／
```

> ★ "火箭"这两个字念得**平平的、像实话**——在这本书里，箱子就是火箭，
> 不要用讲童话的腔调去提示"这是想象"。最后一句放到最轻，像怕惊动了什么。

### P6 ·「猫在看」→ `p6.m4a`

```
猫也跟着「升空」了，／ 趴在箱子边上**看**。／／
它的胡须一动一动，／ 像在**数星星**。／／
小满伸手／ 摸了摸它的头。／／
```

> "升空"两个字稍微顿一下、带一点点好笑，但不许夸张。
> 最后一句念得慢、软——这一页是整本书里最静的一拍。

### P7 ·「飞过书和森林」→ `p7.m4a`

```
书架从旁边过去，／ 像一栋**高高的楼**。／／
盆栽是一片绿色的森林，／ 叶子比她还高。／／
她在窗户上敲了两下，／ 算是**打招呼**。／／
```

> 两句比喻要念得**像真的**（她真的这么看），这是这本书最像"飞"的一页，
> 但速度不许加快。最后"打招呼"三个字轻快一点就够了。

### P8 ·「到家了」→ `p8.m4a`

```
「小满，吃饭啦。」／ 妈妈在厨房喊。／／
火箭稳稳地落回／ 客厅的**地毯**上。／／
她把头盔摘下来，／ 放回箱子旁边。／／
```

> 第一句是隔着一段距离喊的：**轻，但清楚**，别拉开嗓门。
> "稳稳地落回"是这一页的关键词——念得缓，像真的有重量落下来。
> 收尾三句一句比一句轻，念完**别急着停**，留 1 秒再收。
