## 一、这本书

★ **这一本与首页第二屏那本《小宇的云》不是同一本**（用户 2026-10-15 定：12 本全新写，
首页那本原样不动）。两本守的是同两条边界，这里再写一遍：

1. **云要"恰好像"，不要画成写实的乌龟或船。**（`cloud.ts` 文件头写死）
   那朵云**始终还是云**：一团蓬松的、有厚度的白云，只是**差一点点**就像了——
   乌龟要看得见"隆起的背 ＋ 一个伸出来的小头"这两个特征，船要看得见"鼓起的帆 ＋ 翘起的船头"，
   **其余部分仍然是云的边**。★ 不许给云画眼睛、嘴、鼻孔、爪子、船板、桅杆、绳；
   ★ 不许描边（云的边是**渐变的**，不是一条线）。
2. **这是草地上的想象**：小飞**始终躺在野餐垫上**（P8 只是半坐起来），
   ★ **不许真的飞上天**、不许出现他坐在云上的画面、不许出现云托着他。

★ **这本书的可信度在"那朵云的变化顺序"上**：一朵 → 像乌龟 → 散开 → 又聚成船 → 像被子
→ **一朵都没有** → 又来一朵（比刚才小一点）。★ 前一页的形态**不许提前出现**，
后一页的**不许回退**；★ 也不要往天上多加一朵当背景（P7 那句"一朵云都没有"就是靠
前面**只有那一朵**才成立的）。

### 主角锚点 · 小飞（封面与八张跨页**一字不改**）

```
小飞，约 5 岁的东亚小孩：乌黑的短发、额前一层碎刘海，发梢有点翘；
圆脸、深棕色的大眼睛、眼距略宽；笑起来眼睛先弯；鼻子一个小圆点，嘴小。
穿**浅蓝色的短袖 T 恤**（胸前没有任何图案）与**深蓝色的长裤**；光着脚。
身高约 4 个头身，手脚圆润短小。
以上任何一项都不得改动：不换发型、不换发色、不换衣服颜色、不长高、不换鞋。
```

### 小狗锚点 · 小狗（八张都在，同一只）

```
一只**奶黄与白相间**的短毛小狗：背脊与两只耳朵偏**奶黄**，胸口、肚子与四只爪子偏**白**，
鼻子黑亮、眼睛圆；体型小（约与小飞的膝盖同高）。
★ **颈上什么都没有**——不戴项圈、不挂铃铛、不系绳、不穿衣服。
```

★ 「颈上什么都没有」这条是**从恐龙那本的教训来的**：那一本六张图里猫的项圈时有时无，

出图时逐字带上，并把它列进 §六 的并排核对里。

### 道具锚点（八张里同样东西，位置可动、样子不许变）

```

青苹果：**三个**青苹果（浅绿色、带一点点黄），放在篮子边；
　　　　★ P1–P7 一直是三个，P8 有一个到了小飞手里、被咬了一口（篮边剩两个）。
```

### 场景基调

**正午的草坡**：天是干净的浅蓝（正午的高天），草地是明亮的黄绿，
远处草坡顶上**一排树**（五六棵、连成一条线）；风很轻，草叶有一点点倒向。
**没有别的野餐的人、没有帐篷、没有风筝、没有气球、没有垃圾、没有带字的物件。**
★ **没有太阳出现在画面里**（光源按 §2.1 来自左上，但不画太阳本体——
画了太阳，云的戏就被抢了）。
