## 一、这本书

★ **这一本有两件"刻意"的东西，都不是审美，是规矩：**

1. **橙色的救生衣**（`whale.ts` 文件头写死）：八张图里小海身上的救生衣**一件都不许脱**，
   而且**带子一直是系紧的**（P1 妈妈系紧了两格，后面每一张都保持那个状态）。
   这是全套 12 本里**唯一一处"画面自己在示范"**的地方——漏一张，这本书的安全示范就断了。
2. **距离**：这本书画的是**一条船与一条大鱼之间的那段水**。
   ★ 孩子**始终在船上**、**从不下水**、**从不伸手去碰鱼**（P8 只挥手）。
   "敬畏"不是靠形容词画的，是靠**那段谁也不过界的距离**画的——
   所以每一条【构图】里都写死：小船在左页、大鱼在右页，中间留出水面。

### 主角锚点 · 小海（封面与八张跨页**一字不改**）

```
小海，约 5 岁的东亚小孩：乌黑的短发、额前一层碎刘海，发梢有点翘；
圆脸、深棕色的大眼睛、眼距略宽；笑起来眼睛先弯；鼻子一个小圆点，嘴小。
穿**浅米色的短袖上衣**（胸前没有任何图案）与**深蓝色的短裤**，光着脚。
外面套一件**橙色的儿童救生衣**：前后都是橙色的浮力块，胸前**两条横着的扣带**、
肩上两条带子，扣带**扣得紧紧的**（★ 八张里始终系紧、不许松开、不许脱掉一半）。
身高约 4 个头身，手脚圆润短小。
以上任何一项都不得改动：不换发型、不换发色、不换衣服颜色、不长高、不换鞋。
```

★ 救生衣**不是**泳圈、不是臂圈、不是背心式玩具：它是**正经的儿童救生衣**（橙色、有扣带、
领子后面有一块托头的浮力块）。★ 救生衣上**没有一个字、没有品牌、没有反光条上的字母**。

### 妈妈锚点 · 妈妈（**只在 P1 入画**）

```
妈妈，约 35 岁的东亚女性：黑发松松地在脑后挽一个低髻，几缕碎发落在耳前；
穿**浅灰色的短袖衬衫**与深灰色长裤；笑起来眼睛弯弯的。
★ 她在这本书里只做一件事：**两只手把救生衣的扣带系紧两格**——只有手臂、侧身与下半张脸入画，
不给正脸，不俯视、不指点。
```

### 大鱼锚点 · 那条大鱼（P3 起出现，同一头）

```
一条须鲸类的大鱼：背与身体是**青灰色**（背深、腹浅），腹部有许多**纵向的浅色褶沟**，
头顶偏后有一个**喷气孔**；眼睛是**黑亮的、温和的**，**比小海的拳头还大**；
嘴是**长长的、平缓的弧线**，**没有牙齿、没有獠牙、没有尖吻**；尾鳍宽、分成两叶；
胸鳍细长。身上有几块**浅浅的白色斑**（位置八张一致）。
★ 它**不是鲨鱼**：不许有背鳍立成三角、不许有锯齿状的牙、不许有凶狠的眼神。
★ 它温和但**不拟人**：不许画笑脸、不许画眼睛里的高光成"卡通大眼"、不许戴东西。
```

★ **大鱼的体型与位置**：比小船大得多（长度约为小船的三倍以上），
但★ **它从不压在小船上方**——它始终在**另一侧的水里**，与小船之间留出一段水面。
★ 它的**眼睛不许落在水平 46%–54%**（那是它的"脸"，切开最难看）。

### 那只船（八张里是同一条）

```
一条**白色的小木船**：尖头、平底、能坐一个人＋一把桨的划桨小船；船板是白的、有两道木纹，
船舷一圈浅木色的边；船里放着一把木桨（桨叶朝上搁在船头）。
★ **没有马达、没有螺旋桨、没有帆、没有救生圈挂在船舷上、船身上没有一个字、没有船号。**
```

**没有别的船、没有人、没有岛、没有礁石、没有垃圾漂浮在海面上、没有任何带字的物件。**

> "慢慢""不快""浅浅"——这一页全是轻的字，念的时候都要**收着**。
> "像故意陪着这只小船"是全书的暖处，念得**不动声色**（不要念成拟人童话）。

### P8 ·「又稳住了」→ `p8.m4a`

```
小船晃了晃，／ 又**稳稳地**停住了。／／
几只海鸟从头顶飞过去，／ 翅膀**一开一合**。／／
小海朝着大鱼，／ 挥了挥手。／／
```

> 第一句要有**重量的感觉**（晃、又稳）。海鸟那一句念得开阔一点，声音可以放出去一点点。
> 最后一句轻快、短，念完**留满 1 秒**再停——那 1 秒就是这本书说的"善意"。
