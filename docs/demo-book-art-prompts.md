# 演示绘本：封面与跨页 —— 出图提示词与验收记录

> 用途：首页第二屏那本滚动翻页绘本（`src/components/book/`）所用的插画。
> 产物：`public/book/{cover,spread-1,spread-2,spread-3,spread-4a,spread-4b}.webp` 六张书，
> 加两枚选择点图标 `public/book/{choice-dino,choice-ship}.webp`（P7，不是书里的画面）。
> 转换脚本：[`scripts/make-webp.py`](../scripts/make-webp.py)，跨页走 `--preset book-spread`（3:2），
> 封面走 `--preset book-cover`（3:4），图标走 `--preset book-icon`（1:1）。
> 风格库模板：**`illustration-art-style`**（与首屏 12 张封面同一模板，风格连续）；P0 设定表用 **`character-design-sheet`**；跨页构图参考 **`scene-storytelling`** 的 guidance。
> 关联文档：[`cover-art-prompts.md`](cover-art-prompts.md)（首屏 12 张的骨架与负面清单，本文件的负面清单沿用那一份并追加本书专用项）。

> **本批主题是「云」**，主角取自首屏 `public/art/cloud.webp` 那张卡。
> 前两批（恐龙、火箭）已废弃，见 §五 —— 那一段留着，因为它记下的是**与主题无关**的两条教训。

## 一、这一批和首屏那 12 张的关键差别

首屏 12 张画的是 **12 个不同的孩子**，回答"能做什么"。这一批只画 **1 个孩子**，回答的是
产品真正的承诺——「**每一页都是同一个他**」。所以约束的优先级完全换了：

| 约束                          | 为什么                                                                                                   | 对提示词的要求                                                                                     |
| ----------------------------- | -------------------------------------------------------------------------------------------------------- | -------------------------------------------------------------------------------------------------- |
| **跨 6 张是同一个人**         | 这一节的全部论点。脸一漂，等于把产品的反例做给人看                                                       | 先出一张 P0 设定表锁死；之后每张都把设定表作为参考图附上，并把【角色锁定】那一段**一字不改**地保留 |
| **主体不得压在水平 46%–54%**  | 一张 3:2 跨页图**不是一个物理单位**：书脊会从正中穿过，左半右半是两个独立页面                            | 每条提示词都要写死主体的水平位置，并单独强调一次这条禁区                                           |
| **画面比例就是成品比例**      | ★ 2026-10-12 定：跨页 3:2、页面 3:4，**一格都不裁**；封面 3:4 与页面同比例，落进去也不裁                 | 跨页按 3:2 出图且**不裁**；封面仍由 2:3 裁到 3:4，构图按裁后画面写                                 |
| **视觉重心在垂直中线 ±5% 内** | 一页竖着看（3:4），视线落在中间那条带上；主体上下都留得出气口                                            | 跨页不裁之后这条不再是"给刀留的"，而是构图本身的要求                                               |
| **四边铺满，不留白边**        | ★ 云批次栽在这四个字上：写「左右各留 6% 安全边距」，模型当成了**留白**，真的画出白纸边（见下）           | 每条提示词都要**同时**写明"画面铺满整张画布、四边出血"，并说明"安全边距"只指**内容离边有距离**     |
| **中央不得有接缝**            | ★ 云批次第二个坑：五张跨页在水平 50% 处都有可见的竖向突变（见下），翻到书上就是一道折痕                  | 每条提示词都要写明"整幅是一张连续的画面，中央不许有接缝、折痕或左右明暗突变"                       |
| **始终是"草地上的想象"**      | 落点取自 `cover-art-prompts.md` §三第 9 条那张卡的「想象力与闲适」：孩子躺在野餐垫上，天上的云恰好像什么 | 每页都要留一个真实线索（格纹野餐垫、藤篮、青苹果、那只小狗、远处的草坡与树列），不许画成真的飞上天 |

**跨页不裁，封面才裁。** 跨页的源图与预设都是 3:2，`make-webp.py` 对它是恒等变换；
封面出图只给 2:3，要裁到 3:4（提示词的【构图】是按裁后画面写的）。
`gpt-image` 只出 1:1 / 3:2 / 2:3，所以**只有封面**是「先出近比例再居中裁」。

### ★ 出血：四边铺满，不留白边（云批次踩到的坑）

**"安全边距"这四个字会被模型读成"在边上留空白"。** 云批次六张里有五张的中招程度不同，
按"整列每个像素都纯白（min(r,g,b) ≥ 246）"量出来的四边空白：

| 文件                 | 左       | 右       | 外 8% 竖条的近白占比（左 / 右） |
| -------------------- | -------- | -------- | ------------------------------- |
| `cover.webp`         | 0.0%     | 0.0%     | —                               |
| `spread-1.webp`      | 0.0%     | 0.0%     | 42.5% / 26.9%                   |
| `spread-2.webp`      | 0.0%     | 0.0%     | 72.0% / 52.6%                   |
| **`spread-3.webp`**  | **3.0%** | **3.2%** | **89.1% / 90.4%**               |
| **`spread-4a.webp`** | 0.0%     | 0.0%     | **62.0% / 85.8%**               |
| **`spread-4b.webp`** | 0.0%     | 0.0%     | **68.6% / 87.5%**               |

> ⚠️ 加粗的三行是**返工前**的数。三张都已重出，现在的数字见本节的
> 「2026-10-12 的返工进度」——四边纯白列都是 0.0%、右缘近白降到 60–66%。

`spread-3` 是真的平涂白纸边（把左右各 3% 的白列排除后，画面只剩 1186×632）。
其余四张的边是**很淡很淡的水彩天空**——不是纯白，所以按"整列纯白"量是 0%，但翻到书上
就是两道空。**两种都算不合格**，判据要同时看这两列数字。

> 这三张的 1264×632 是**当时**按 2:1 落盘的尺寸（比例那步后来改成了 3:2，见 §五）。
> 比例改了，判据与这条教训都不变：重出时按 3:2（1536×1024）出图、按 3:2 落盘，
> 两张表里的百分比照旧按同一套脚本量。

**这不是尺寸问题，是提示词问题。** 图本身是精确的成品比例，前端
`background-size: 200% 100%` 把两个半幅一一对上页面，一个像素都不缺。
空白是画在画里的，所以只能改提示词重出，前端无解。

**改法：每条提示词里，把「左右各留 6% 安全边距」换掉**，改成下面这一段（逐字带上）：

```
★ 画面必须铺满整张画布，是"出血"画法：四边不得出现白边、纸边、画框、装裱、渐隐或任何留白。
   天空与草地一直画到画面最外缘的每一个像素，边缘处的颜色与纹理要有水彩的颗粒，不许平涂留白。
   "安全边距"只指重要内容（小宇与小狗的脸、两朵云）离画面边缘保持距离，
   不是在边缘留空白——边缘要画满景物。
```

并且**逐张点名边缘画什么**（这是最有效的一句，只说"别留白"模型会给一条渐隐的带）：
跨页的边缘要给具体的东西——絮状的云尾、飘出去的花瓣状小云、草坡或树列的延续、
飞起来的餐巾或花瓣。见每条提示词的【构图】里新加的那一行。

> **定量验收**（出图后跑，判据是两列都为 0 且近白占比 < 25%）：
> `.claude/tmp/measure-margins.py`（整列纯白）与 `.claude/tmp/edge-empty.py`（外 8% 近白占比）。
> 这两个脚本是临时工具、不入库，重出图前按上面的判据重写一遍即可。

### ★ 中缝：一张连续的画面，中央不许有接缝（云批次踩到的第二个坑）

**五张跨页全部在水平 50% 处有一条可见的竖向突变**，翻到书上正好落在书脊上，
看着像一道折痕或两页没对齐。定量证据（`spread-*.webp`，逐列相邻像素平均绝对差；
下表是 **2026-10-12 重出 4a/4b 与 3 之后**重测的）：

| 文件             | 中缝带内峰值 / 带外峰值 | 比值      | 中央线两侧的平均色差（0–765） |
| ---------------- | ----------------------- | --------- | ----------------------------- |
| `spread-1.webp`  | 44.48 / 14.53           | **3.06×** | 28.0                          |
| `spread-2.webp`  | 78.72 / 14.48           | **5.44×** | **209.9**                     |
| `spread-3.webp`  | 37.63 / 12.12           | **3.11×** | 65.4（重出前 29.9）           |
| `spread-4a.webp` | 61.66 / 12.19           | **5.06×** | 46.4                          |
| `spread-4b.webp` | 69.85 / 13.26           | **5.27×** | **208.4**                     |

判据是**比值**而不是绝对值：水彩本来处处有跳变，所以看的是"中缝比画面别处锐多少"。
五张全部 ≥ 3×（阈值取 1.8），把 46%–54% 竖条裁出来放大后逐张肉眼复核，接缝都在。

`spread-2` 与 `spread-4b` 更重一档：中央线两侧的**平均色**差了 209 与 208（满量程 765），
也就是左右两半根本接不上——像两张不同的图并排。其余三张的色差在 28–66，
是"画出来的一条线"（云层引线、草坡分界），但那道线仍然正好落在书脊上。

> **`spread-3` 重出过一次，接缝没有跟着消失。** 这一张是按「★ 出血」那段重出的
> （左右白边从 3.0%/3.2% 降到 0%），但**它出图时中央接缝这一条还没写进提示词**，
> 所以只修掉了白边：比值从 3.97× 略降到 3.11×，色差反而从 30 升到 65，仍是合格线外的图。
> **这正好说明边缘与接缝是两个独立的失效点**——一次只改一处，另一处原样留着。

> 这一条与「不要画成书本的样子」那条负面清单**不重复**：那条说的是不要书脊、纸边、桌面，
> 五张都做到了（没有画纸、没有桌面）。但"中央有一条线"是**两回事**，清单里没写，
> 模型就自由发挥了。**凡是"不要出现 X"的清单，都要同时写"要出现什么"**——
> 这里要的是"整幅是一张连续的画面，左右两半必须能无缝拼在一起"。

**改法**：每条跨页提示词的【构图】里带上下面这一句（逐字），负面清单里也已加一条：

```
★ 整幅是一张**连续**的画面：画面中央（水平 50% 处）**不得**出现任何竖向接缝、折痕、
  装订沟、分格线或纸张边缘；左右两半的天空、云、草地与景物的颜色与明暗必须连续过渡，
  不许出现"两张图并排"那种突变。书脊是成品书加上的，不是画面里画出来的。
```

> **验收**：`.claude/tmp/check-4a4b.py` 的接缝一段（`SEAM = 0.08`，阈值 1.8×）。
> 这个脚本与上面两个量边距的一样是临时工具、不入库；重出图前按同一判据重写一遍即可。

## 二、共用锚点（所有提示词逐字保留）

### 小宇的身份锚点

```
小宇，约 5 岁的东亚小男孩：圆脸、皮肤暖白、脸颊两团淡粉；一双深棕近黑的大眼睛，
眼距略宽，睫毛短；鼻子一个小圆点，嘴小，笑起来露一点门牙；乌黑顺直的短发，额前是
自然垂下的碎刘海，发尾服帖不外翘；身穿浅色短袖 T 恤，领口与袖口各有一圈细彩边，
胸前不印任何图案；下身是宽松的深色长裤，脚上白色短袜、深色小布鞋；身高约 4 个头身，
手脚圆润短小。
以上任何一项都不得改动：不换发型、不换发色、不换衣服配色、不长高、不换鞋袜。
```

### 小狗的身份锚点

```
一只小狗，中华田园犬幼犬：毛色奶黄与白相间，背与两耳偏奶黄，胸口、四爪与尾尖偏白；
耳朵半垂，尾巴蓬松下垂；脖颈上不戴任何项圈、铃铛或挂饰。体型是幼犬，不是成犬。
它每一页都在，但姿态可以变；毛色分布不许变。
```

### 风格段

```
温暖的手绘绘本风：水彩铺色打底 + 细彩铅轮廓线收形，可见纸质纹理，笔触松弛但不潦草。
高明度、低饱和的粉彩色板，只用一个暖色重音（正午阳光落在草地上的暖金，与野餐垫上
那一小块砖红格纹）。阴影柔和无硬边。统一光源来自左上方，色温暖白。
与同一系列已完成的 12 张绘本封面是同一位画师、同一套颜料、同一次绘制。
```

### 关键设定：这是草地上的想象，不是真的飞上天

```
小宇躺在草坡的野餐垫上看云，他"上去"的是云的形状本身——整个故事发生在同一片草地与
天空之下，画面里必须始终留有真实线索：米白与砖红细格纹的野餐垫、藤编野餐篮、两三个
青苹果、那只小狗、远处缓缓起伏的草坡与一排树。
不要画成真正的热气球吊篮、滑翔翼、飞行器、飞行服、护目镜或高空失重。
云是软的、低的、可以坐靠的；小宇始终坐在云上或靠在云里，不要出现被甩出去、坠落、
或者高到完全看不见地面的画面。
```

### 负面清单（沿用 `cover-art-prompts.md` §二，末尾追加本书专用八条）

```
不要任何文字/字母/数字/水印/签名；不要品牌 Logo、卡通 IP 角色、商标或商品包装；
不要恐怖、阴森、暴力、受伤、哭泣、争吵、或被冷落孤单的形象；
不要危险动作（明火、高处无防护、深水涉水、无成年人看护的独处险境）；
不要写实到失真的人脸；不要深色压抑、赛博朋克、霓虹或高饱和撞色；
不要杂乱堆砌的背景细节；不要多格分镜、拼贴、样机、画框或阴影底板；
不要强透视导致的形变。
—— 以下为本书专用 ——
不要把画面画成"一本打开的书"的样子：不要书脊、纸张边缘、桌面、底板、投影背景板，只要插画本身。
不要出现第二个小孩，也不要成人的手或身体入画——这本书里只有小宇一个孩子。
★ 不要把云画成写实的恐龙或船。轮廓要"恰好像"，质地仍然是云：边缘有絮状的消散，
  身体里有水汽的半透明感；不许长出鳞片、眼睛、牙齿，也不许出现真实船板的木纹与缆绳。
  这是云这一题最容易出错的地方——模型会把它画成一只真恐龙浮在天上。
不要真正的飞行器、热气球吊篮、飞行服、护目镜或太空场景。
不要深黑色或暴风雨中的积雨云。天空必须是浅底、暖光、粉彩的。
★ 画面必须**铺满整张画布**，四边出血：不要白边、纸边、画框、装裱、留白或渐隐到白。
  天空与草地要画到最外缘的每一个像素，"安全边距"不是"在边上留空白"。
★ 整幅必须是**一张连续的画面**，中央不得有任何竖向接缝：不要中缝线、装订沟、折痕、
  分格线，也不许左右两半在颜色或明暗上突变（看起来像两张并排的图）。
  跨页在书上是**两个页面**，但源图里它们必须无缝相连——书脊是我们前端加的，不是画出来的。
★ 主体（小宇的脸与身体主干）不得落在画面水平 46%–54% 这条带上——那是书脊会穿过的地方。
  这是全套里唯一一条「画完就救不回来」的约束：裁切、压缩、前端都改不了它。
```

## 三、P0 · 设定表（不进仓库，只作后续参考图）

**参考图**：`public/art/cloud.webp`　**输出**：竖版 2:3（1024×1536）

```
儿童绘本主角的角色设定表，用途是后续多张跨页插画的一致性参考。
请以附上的参考图里那个短发小男孩为同一个人来画，旁边那只小狗也要一起锁下来。

【身份锚点】
（逐字贴 §二的「小宇的身份锚点」+「小狗的身份锚点」）

【版式】
干净的暖白纸色背景（接近 #f6eddc），无场景、无道具、无地面投影。
```

> **这一处最值得记的不是接缝本身，是它漏出去的原因。** 负面清单里那条
> 「不要把画面画成"一本打开的书"的样子：不要书脊、纸张边缘、桌面、底板」
> **五张全都做到了**——没有一张画了纸或桌面。失效的是它写作的方式：
> **清单只说"不要什么"，没说"要什么"**，于是模型在"中央"这块没被约束的地方自由发挥，
> 把跨页当成了两个可以各自构图的半幅。
> 书上那条通用规矩：**每加一条"不要 X"，都要在同一段里补一句"要是 Y"**。
> 这条与书脊带那条并列，是这套出图里仅有的两条「画完就救不回来」的约束。

**比例：跨页从 2:1 改成 3:2（2026-10-12 定，与上一件一起做）**：原来的规格里，
一张 2:1 跨页 = 两个 **1:1** 的页面，而封面是 **3:4**，两者对不上——合着的书只有一页宽，
3:4 的封面塞进 1:1 的页面只能上下各裁掉约 12.5%（当时实测六个候选裁位，居中裁保住了
左右两朵云与小宇的脸，所以能用，但这是在将就）。当时记下的两条出路，**选了后一条**：

- ~~封面按 1:1 出图~~；或
- **跨页按 3:2 出图、不裁切** → 半张跨页 = **3:4 的页面**，与 3:4 的封面严丝合缝。

成本核算（三处都动了，不是零成本）：

| 位置                    | 改动                                                             |
| ----------------------- | ---------------------------------------------------------------- |
| `scripts/make-webp.py`  | `book-spread` 预设 `(2,1,1536,220K)` → `(3,2,1536,220K)`         |
| `storybook-flip.css` §1 | `.book` 的 `aspect-ratio: 2/1` → `3/2`，宽度上限加一条 `90vh`    |
| `storybook-flip.css` §7 | 静止模式的跨页框同样 3:2；封面的专用框 `1/1` → `3/4`（正好不裁） |

**`90vh` 那条上限不是随手加的**：3:2 的书比 2:1 高 1/3，若只按宽度定尺寸，书顶边会抬高
（首屏交接的三处时间契约会跟着错），书底边还会顶到收尾 CTA。夹到书高 = 60vh 之后，
顶边落在 (100vh − 60vh)/2 = **20vh**，与 2:1 时代 1440×900 下实测的 20.4vh 几乎重合，
**首屏那三个数一个都不用动**。推导写在 `storybook-flip.css` §1 的注释里。

> 副作用要说清楚：书高被 60vh 钉住之后，同一视口下**书会比以前窄 1/4**
> （1440×900 下 1065px → 810px，页面从 533×533 变成 405×540）。
> 换来的是页面真的是 3:4 的书页比例，并且封面落进去不再被裁。

源图本来就是 3:2（1264×848），2:1 是把上下 12% 当作"留给刀的安全边距"裁掉的——
而那 12% 本来也是照裁后画面构的图，不裁一样成立。**重出时按 3:2（1536×1024）出，
落盘后尺寸为 1536×1024（如果还是只给到 1264×848，就落 1264×848，仍然不裁）。**



```bash
python -I scripts/make-webp.py <源图目录> public/book --preset book-icon --match 'choice-*'
```

三条都要跑：封面是 3:4、跨页是 3:2、图标是 1:1，比例不同不能合并。源图按 §一 的产物名命名
（`cover.jpg`、`spread-*.jpg` 与 `choice-*.jpg`），所以不需要 `--name` 改名——`--match`
直接按前缀筛，三条命令可以指向同一个源图目录。

跨页与图标那两条**不裁**：它们的源图比例与预设一致，`crop_to_ratio` 是恒等变换；
只有封面那条真的下刀（2:3 → 3:4）。

脚本只裁不补：**源图裁完比目标窄就按原样落盘并告警**，绝不放大——缺的像素补不回来。
看到 `偏小` 告警请回头重出图，不要改脚本里的数字。
