# 输入框上方 12 个「站着的小主角」——出图提示词

> 用途：工作台 `/home` 那一屏，输入卡上方站着的那个孩子（`src/components/studio/CreateLanding.tsx`
> 的 `.cl__figure`）。**它只跟随主题墙**——点哪张封面就站哪个孩子，没有第二个来源
> （曾经有过"侧栏底部换人头像 + 手选覆盖主题"那一套，2026-10-15 按用户要求整块拆掉，
> 理由见 docs/known-tradeoffs.md）。
> 产物：`public/figures/{key}.webp`（2:3 / 256px 宽 / 透明底 WebP）。
> 转换脚本：先 [`scripts/cutout.py`](../scripts/cutout.py) 去底，再
> [`scripts/make-webp.py`](../scripts/make-webp.py) `--preset figure` 缩档。
> 选用的风格库模板：**`character-design-sheet`（角色设定表）的身份锚点纪律** +
> **`illustration-art-style`（插画与艺术风格）**——后者就是
> [`cover-art-prompts.md`](cover-art-prompts.md) 那 12 张封面当初用的那一个。
> 关联：`src/lib/figures.ts` 的表、`src/lib/themes.ts` 的 `THEME_KEYS`。

---

## 一、这批图要同时满足的四条约束

前三条来自已经定稿的实现，不是审美偏好：

| 约束                                   | 来源                                                       | 对提示词的要求                                                                           |
| -------------------------------------- | ---------------------------------------------------------- | ---------------------------------------------------------------------------------------- |
| **显示高度只有 120–168px，而且是全身** | `create-landing.css` 的 `.cl__figure`                      | 剪影必须干净：一条腿、一只手、一件道具就够，多一根线在小尺寸上就是噪点                   |
| **要抠成透明底摆在天上**               | 页面背景是 `StudioBackdrop` 那片渐变（`--paper: #f4f8f9`） | 背景必须是**单一平涂的纯白**，不能有地面、投影、纹理、外发光——任何一样都会跟着一起被留下 |
| **12 个要和 12 张封面是同一支笔画的**  | 他们本来就出自同一张封面                                   | 必须**带参考图出图**，且 `【风格】` 那一段一字不改                                       |
| **他是"从那张封面里走出来的同一个人"** | 产品主张：每一页都是同一个他                               | 脸、发型、衣服款式与颜色**不许改**；改姿势可以，换衣服不行                               |

再加一条题材要求，与封面那批同源：**这是孩子站着的样子，不是"可爱吉祥物"**。
不要大头身、不要 Q 版二头身、不要 3D 盲盒公仔——那正好是这次要避开的参考做法。
比例沿用封面里那个孩子的实际年龄感（5–8 岁，约 5–6 头身）。

## 二、通用骨架（每张都用这一段）

复制这一段，把 `【参考图】` / `【姿势与取景】` / `【道具】` 三段换成第三节对应那一条，就是一张完整的提示词。

```
儿童绘本角色立绘，竖版，一张完整画面（不是拼贴、不是多格分镜、不是设定表、不是画框样机）。

【参考图】
（替换为第三节对应的一条）

【姿势与取景】
（替换为第三节对应的一条）

【道具】
（替换为第三节对应的一条）

【背景】
纯白 #FFFFFF 单一平涂：无纹理、无地面、无投影、无接触阴影、无光晕、无外描边。
人物边缘干净，方便后期抠图。

【人物】
东亚面孔的儿童，日常衣着，健康、有活力、表情自然；神态专注或开心，不做夸张变形。

【风格】
温暖的手绘绘本风：水彩铺色打底 + 细彩铅轮廓线收形，可见纸质纹理，笔触松弛但不潦草。
高明度、低饱和的粉彩色板，只用一个暖色重音。阴影柔和无硬边。统一光源来自左上方。

【文字】
画面内不出现任何文字、字母、数字、签名或水印。

【输出】
竖版，2:3。

【负面】
不要多格分镜、角色设定表、正侧背三视图、动作网格；不要拼贴、样机、画框、色板底板；
不要 3D 渲染、盲盒公仔、黏土质感、塑料光泽（这批是画，不是玩具）；
不要地面、投影、背景纹理、外发光；不要裁掉头顶或脚底；
不要任何文字/字母/数字/水印/签名；不要品牌 Logo、卡通 IP 角色、商标或商品包装；
不要恐怖、阴森、暴力、受伤、哭泣、争吵、或被冷落孤单的形象；不要危险动作；
不要写实到失真的人脸；不要深色压抑、赛博朋克、霓虹或高饱和撞色；不要强透视导致的形变。
```

★ `【人物】` 与 `【风格】` 两段**一个字都不要改**。理由不是"统一好看"，是
[cover-art-prompts.md §六](cover-art-prompts.md) 那条付过学费的判断：
"改一个字，第 7 张和第 3 张就会明显不是一套。"

★ 背景要**纯白**而不是绿幕/品红，两个理由：

1. 这批画有细彩铅轮廓线收形，**被轮廓封住的白高光不与画面边框连通**，
   去底脚本的"从四边泛洪"吃不到它；换成色键，轮廓内的白会被整片吃掉。
2. 页面底色本身就近白（`--paper: #f4f8f9`），万一边缘留一圈白也读不出来；
   而饱和色键必然在描边像素上留一圈品红/绿色溢，在那片天上非常显眼。

## 三、12 张的锚点

顺序与 `src/lib/themes.ts` 的 `THEME_KEYS` 一字不差（`dino` 是默认站着的那一个）。
每张给出要替换进骨架的三段。**出图时把 `public/art/{key}.webp` 原文件一起作为参考图传进去。**

★ 加粗的那一句是这一张单独要盯的地方——模型最容易在这里出错。

### 1. 🦕 恐龙 → `dino.webp`

**【参考图】**
附上 public/art/dino.webp。画面里蹲在蕨叶间、和长颈龙一起低头看一朵小白花的那个**扎双马尾的小女孩**就是本人，照她画。
必须与参考图一致：脸型与五官、双马尾的发型与发色、橙色外套的款式和颜色、下装、鞋子、肤色与年龄感，色彩重音就是那件橙色外套。
保持参考图的画风、纸质纹理和轮廓线粗细不变。
**长颈龙、蕨丛、薄雾与光柱都不要画进画面。**

**【姿势与取景】**
从参考图里的「蹲着」改成自然站立：正面略偏 3/4，双臂放松垂在身侧，重心落在两只脚上。全身从头到脚完整入画，头顶与脚下各留约 8% 空白。不弯腰、不蹲、不坐、不躺、不跳。

**【道具】**
只带这一件：那朵小白花，捏在一只手的指尖。除此之外手上、身上、口袋里不添任何东西。

## 五、怎么保持 12 张是一套

1. **先出 2 张定调**：`dino`（白天、有道具、轮廓最复杂）+ `moon`（源图是夜景，换白底最容易暴露色温漂移）。这两张过了再批量出剩下 10 张。
2. **每张都带参考图**，不要靠文字重描那个孩子——文字只用来指定"谁是本人""什么不入画""换什么姿势"。
3. **`【人物】` 与 `【风格】` 两段一字不改**（见 §二 那条）。
4. **出完 12 张并排检一遍**：同一支笔？同一个完成度？头身比是否一致？有没有人被裁掉脚？白底是不是真的纯白（有没有偷偷画了地面或一层淡影）？
5. **优先在同一张上多滚几版挑一版**，别重开描述——与封面那批同一条。

## 六、落地：去底 → 缩档

源图（纯白底 PNG/JPG）先落到一个目录，比如 `~/figures-src/`，然后两步：

```bash
python -I scripts/cutout.py ~/figures-src .out/figures-rgba
```

```bash
python -I scripts/make-webp.py .out/figures-rgba public/figures --preset figure
```

| 项     | 值                                                                                                                                          |
| ------ | ------------------------------------------------------------------------------------------------------------------------------------------- |
| 文件名 | `public/figures/{dino,paint,rocket,bird,star,moon,whale,castle,cloud,flower,turtle,balloon}.webp`                                           |
| 预设   | `figure`：2:3 / 目标宽 256 / 单张上限 22 KB（**上限是预算**；下面那一行是实测）                                                             |
| 实测   | 逐张 **10–17 KB**、合计 **0.15 MB**、平均 **13 KB**；源图 6.47 MB → **44.0×**（2026-10-15 落地那一版，`make-webp.py` 自己打的那一行）       |
| 比例   | 12 张合计预算 ≤ 264 KB，实测 0.15 MB                                                                                                        |
| 格式   | WebP，**保留 alpha**（`make-webp.py` 里 `ALPHA_PRESETS` 那一档）                                                                            |
| 裁切   | 会居中裁到 2:3。出图时主体四周那 8% 空白就是留给这一刀的                                                                                    |
| 接入   | `src/lib/figures.ts` 的 `figurePath(key)`——文件名只由主题 `key` 决定，与 `artPath()` / `themeCardPath()` 同一条约定，**对不上就是一张裂图** |

★ 不走 `/api/assets?w=`：静态 `public/` 走不到那条通路（Next 直接发盘上的字节，查询串它看不懂，挂 `?w=` 会静悄悄回原图，docs/known-tradeoffs.md「缩略档」那条）。所以预生成。

★ 256px 这一档现在只有**一个**消费者：卡片上方那个 120–168px 高的立绘（2× 屏够）。侧栏那 44px 头像随切换器一起拆了，所以**第二档不用开了**——为 44px 再出一份小图是"同一个东西两份画"（`chip-icon` 那一档被删掉的理由记在 `make-webp.py` 的文件头）。

### 去底（`cutout.py` 三个旗标为什么是这三个数）

落那一版用的是 `--tol 2 --choke 0 --min-island 40`。**三个数里两个不是默认值，都是量出来的**，
机制与完整实测写在 [`scripts/cutout.py`](../scripts/cutout.py) 的文件头。两条结论：

- **白底必须用"边缘连通泛洪"，不能用全局色键。** 这批画里**白是颜料**：轮廓线把内部的白封住，
  泛洪够不到，于是保住了。这是量出来的两档读数：`--tol 2` 下「最大封闭白块」只有 0.2%～0.5%、
  均色 **纯白 (255,255,255)**（`whale` 那张 5288 px，bbox 在脸上——眼白）；放宽到 `--tol 12`，
  `flower` 那张同一块**跳到 3.9%**、`边缘残留` 从 0 变成 1～5 px。全局色键就是在人脸上打洞。
- **`--tol` 不是越大越干净。** `--tol 12` 会吃掉一条拴气球的线（那条线本身近白，泛洪顺着它
  抹掉了它，症状是气球与手脱开）；压到 2 保住它，但 JPEG 噪声会成片留下，所以必须配
  `--min-island 40` 抹孤岛。**判据是连通块，不是眼看。**

### 验收（素材侧）

`cutout.py` 会逐张打印四个体检数：

- `alpha 覆盖率 %` —— 太低说明底色根本没被认出来（源图不是白底），太高说明吃进了人物。
- `边缘残留` —— 仍不透明、本身接近白、且紧贴透明区的像素数。非 0 就是边缘没去净，会在那片天上露出一圈白。
- `最大封闭白块` —— 轮廓内不与四边连通的近白块里最大的那块。有是**对的**（眼白与高光本该留下），
  但出现在本该是背景的地方就说明那一张背景不纯。
- `抹掉噪点 N 块/N px` —— `drop_islands` 删掉的孤岛。这一档是紧阈值的代价，也是它的解药。

★ 脚本判不过的一律打 `边缘可疑` 并列进末尾清单，**交人眼逐张过**；不许把"没测成"记成"测出来"。源图压根不是白底（模型偷偷画了地面）时脚本直接报错退出，而不是产出一张半透明的怪图。

**落地那一版的验收记录**（2026-10-15，12 张，848×1264 源图）：

| 判据                  | 结果                                                                          |
| --------------------- | ----------------------------------------------------------------------------- |
| `边缘残留`            | 12 张**全为 0**                                                               |
| `最大封闭白块`        | 全部 ≤ 0.5%，且均色为纯白 (255,255,255)——落在脸上（眼白），没有出现在背景位置 |
| 抹掉的噪点            | 每张 240～1010 块——与"紧阈值留下的 JPEG 噪声"这条预期吻合                     |
| 最终 256px 的连通块数 | 每张 ≤ 4，且除主体外**全部小于 20px**（气球那个 4310px 的独立岛没有了）       |
| 12 张拼在深色垫板上看 | 边缘无灰边/白雾，气球读作**被握在手里**（主体连通块 bbox 从 y=24 起）         |
