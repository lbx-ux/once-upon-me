# 启动期清单：组队 · 报名 · 缴费

> 定位：**参赛资格**这一条线上的操作清单，与产品开发无关，因此单独一个文件。
> 依据：2026 第九届传智杯 · AI WEB 网页开发挑战赛（赛道 ID `10037`）官方赛道详情页与报名通知。
> 官方规则全文整理在仓库外，本文件只摘**会卡住我们的那些条款**，并注明出处章节。
> **本文件里的时间是硬约束，产品开发的周计划可以挪，这些不能。**
> **状态（2026-10-12）：报名 ✓ 缴费 ✓** —— 剩下的格子是"确认入口可见"与"提交物自查"。

---

## §0 三件事的依赖顺序

```
组队（同校 1–3 人）                    ✓
   │  逐人核对学校属性 → 定组别（★ 选错直接取消资格）
   ▼
报名（赛道 10037）                     ✓   ── 报名截止 2026-11-18
   │
   ▼
缴费                                   ✓   ── ★ 提交入口的前提
   │
   ▼
作品提交（2026-11-18 截止，与报名截止同一天）   ← 现在唯一还压着时间的节点
```

**两条来自官方原文的风险，合起来意味着这件事不能拖**：

1. 「本次省赛作品提交入口需参赛者**完成缴费后**，登录赛事个人中心所报赛项查看，
   不再单独提供外部链接」（官方 §7.1）
2. 报名截止与作品提交截止是**同一天**（2026-11-18，官方 §一）

而**省赛一经报名成功，组委会不接受任何形式的退赛申请**（官方 §十二 注）。
所以顺序上：**先把组别核对清楚再交钱**，交完就退不回来了。

## §1 组队

- [x] 队员 **1–3 人**，且**同一所学校**（官方 §4.1）
- [x] 指导老师**不超过 2 名**（官方 §4.1）
- [x] **逐人核对学校属性，确定组别**（见 §2，这是唯一会直接取消资格的一条）

> 这三项打勾的依据是**报名已完成**——报名流程要求填这几项。
> 但"填了"和"填对了"不是一件事：**组别报错是取消资格级的问题，而报名后改不了**。
> 花一分钟按 §2 那张表复核一次，成本远低于后果。

> 参赛资格范围（官方 §4.1）：普通高等院校、高职院校、二级学院、独立学院、
> 本/专科在校大学生及研究生均可报名；其他社会人员亦可。

## §2 ★ 组别：唯一会直接取消资格的选择

| 组别     | 适用对象                        | 报名规则                                    |
| -------- | ------------------------------- | ------------------------------------------- |
| 研究生组 | 研究生                          | 只能报研究生组                              |
| **A 组** | **985 / 211 高校本科生**        | 只能报 A 组或更高（研究生组）               |
| B 组     | 非 985/211 的普通本科院校本科生 | 可报 B 组或更高（A 组、研究生组）           |
| C 组     | 高职高专院校学生                | 可报 C 组或任意更高（B 组、A 组、研究生组） |

> ⚠️ 官方原文：「如经发现参赛队**未按规定选择正确组别，将无条件取消其参赛资格及所有成绩**。」
> **队内只要有一个人是 985/211，整队就按最高那一档报。** 逐人核对，不要凭印象。

## §4 提交物红线速查（省赛与国赛一致，官方 §11）

这一节现在看是为了**反向安排开发排期**：哪些东西从第一周就得攒，不能最后补。

| 提交物   | 硬要求                                                                   | 现在就要开始的理由                                                              |
| -------- | ------------------------------------------------------------------------ | ------------------------------------------------------------------------------- |
| 代码仓库 | GitHub / Gitee，**Public** 或给评审访问权限                              | 仓库首页与 README 是评委第一眼                                                  |
| Git 记录 | **保留完整的提交历史，体现真实开发过程**（官方 §11.1）                   | 最后一次性倒进去 = 直接违背这一条                                               |

| 环境配置 | `.env.example` + 依赖清单；**仓库内不得有任何 API Key**（官方 §11.5）    | 已有 `.env.example`，保持住                                                     |

## §6 要咨询组委会时

官方规则里有两处**前后不一致**，报名后值得问一次（细则见官方规则整理文档第十五节）：

1. 国赛奖项比例两处不一致（二等奖 20% vs 25%、三等奖 30% vs 35%）
2. 省赛提交时间表述矛盾：一处写「11/18 截止」，另一处写「反馈后再完成最终提交」

**按最紧的解读准备**（11/18 交出完整作品），同时问清口径。
咨询渠道与赛区联系人在官网赛道详情页（ID 10037）与官方规则文档 §十六，
**不在这里复述联系方式**——本仓库是公开的。
