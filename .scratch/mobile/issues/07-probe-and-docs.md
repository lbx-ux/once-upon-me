# 07 · 探针与文档

Status: done

## 新探针 `scripts/chk-mobile.mjs`

无头 Chrome 直连 CDP、取真帧 —— 照 `chk-reader-desk.mjs` 的分法。
★ **不进预览面板**：那个面板把 rAF 与 transition 一起冻住，量几何会读到过渡起点
（那两条账记在 `chk-reader-desk.mjs` 与 `chk-shared-reader.mjs` 的文件头）。

五条判据，每条都取"只有真做才会不同"的量：

| #   | 量什么                                                                    | 错了会怎样                                                     |
| --- | ------------------------------------------------------------------------- | -------------------------------------------------------------- |
| 1   | 五个视口 × 八条路由：`documentElement.scrollWidth <= clientWidth + 1`     | 手机上整页横着能拖（这一轮要修的那件事本身）                   |
| 2   | 844×390 下书的高 ≥ 0.80 × 视口高                                          | "横放在屏幕上"没做到（竖屏那一档必然 ~0.28，**这条有判别力**） |
| 3   | 390×844 下 `.rotate-hint` 可见、844×390 下不可见                          | 提示不出现 / 横屏还挡着                                        |
| 4   | 派发真触摸事件后**读出那一行的文字变了**，且拖动**中途** `q` 落在两叶之间 | 滑动没接上 / 不是跟手（先不动再跳）                            |
| 5   | 阅读器两台 + 底部标签栏里每个可点元素 ≥ 44×44                             | 手指点不准                                                     |

★ 判据 3 的内容是 `getComputedStyle` 的 `display/visibility` **加上矩形非零** ——
"在不在 DOM 里"证明不了"看不看得见"（SSR 的 HTML 里元素本来就在）。
★ 判据 4 的判据取**文字变了**而不是"某个变量变了"：前者只有真翻页才会不同。
