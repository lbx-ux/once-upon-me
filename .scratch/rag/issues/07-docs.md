### 2. ★ 与工单原文的一处偏差：**没有加 `providers/embeddings.ts`**

工单写的是「§二 引擎层那张树图加 `rag/` 与 `providers/embeddings.ts`」。
**那半句不成立了**——它写于工单 01 探针之前。探针的读数（spec §二.4）是
**这把 key 上没有任何可用的嵌入模型**，于是 spec §四 当场把 `providers/embeddings.ts`、
`EMBEDDING_*`、`Retriever` 接口一起撤掉了，理由是「**不写一个用不上的配置项**」
（同一条纪律：`example-wishes.ts` 那句"留一个没人读的表，下一个改的人会漏改它"）。
所以树图里只有 `rag/`，而"为什么没有 embeddings.ts"这件事**写进了 ADR-0011 与 GLOSSARY 的「检索档」**
——**撤掉一个东西也得留个说法**，否则下一个人会以为是漏写的。
