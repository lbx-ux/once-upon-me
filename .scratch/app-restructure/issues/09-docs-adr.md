## 一、必须改的两条（有实测证据，不是润色）

### 1.1 `IMAGE_SUPPORTS_REFERENCE` / README §五 / `.scratch/w2-solo-flow/spec.md`

- 事实：`POST /v1/images/edits` **可用**，`wan2.7-image` **不需要换**（[spec §1.1](../spec.md)）
- 现状：`IMAGE_SUPPORTS_REFERENCE=0`、`.env.local` 里也是 0、
  `.scratch/w2-solo-flow/spec.md` §一 第 4 条与 §四 都写着"供应商不支持参考图"
- 危害等级 **最高**：它是一条**否定结论**，会把后来者挡住——不试就是"已经有结论了"。
  而且 W1 的探法（试 7 个字段名）**看起来像**已经试过了，最难被质疑。
- 改法：三处都改，并在改后的位置**留一句 W1 为什么错了**（"只在 `/generations` 上试字段名，
  没试 `/edits` 这条路由"）。★ 留这一句比改数字更重要——它是"怎么错"的样本

### 1.2 TTS 推迟的口径

- 旧：W2 spec 口径 2 + README §五「选择点」的"拆掉播放条"
- 新：TTS 进入本轮（[08](08-voice.md)）
- 改法：**不是**把旧理由删掉，是**保留它并说明它现在约束什么**——
  "播放条被拆掉的教训是'控件在而能力不在'，这条教训现在约束的是
  **整本能不能响**，而不是'要不要做声音'"

## 三、ADR：两条新的 + 一条复查

| ADR  | 主题                                                | 为什么需要                                                                                                                                        |
| ---- | --------------------------------------------------- | ------------------------------------------------------------------------------------------------------------------------------------------------- |
| 新   | **角色档案是第一等资产**（或：ADR-0007 的界面兑现） | "孩子"从一个表单字段变成可复用实体，删孩子要连带删他的卡与书——这是**不可逆操作的边界**，值得一条 ADR                                              |

| 复查 | **ADR-0008**（BYO 模型与 key）                      | 设置抽屉把 key 的采集位置换了，**决策本身没变**（仍是 per-request Env）——所以是复查加一句"实现位置变了，决策不变"，**不是**写新 ADR               |

## 四、答辩口径的改写（#5 那一章）

改后的说法（[spec §二之补](../spec.md) 第 4 条）：

> 默认角色是**合成的**，我们不需要任何真孩子；家长要给自己孩子做书时，
> 走**单独授权**的上传，有同意、有删除凭据、原图不留在我们的库里。

★ 这句必须与代码一致，所以要**核对一遍**再写进文档：
`deleteChild` 是不是真的报数、原图是不是真的不落盘、`events.jsonl` 里是不是真的没有图像字节。
**文档写完要能对着代码逐条指认**，不能是"我们打算这么做"。
