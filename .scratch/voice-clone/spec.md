# 用自己的声音：录音 → 音色 → 能删

用户 2026-10-16 在 `/voice` 的截图上划掉了三处（页头说明、卡脚那行"音色 id + 绑定模型"、
「用自己的声音 · 还没做」那一块），并在右上角要一颗**「新建声音」**；
问过之后他选的是：**这一轮真把录音克隆做了**（不是摆一颗点开说"还没做"的按钮）。

这是 `app-restructure/08-voice` 里那句「用自己的声音还没做」的**兑现**。
那一单把引擎侧的闭环量完了（`create_voice` → 用它合成 → `delete_voice` → 删后再合成 400 →
`list_voice` 归零），并且量到一条**很关键的好消息**：`create_voice` 的 `url` 字段收
`data:audio/mpeg;base64,…`（实测 200），所以**样本从不需要放到任何可访问的地址上**。
这一轮做的就是界面那半。

## 一、这一轮做出来的东西

`.storage` 之外只有一句话：**家长录一段自己的声音 → 得到一条只属于自己的音色 →
不想要时能删掉**，中间每一步都看得见（在录、录了多久、正在生成、生成好了没）。

| 步骤           | 界面上的样子                                | 判据（怎么算这一条成立）                                                                                                        |
| -------------- | ------------------------------------------- | ------------------------------------------------------------------------------------------------------------------------------- |
| 1 同意         | 面板第一屏一段话 + 一个勾，勾了才出现录音钮 | ★ 同意是**每次新建一条音色都要过一次**，不是勾一次全站通吃                                                                      |
| 2 采集         | 「开始录音」+ 计时；或「选一个音频文件」    | 录到的音频**必须是厂商收的格式**（WAV 16bit / MP3 / M4A，≥16kHz，10–20 秒为宜，≤60 秒、≤10MB）                                  |
| 3 试听自己那段 | 录完先能听**你刚录的这一段**                | 听的是样本，不是合成结果——"录歪了"要在花钱之前发现                                                                              |
| 4 生成         | 一个按钮 + 生成中的真实状态                 | 真调 `create_voice`；拿到 voice_id 才算成                                                                                       |
| 5 能听         | 新卡上「听一句真的」                        | 刚创建的音色**立刻合成一次**：成了才说"能用了"，没成就如实说"还在部署中"（`list_voice` 里新建的 status 是 `DEPLOYING`，实测过） |
| 6 能删         | 卡上一颗「删掉它」→ 两步确认 → 报数凭据     | 真调 `delete_voice`；删完再说"还能不能用来合成"（实测：删后再合成 400）                                                         |

## 二、四条已经写死、这一轮照着做的规矩

1. **样本不留存**（§8.3 原文："30 秒声音样本（原始）不保留，拿到 voice_id 后立即删"）。
   我们的实现比这条更硬：**样本从不上传以外的任何地方**——不进 localStorage、不落盘、
   不进事件日志，只活在内存与那一次请求体里（适配器把它编成 data URL 发出去，处理完即弃）。
   界面上要把这句话说出来。
2. **只录本人**（§8.4 口径）：界面明写"录你自己的声音"，不提供"录孩子"的引导。
3. **产出的说明**：告诉用户这是**合成语音**，不是保存了他的录音。
4. **key 仍只从请求体来**（ADR-0008）：创建与删除都走请求体里的 env，服务端
   `process.env` 不参与——与试听、探测同一条。

## 三、三个实现上的选择（有理由，改之前先读）

| 选择                           | 选定                                                                                          | 理由                                                                                                                                                                                                          |
| ------------------------------ | --------------------------------------------------------------------------------------------- | ------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- |
| 录到的音频怎么变成厂商收的格式 | **浏览器里解码 → 重采样成 16kHz 单声道 → 自己写 WAV 16bit**                                   | `MediaRecorder` 在 Chrome 上给的是 `audio/webm;codecs=opus`，**厂商不收**（只收 WAV/MP3/M4A）。转码要一个真解码器，而 `AudioContext.decodeAudioData` 就是浏览器自带的那个。顺带拿到**时长**，才能判"10–20 秒" |
| 「我的音色」存在哪             | **localStorage**（`xiaozhujue.voices.v1`：voiceId / 名字 / 建它时的模型 / 时间 / 授权凭据号） | voice_id **不是密钥**（它是个厂商侧标识符，`speech.voice` 本来就在持久层里），所以可以存；而 key 仍然只活在内存。存服务端要另建一套目录与清理，换来的只是"换浏览器也在"，不值当                               |
| 列表从哪来                     | **本地那份是列表，厂商是权威**                                                                | `VoiceSynthesizer` 接口上没有"列出我的音色"，加一个只为界面服务的枚举方法会把 seam 撑大。所以：卡片来自本地记录，而**能不能用**每次真问一次（合成 / 删除都是真调用）                                          |

## 四、与既有东西的接法

- **一个值只有一个家**：音色仍然是 `settings.speech.voice` 那一个字符串。
  克隆出来的音色只是把它**变成另一个合法取值**，不新开一个"当前克隆音色"的状态。
- 因此做书那几处（`/home` 的药丸、设置抽屉的两颗默认音色钮）列的是
  **预设 + 我的**合并表 —— 由 `SettingsProvider` 提供（它已经是那份设置的家）。
- **模型对不上就说出来**：克隆音色建的时候绑死在当时的 TTS_MODEL 上（实测跨模型 400）。
  当前模型与它记录的模型不一致时，卡上标明并且**不许选**——不然用户撞到的是一次 400，
  而界面上什么都没说。

## 三处落地时改了口径的地方（与工单原文不同，理由都在那边）

1. 录音的自动停在上限 **60 秒**（不是 20 秒），20 秒改成提示；
2. `/api/voice/clone` 只认我们客户端那一种容器（`audio/wav`）——转码在浏览器里做；
3. 「新建声音」的面板用**居中**浮层，不是右侧抽屉（它是一条有先后的流程）。
