# 02 · 家长那句自由输入过闸

Status: done（2026-10-19）
依赖：raz/05（条款库与 `review.ts`）
依据：[spec](spec.md)、`E:\compete\计划表.md` B3「还欠的三件」第 3 条

## 今天是什么样

`/create` 的第一句（`theme`，没挑模板时它就是家长那句话）、`wish`，
以及"重写一版"的要求（`reviseNote`）**直达提示词**——`prompts/story-plan.ts` 里
三处 `${input.…}` 原样拼接。既不经过任何词表，也进得了检索的 embedding 请求
（`retrieveOnce` 在 `planStory` 里排在提示词之前）。

## 要做的

- [ ] `engine/review.ts`：`reviewInput(fields)`——**纯函数**，与 `reviewText` 同源。
      产物里每条问题带上"是哪一格"（主题 / 那句话 / 改稿要求）。
- [ ] `engine/plan.ts`：`planStory` **最前面**跑一次，命中 → 抛 `review-blocked`，
      消息里带**条款 id + 命中的词 + 是哪一格**。
      位置的理由有两条，缺一不可：① 在**第一句提示词之前**；
      ② 在**检索之前**——`retrieveOnce` 会把这句话送去 embedding。
- [ ] `scripts/review-cases.mts`：加一组**家长输入**的用例。反例不能只拿样书正文凑，
      得是**人真的会打的那几句**（"他想当消防员""怕黑""学骑车摔了一跤"）。
- [ ] `review.test.ts` / 新的用例：`flag` 与 `block` 在这道闸上**处置是同一种**
      （都拒发），理由与 `illustrateBook` 第二道闸一样：**这是别人的话，没有"重写一版"这条路**。

## 验收

- [ ] 越线的家长输入**拒发**，错误消息里能看见条款 id 与那个词
- [ ] 反例表里**一条都不误拦**（含 12 个预设主题名、12 本样书的主题）
- [ ] 三条闸门 + `engine-run --mode=stub`

## 不做

- ✗ 不做界面级的即时校验（引擎层这一道是**必要**的：`/api/books` 与
  `story/rewrite` 两条路都直达引擎，拦在界面等于只拦住了浏览器）
- ✗ 不替家长改那句话（静默改写 = 静默降级，`errors.ts` 那条）

★ **判据选的是"调用次数 = 0"，不是"抛了错"**。只断言"抛了错"的话，把这道闸挪到
第一次模型调用**之后**也照样绿，而那样拦下来的东西**已经进过模型一次**——
那道闸的全部价值有一半就在这个 0 上（另一半是省一次文本调用的钱）。
与 `illustrate.ts` 那边"拦在第一张图之前"用的是同一条量法（那里量的是 `imageCalls === 0`）。

**★ 写反例时被自己的词表咬了一口，如实记下来**

起初想写「不想让他觉得自己是笨蛋」——那是一句家长真的会打的话。它是**会被拦的**：
`笨蛋` 在 R-05 的词表里。这一条没有删掉，它进了脚本里的 `INPUT_FALSE_POSITIVES_KNOWN`
一栏，报告里印成「漏过（已知）」：

- 没有放宽词表：`笨蛋` / `傻子` 是"按外貌或能力贬低角色"那条**唯一的机械抓手**，
  放宽它等于把那一整条交还给模型；而要放宽得**先拿 96 段样书重跑一遍**（改词表的纪律）。
- 也没有把它从用例里删掉——那会让"这条边界在哪"重新回到某个人的记忆里。
  这条与工单 05 那条**故意用委婉说法绕过**的反例是同一个用法：**把边界钉在纸上**。

**一处对计划的偏离：命名**

计划里那三格叫「家长那句自由输入（`/create` 的第一句）」。落地时审的是**三格**，不是一格：
`theme`（没挑模板时它就是家长那句话）、`wish`、以及 `reviseNote`（"重写一版"的要求）。
第三条是读代码时发现的——`story/rewrite` 那条路也把家长的原文拼进提示词
（`prompts/story-plan.ts` 的 `reviseNote` 那一段），而计划里那张单子上没有它。
★ 主角名字（`childName` / `nameReading`）**不过这道闸**，是有意的：
它是孩子档案上的字段，不是这一屏的自由输入，而且它进提示词的那一句
（"名字念 X，别念错"）把它当拼音标注用，不是当内容用。这一条写在 `reviewInput` 的注释里。
