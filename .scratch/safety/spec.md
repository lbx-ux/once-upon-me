## 为什么还要这两件

文字面那一道闸审的是**字**：正文、`scene`、`imagePrompt`、选择点那两句、书名。
它拦得住"模型写了一段吓人的话"，拦不住两件事：

1. **图上画出了不该出现的东西。** 生成图的那段文字描述（`imagePrompt`）是审过的，
   所以缺口比听起来小——但**模型自己往图里加的东西**没有任何代码看过。
   一个 4 岁的孩子看不懂字，他看的就是那张图。
2. **家长那句自由输入。** `/create` 的第一句（`theme` / `wish`）与"重写一版"的要求
   （`reviseNote`）是**任意文本直达提示词**：它既不经过任何词表，也进得了检索的
   embedding 请求。家长写"小狗流血死掉的故事"，模型照做的可能性远高于它自己想起来写。

## 两件各自的判据形态**不一样**，这一点是全篇最要紧的

|                    | 画面审核                                                         | 家长输入过闸                                       |
| ------------------ | ---------------------------------------------------------------- | -------------------------------------------------- |
| 判据是什么         | **一个视觉模型的判断**                                           | **词表确定性扫描**（与文字面同一套）               |
| 可复现吗           | 不可复现                                                         | 可复现                                             |
| 所以它能做什么     | **兜底**：它是这条路上**唯一可用的仪器**（栅格图没有可枚举的词） | **判据**：命中一律拒，读数天天一样                 |
| 它**不许**宣称什么 | 不许说"覆盖了画面红线"                                           | 不许说"覆盖了红线"（谐音/拼音/委婉说法照旧是盲区） |

★ 这条分野不是修辞。`.scratch/rag/issues/05` 的「不做」里写着
「不把审核做成『再问一次大模型有没有问题』——那是没有判据的判据」。
那句话**对文字成立，对图不成立**：文字有词表，问模型是拿一个坏仪器换一个好仪器；
图没有词表，问视觉模型是**唯一有仪器**。
所以画面这一档落地时必须把身份写清楚：**它是兜底，不是判据**，
它的读数要配一次真跑量出来的误报率，而不是装成一条红线。

## 落地形状

1. **画面审核**：`providers/` 多一个能力 `PictureReviewer`（与 `VisionComparator` 分开成
   一个接口，理由与 `PortraitAnalyzer` 那条一样——问的问题不一样）。
   清单**不是**词表词，是**画面专用的判据**（`review-corpus.ts` 的 `PICTURE_CLAUSES`，
   六条，每条带一句「**不算**」），逐条答，产物是条款 id + 一句话说在哪儿。
   ★ 这里偏离过一版：**最初写的是 `LEXICON_CLAUSES` 那 6 条的条款原文**，
   拿盘上 87 张真图跑出来误报 **36.8%**（32 张），而且每一条的误报成因都是同一种写法——
   条款原文是**给"字"写的**（"无成年人看护的独处险境"、"死亡、丧亲的**情节或字眼**"），
   落到画面上就成了"一个人待着的孩子""低饱和的色调"。所以换成了画面专用的那一份；
   条款 id 不变，翻回 `REVIEW_CLAUSES` 仍查得到原始条款。细节见工单 01 的 Comments。
   落在 `illustrateNode` 出图之后
   （**页**在这一圈里）与 `illustrateCover` 出图之后（**封面**）。
2. **家长输入过闸**：`review.ts` 多一个 `reviewInput()`（纯函数），
   在 `planStory` **最前面**跑——在第一句提示词、也在检索的 embedding 请求之前。

## 不做

- ✗ **语义档那三条**（说教 / 情绪接住 / 适龄）。计划表里写着"留着但今天不跑"，
  2026-10-19 用户当面确认维持。理由：文字面已经有确定性判据，
  再叠一层模型判断会把"可复现"这条卖掉。
- ✗ 画面审核**不重写提示词**（不把"上一版画了骷髅"喂回出图 prompt）——
  与一致性重画同一条纪律：喂回去等于把那个概念又写进提示词一次。
- ✗ 不给画面审核做"分数"。它有/没有，没有程度。
