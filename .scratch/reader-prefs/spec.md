# 阅读偏好（自动朗读 / 自己翻）· spec

> 工单：[01-settings-reading-prefs.md](issues/01-settings-reading-prefs.md)（含实测记录）

## 一、要什么（用户原话）

> 在左下角的侧边栏弄一个设置，点开设置是阅读偏好，用户可以选择在阅读独读版的时候，
> 是系统自己播放音频，音频播放完自动分页还是用户手动分页。

## 二、现状（改之前）

两个独读版阅读器——`/reader/<bookId>`（自己做的书）与灵感书单那本样书——的朗读
只有一种用法：点一下念**当前这一页**，念完就停，页永远由人翻。缺的是一条
**自动朗读**：按一次，一页页自己念、念完自己翻。而"谁来翻页"这件事，**产品上没有任何地方
可以选**。

## 三、做什么

1. **侧栏左下角一格「设置」**，点开是弹窗，里面一节「阅读偏好」，两条原生 radio。
2. **两个答案**：
   - 我自己翻（默认）—— 点一下「朗读」只念当前这一页，念完就停，页由人翻。
   - 自动朗读 —— 在阅读器里按一次「自动朗读」，从这一屏起一页页自己念、念完自己翻。
3. **两个阅读器都生效**（都是独读版）。
4. 偏好存在**本机浏览器**里；这一条**不写在弹窗上**（2026-10-17 用户圈掉了那两句注解，
   见工单 Comments），只记在这里与 `lib/reading-prefs.ts`。

## 四、不做

- 共读版（孩子做选择的那种还没做，偏好对它无意义）。
- 账号级同步（要动后端表结构、接口，且阅读器要多一次取数——另一个量级）。
- 阅读器里的第二颗开关（两个阅读器都在 `(studio)` 路由组之外，那一屏刻意没有侧栏）。
- 跨标签页同步（设置弹窗与阅读器不会同时开着）。

## 五、算做完的判据

1. **不设偏好时行为一个字不变**：手动模式下那颗钮仍然在封面/封底禁用、念完就停。
2. **自动朗读真的接得上**：一段念完 → 自动翻页 → 下一页的声音**自己**起来。
   判据取"下一页那段音频真的成了当前源并且在播"，不取"按钮变成 ■ 停止"。
3. **人翻页说得一不二**：自动朗读念着时按 ‹ ›，声音停、这一趟结束，
   且**不许自己再念下去**。

## 六、拍板的四条（2026-10-17，用户选定）

| 决定     | 取值                         | 一句话理由                                                   |
| -------- | ---------------------------- | ------------------------------------------------------------ |
| 怎么开始 | 按一下才开始                 | 浏览器不许页面在没人点过时出声，被拦掉的样子与"没有朗读"一样 |
| 手动翻页 | 人接管，这一趟结束           | 与两个阅读器里从第一天就写着的那句"翻页就停"是同一条         |
| 范围     | 两个阅读器都算               | 只做一半的话，"设了自动朗读、翻样书却不响"会读成坏了         |
| 存哪     | 本机浏览器（`localStorage`） | 与侧栏折叠、阅读记录同一性质；不是账号数据                   |
| 默认值   | 我自己翻                     | 一个偏好项不该顺手改掉任何人的既有体验                       |
