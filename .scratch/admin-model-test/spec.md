# spec：站长那一屏「模型选择」重做（2026-10-18）

## 用户要的

> 在站长的管理端，模型选择可以弄成这样的

附了四张**别家产品后台**的参考截图。截图里那三样是这个需求的实体：

1. 一个「厂商 / 网关」下拉，选中一家就把接口地址填好；
2. 「模型名」那一格右边挨着一颗「拉取模型列表」；
3. 一颗「测试连通」，按下去真打厂商接口。

在这之前这一屏**只能填**：配错了（地址抄错、key 少一位）要等到真去生成一本书才发现，
而那条路上最贵的一步是出图（0.2 元/张、一页十几秒）。所以这个需求真正要买的不是"像截图"，
是**在这一屏当场知道通不通**。

## 三个决定（都问过用户，答案是定死的）

| 问题                       | 用户选的         | 另一条路是什么                                                     |
| -------------------------- | ---------------- | ------------------------------------------------------------------ |
| 「测试连通」真打厂商接口吗 | **四种都真打**   | 只做本地形状检查（不花钱，但"通不通"这条信息根本不存在）           |
| 选中一家替你填到什么程度   | **只填接口地址** | 连模型名一起填——那会撞上"全仓库零个硬编码模型 id"这条既有验收      |
| 测试完的结果怎么给         | **通了就给结果** | 只给一句话（图、声音、它说的话都是**通的证据本身**，一句话替不了） |

## 做成什么样

### 1. `src/lib/settings/gateways.ts`：一张**地址表**，不是模型表

九条：OpenAI / DeepSeek / 智谱 GLM / 阿里云百炼（对话）/ 阿里云百炼（语音合成）/
月之暗面 / 硅基流动 / 火山方舟 / 自定义。

- **只写地址，一条都不带模型名**。有一条测试按"键集合"钉住这件事：将来谁往表里加一个
  `model` 字段，测试当场红。
- **按能力过滤**（`gatewaysFor(capability)`）：语音那一路的地址是 `…/api/v1`，
  与对话那一路（`…/compatible-mode/v1`）**不是一家**，混在一张下拉里等于让人选错。
- **它是地址书签，不是背书**：本仓只实测过当下在用的那一家。所以下拉底下永远跟着一句
  「这些地址是照各家文档抄的，本仓只实测过当下在用的那一家——选完点「测试连通」就知道通不通」。
  不说这一句，站长会以为"选中的那家一定对"。
- `gatewayOf(baseUrl, capability)`：从**当前生效的地址**反查是哪一家，认不出就是「自定义」
  （绝不猜）。它决定下拉停在哪一格。选中「自定义」**什么都不动**——它的意思是"别动我的格子"，
  不是"把地址清空"（清空是「恢复默认」那个动作）。

**刻意没有收进来的两家**：Anthropic 兼容网关（引擎那几个适配器说的是 OpenAI 兼容的
chat completions 与 DashScope 的 TTS，收进来只会给一个填上也不通的地址）；
火山方舟的**图像**那一项（它要的是接入点 id，不是模型名——收了就是在诱导填错）。

### 2. 「测试连通」：`POST /api/admin/model-test`

按能力分四支，发出去的那点东西**由服务端写着**（`model-config.ts` 的 `TEST_REQUEST`），
浏览器不另写一份：

| 能力 | 发什么                                            | 通了怎么算               |
| ---- | ------------------------------------------------- | ------------------------ |
| 文字 | 一句话，`max_tokens: 64`                          | 它回的话                 |
| 图像 | 一句提示词，尺寸取产品自己的 `DEFAULT_IMAGE_SIZE` | 那张真图（浏览器解码过） |
| 视觉 | 前端选的一张本地图 + 角色锚点提示词               | 读出来的那几个锚点       |
| 语音 | 卡片上印的那一句（`PREVIEW_LINE`）                | `<audio>` 能播           |

四条纪律：

- **测得通的尺寸必须是产品出图用的尺寸**（1536×1024）。挑一个方图去测，通不通都不说明产品能不能跑。
- **副标题写的那几个数就是真发出去的那几个数**，同源（`TEST_REQUEST`）。
  两处各写一份的话，副标题会停在"64 token"而实际发 4096——而"字写得很具体、做的是另一件事"
  正是最坏的那种错。有一条测试钉着这个同源。
- **失败也是 200**，体里 `ok:false` + 一句能照做的话（`adminFailureOf` 翻的，后面附厂商原文）。
  这一屏要的是"把状态画出来"，不是一个 HTTP 码——前端拿到 4xx 只会说"请求失败"。
- **不落盘、不重试、不写日志**。视觉那张图只活在那一条请求里。

`adminFailureOf` 只改写一处：`provider-not-configured` 在用户端那句话说的是 ADR-0008
（那时没有管理页，只能让用户找站长）；在这一屏上正确的下一步是"把缺的那一格填上并保存"。

### 3. 顺手修掉的一处：保存按钮的类名

`.adm__model-actions` 里那颗「保存」写的是 `adm__req-go`，而它在 `admin.css` 里
**一处都没有**（删权限申请队列那次之前的遗留）——也就是说那颗按钮一直是浏览器默认样式。
换成页面上真有的 `.adm__newgo`（建号表单在用同一个）。

## 判据（可复现）

```bash
node scripts/dev-preview.mjs --dist=.next-x --port=33xx     # BACKEND_URL 指向受测后端
node scripts/chk-admin-model.mjs http://127.0.0.1:33xx <一张真登录拿到的 xzj_session> [--live=1]
```

- 形状：四张卡各有副标题 / 下拉 / 「模型名」那一行里既有输入框又有拉列表钮 / 一颗测试连通。
  ★ 那一行按**结构**找，不按按钮上的字找——拉取中那颗按钮的字是「在拉…」，
  「按字找」会报一个假故障（第一版就是这么误报的）。
- 预设只填地址：选「DeepSeek」之后，接口地址那格变成 `https://api.deepseek.com/v1`，
  而**模型名那一格一个字没动**。
- `--live=1` 才真打：四种各点一次，把结果读回来。★ 默认不跑——图像那一按一口价 0.2 元/张，
  不该被一次误触花掉（与 `w1-image-bakeoff.mts` 那条「不带 `--yes` 只打印预算」同一条纪律）。
