# home-handoff · 首页 →「开始创作」→ /home 的过渡

Status: done（代码、终态契约与接力载荷都验过；★ **动效本身没验**，见工单 Comments）

## 一、要解决什么

用户实测的原话：**「从首页点击进主页就是很单调的直接跳转，这样子不太优雅」**。

首页（`app/page.tsx`，12 张绘本封面在一个 3D 环上）与工作台「创作」那一屏（`/home`，
同一批图摆成一面墙）**本来共用同一片天、同一批图、同一个顺序**，但切页那一刻两者
毫无交接：首页整屏消失、工作台整屏出现。所以这一单做的是**把那次路由的接缝补上**，
不是给页面再加一段特效。

## 二、判据（做完了是什么样）

1. 点「开始创作」→ 首页文案 / 点阵 / 柔光淡出 200ms（**环继续自转，一个像素不改**）
   → 切页 → 那 12 张封面**从它们刚才在环上的位置**飞进主题墙自己那一格。
2. 进工作台时侧栏从左边让进来（`AppShell` 挂载那一次）。
3. **四条退化路径**都不留半成品：直接访问 `/home`、`prefers-reduced-motion`、
   禁 JS / 中键 / ⌘ 点击、载荷过期。前三条走的是**改动前那条路**，一字不差。

## 三、不做什么

- 反方向（工作台 → 首页）也接力：那是另一套几何（墙面解散回环），另开一单。
- View Transitions API：`next` 15.5 那条实验开关要 React canary（本仓库锁 stable），
  而且它把整个视口做快照交叉淡入——那正是"两个网站互换了"这句话。
- 给墙上那 12 张换更大的派生图：飞行头 200ms 里的锐度差是**本来就有**的差异
  （环上那张源图 1280、墙上那张源图 320），接力只是让它出现在同一位置上。
