# 05 · 运行视图那两层玻璃（`--surface-glass`）

Status: done（2026-10-17）
对应 [spec.md](spec.md) §一

## 改了什么

- `src/app/globals.css`：新令牌 `--surface-glass`（α 见下：先 0.8，第二轮改成 **0.7**）、
  以及第二轮新增的 `--paper-glass: rgba(244, 248, 249, 0.45)`（设计令牌只在 `:root`
  定义一次那条硬约束）。`generation-run.css` 里 `.gr__rail` 与 `.gr__composer-inner`
  从 `--surface` 换成它；故事闸门那些卡也用它（同一片天，同一条门槛），
  卡里那些框用 `--paper-glass`。
- `scripts/check-scrim.mts`：新一节"运行视图那两层玻璃"。
- `scripts/check-scrim.mts`：修 `let fail = false` 的声明位置（见下）。

## α 是怎么定的（量的，不是挑的）

现有那三张卡面表（`CARD_FACES`）量的是**实心**面（`parseHex` 读一个十六进制值），
半透明的面叠在天光上算不出来。新那一节的做法：

1. 在**同一个采样格网**（`BANDS × COLS × ROWS_PER_BAND`）上找**整条天空带最暗**的一点；
2. 把 `--surface-glass` 按 gamma 空间叠上去（与脚本既有的 `over()` 同一条公式）；
3. 按 WCAG 算全部六种墨色的对比度，门槛仍是 4.5:1（这一层上落着 13–15px 的小字）。

★ 取"整条天空带最暗处"是**刻意的保守**：底部那条是 `sticky`，滚到哪儿就压在哪儿，
逐段算会得出"第 3 段可以、第 7 段不行"这种没法照着排版的结论。

**实测（1440×900，10 段 × 120 列 × 8 行）**：最暗天光 rgb(200,209,204) 上合成出
rgb(244,246,245)，`--ink-muted` **4.90:1**、`--accent` **4.76:1**、`--danger` 6.42:1。
★ 当时这一行接着写的是"**0.60 是这条线的底**（`--ink-muted` 恰好 4.50）"——
**那句是估的**，见下面第二轮。

## Comments

- 2026-10-17 **顺手修了量具自己的一个洞**：`let fail = false` 原来声明在个人主页那几行
  检查**之后**，而那几行会先写 `fail`——于是它们一旦不过，这支脚本抛的是
  `ReferenceError: Cannot access 'fail' before initialization`，而不是把那一行标红。
  **量具坏了会装成"跑通了"**，所以把声明提到第一处写入之前。
- 2026-10-17 全绿：`node scripts/check-scrim.mts` 的十段表、三张卡面表、个人主页那两条、
  以及新那一节都过；`--ink` 在天空带每一段的硬断言仍然成立。
- 2026-10-17 **第二轮：用户看了闸门那一屏之后说「白色背景的透明度增高一点，要不然和
  背景不符」**（并圈了阶段轨与书名那一格）。三件事：

  1. **先把"底在哪"量清楚，而不是直接往下调。** 实测三档（同一支脚本、同一个格网）：

     | α                | 合成色           | `--ink-muted` | `--accent` |
     | ---------------- | ---------------- | ------------- | ---------- |
     | 0.80（原）       | rgb(244,246,245) | 4.90          | 4.76       |
     | 0.70（**现取**） | rgb(238,241,240) | 4.70          | **4.56**   |
     | 0.68             | rgb(237,240,239) | 4.65          | 4.52       |
     | 0.60             | rgb(233,236,235) | 4.49 ✗        | 4.37 ✗     |

     **卡在 4.5 上的是 `--accent`，不是 `--ink-muted`**——两条线斜率差不多，而 accent
     起跑就低一档。所以令牌真正的底是 **α ≈ 0.69**，不是这一单原来写的 0.60
     （0.60 时两个墨色**都过不去**，脚本当场报 ✗）。取 0.70：最透明、又留着一点余量
     （采样格网可能漏掉更暗的云影）。**两个注释里的那个 0.60 都改掉了**——留在那里的
     假数会让下一个想调薄的人照着一个过不去的值改。

  2. **顺带发现真正的白不是卡，是框。** 用户圈的第二处（书名那一格）说明了这一点：
     `.ss__input` 铺的是**不透明**的 `--paper`，而一屏 8–20 张卡、每张卡里两三个框——
     框比卡更白更实，所以"整屏还是一张白纸"。新增 `--paper-glass:
rgba(244,248,249,0.45)`（不透明→16% 天光透进来；卡片那层是 30%），
     代价是框与卡之间只剩一次很轻的色阶（1px 描边承担剩下的区分）。
     ★ 它**不进这支脚本**：框叠在卡之上，只会更不透明，所以玻璃那张表就是下界——
     给它加一行会得到一组必然更高的数，那不是闸门是装饰（理由写在脚本那一节里）。
  3. **顺手修了一处没人量过的灰**：闸门那些框的占位文字原来落在 Tailwind preflight 的
     `::placeholder { color: color-mix(in oklab, currentcolor 50%, transparent) }` 上，
     现在显式写成 `--ink-muted`（与 `fields.css` 同一条写法，含 `opacity: 1`）。

  ★ 这一轮**没有改门槛**，也没有动 `--surface` / `--paper` 这两个全站令牌
  （首页、阅读器、工作台都在用它们）；改的只是"压在天空上"的那两层。
