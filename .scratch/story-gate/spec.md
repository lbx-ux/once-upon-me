## 一、用户说的两件事

> 1. 创作流程上面和下面的两个白色的背景不透明度减小一点
> 2. 现在用户只能修改画出的东西，不能修改具体的故事，应该把第一个编故事的提示词也给用户
>    看一下，用户可以修改一下，应该怎么发展，当用户确定之后再来生成图片

第二件是主体，第一件是同一个页面上的配色收尾（工单 05）。

## 二、为什么是"闸门"而不是"再做一个编辑页"

流水线原来是**一条**（`runBook` = 编故事 → 逐页画 → 封面 → 配音 → 装订），进去就一路跑到底。
出图是这条路上**唯一真正花钱**的一步（实测 ≈154 s/页、0.2 元/张），而它紧跟在编故事后面——
**家长在读到故事第一个字之前，整本书的钱已经花出去了**。

用户要的正是把这一步挪到"家长看过、改过、点头"之后。所以：

```
  ① 编故事  ──▶  【闸门：StorySheet，家长逐条改 / 让 AI 重写一版】  ──▶  ②–⑦ 逐页画 / 装订
     planBook                          改完点「就按这个画」                      illustrateBook
```

**闸门是一道门，不是一个随时能开的抽屉**：②开跑之后故事仍然是只读的（那时候每一页都在花钱，
一个能改的入口会让人以为"改了就不用重跑"）。

## 三、两个已确认的取舍（2026-10-17 与用户确认）

| 决定               | 选定                                                          | 代价                                                                    |
| ------------------ | ------------------------------------------------------------- | ----------------------------------------------------------------------- |
| 能改到哪一层       | 书名 + 每页正文 + 每页画面/情节，**外加**一句"让 AI 重写一版" | 每页三个框，20 页的书是 60 个框；提示词升版 `story-plan@v2`             |
| 关了标签页怎么找回 | 书架上多一栏（「正在编辑」里多一种状态：还没开始画）          | `BookSummary.status` 多一档 `'story'`，书架/个人主页/角色墙三处要跟着认 |

## 四、几条横跨多张工单的约定

1. **`doc` 是唯一那一份**。家长看到、能改的、盘上存的、以及真拿去画的，都是
   `PlanDraft`（书名 + 每页草稿）。为界面另立一个类型、中间加一层转换，
   那一层就是"改的东西"与"画的东西"分家的地方。
2. **判据只有一处**：`lib/story-problems.ts`（`planDraftCodec` + `buildTree`）。
   界面上标出来的问题、按钮亮不亮、服务端 400 时说的那句话，全部来自它。
3. **故事草稿存 `books/<id>/story.json`**，与 `book.json` / `events.jsonl` 同一个目录。
   "有 story.json 没有 book.json" = 这一本还没开始画——书架上那一栏认的就是这件事。
4. **`bookIdOf` 不含故事正文**（拼的是 `card|revision|form|theme`），所以改故事不改书号。
   这是闸门能成立的前提；改的如果是**主题**，那才是另一本书。
5. **`stats.elapsedMs` 的口径是"机器时间"**（① + ②），不含家长看故事与改故事的时间。

## 五、验收（做完之后的实测记录见各工单的 Comments）

三条只有真做才会不同的判据：

1. **改过的正文真的进了书**：把第 1 页正文改成一句独特的句子，画完之后读
   `book.json` 的 `tree.nodes[0].body` —— 必须是改的那句，不是模型原来那句。
2. **闸门真的拦住了钱**：停在闸门那一屏时，`books/<id>/` 下只有 `story.json` 与
   `events.jsonl`，一张 `page-*.png` 都没有。
3. **草稿找得回来**：闸门那一屏关掉标签页 → `/shelf` 的「正在编辑」里有它、
   写着"还没开始画"、没有「制作为绘本」→ 点进去回到那一屏，改的字还在。
