## 三、书架与摘要：两个数要分开（**已做**，2026-10-18）

`BookSummary`（`lib/library.ts`）加 `form`，并把**页数口径分开**：

- `pageCount` = **路长**（书架写这个——那是孩子会读到的量）；
- 全树节点数另记（管理页/审计要看的是它）。

四件要说清的事：

1. **两个数各自从哪来，都只有一处**：
   - 成品那一档（`summarize`）从**清单里那棵树**读：树里已经有 `next` 与 `pathFromRoot`
     （②装订时算好的），所以是 `pathLengthsOf`（工单 05 加的那个纯函数），不是这里另走一遍；
   - 草稿那一档（`summarizeStory`）用的是**闸门那一屏同一个** `storyShapeOf`
     （它内部就是 `buildTree`）。★ 两处各算一份的症状是"书架说 9 页、闸门说 7 页"，
     而这两个数说的是同一本书。`story-draft.ts` 文件头第 1 条那句
     "派生只发生在两处：②开跑前，与书架数页数"——这就是那第二处。
2. ★ **两条支不一样长时取长的那一条**（`readPages`，规则只写一处）。理由是架子上那个数
   的口径是"**最多**读到多少"：取长的，没有一个孩子会读到比它更多的页；取短的，
   家长按 7 页安排睡前时间、孩子读了 8 页——而架子写的是一个确定数，读起来不像"至少"。
   （闸门那一屏写的是**区间**（`8–9 页`，`shapeLineOf`）：那是回答"这本书多长"，
   允许两个数；架子上那一格摆不下区间，只能选一边。）
3. **问不出路长时回全表节点数**：树是坏的（一个叶都没有），或者清单里的 `pathFromRoot`
   是空的。★ 这是**真的会撞上**的一档，不是假想：`library.test.ts` 里原来那三条 fixture
   就是"三个 `next: []` 的节点"——那不是一棵树，是三个孤立的点，而页数口径改成路长之后
   它会量出 **0 页**。所以：**fixture 改成一条真的链**（假的形状另立一条用例专门钉兜底）。
4. **形态要标出来**：两种形态在架子上长得一模一样（封面 + 书名 + N 页），
   不标就分不出。角标复用既有那一枚小圆片（`.shelf__audio` 那条样式规则现在写成
   `.shelf__audio, .shelf__form`——**同一种东西，只有一条规则**，两个名字各说各的），
   并且 `title` 里回答家长会问的那一问："为什么页数比图少"。
   ★ 成品那一栏与「正在编辑」那一栏**都标**：草稿一样分不出形态，而它那一栏的页数
   现在也是路长。

书架那本上标出「共读版」：形与独读版一模一样，不标就分不出。
`components/shelf/*` 的角标样式与既有语言一致（不新造一套）。

## 怎么验的（§三）

- 判据取**服务端渲染出来的那一行字**（这一屏是纯 SSR，没有"挂载后才敢显示"）：
  拿一张本地签的会话票打 `GET /shelf`，在 HTML 里读每一张卡的 `.shelf__meta`
  与「共读版」角标。★ 为什么自己签票而不是走登录：登录要 Java 那台服务在跑
  （本机当时没起），而这一单要验的是**读数**，不是鉴权——票是用 `.env.local` 里
  那把 `APP_JWT_SECRET` 按 `session.ts` 的同一套规矩（HS256 / `scope: session`）签的，
  签完只落在 `.out/`（不入库），一小时过期。
- **路长是独立算出来再对**的，不是照屏幕上那个数抄：用 `doc.nodes` 的 `from` 串一遍
  得到"每条路各几页"（草稿那本：9 节点、路长 7、选择点在第 5 页），
  再和架子上写的 7 比。
- 跑完把暂存的那本 stub 书删掉（它只是为了让**成品那一栏**也有一个真读数）。

## 边界

- 不动 `bookIdOf`（书号含 `form`，所以同一主题的两种形态是两本书——这是对的）。
- 书架的排序/删除/缩略档一行不动（它们按资产路径工作，与形态无关）。
- **个人主页那一列不标「共读版」**（`ProfileHome` 的 `RecentBook`）：那一枚标签说的是
  草稿 / 可朗读 / 还没有声音，槽位只有一个，再加一格就要重新排它的优先级——那是
  另一单的事。个人主页的**页数**跟着这次一起变成路长了（它读的是同一个 `BookSummary`）。
- **`book.form` 不写兜底**：类型上它必填，盘上 19 本 `book.json` 逐本查过、全都有
  （`grep` 的那一段写在 `BookSummary.form` 的注释里）。真读到一个没有的，它只是**不标**
  ——`solo` 是"没有选择点"，那正是那种书的形状。
- 管理页/审计要的"全树节点数"这一单只做到**记在摘要里**（`nodeCount`），
  没有哪个屏显示它——今天还没有"要看的那个管理页"。
