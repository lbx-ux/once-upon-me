# 05 · 闸门那一屏能改选择点 + 画桌标出岔路 + 钱说在花钱那一刻

Status: open
依赖：[01](01-shape-and-prompt.md)

## 一、`StorySheet` 补选择点三个框（最要紧的一处）

现在只摊 `scene` / `body` / `imagePrompt` / `mood` 四格，`choice` **只在有错时显示
一行红字**（`StorySheet.tsx:178/232`）——于是共读版多出来的那一样，恰好成了整棵树上
**唯一改不了**的东西。

补：`prompt` / `options[0]` / `options[1]`，每项两项（`label` 给人看、`spoken` 给人听）
＋ 图标从 `CHOICE_ICONS` 里挑（不在词表里的旧值照实显示，不静默改成别的）。

★ **判据仍然只有一处**：`story-problems.ts` 已经把 `choice` 映射到格子上
（`splitField` 的 `known` 列表里已有它），**不新增任何校验规则**。
界面说"可以画"与服务端"就按这个画"必须来自同一个函数——各写一份的症状是
"按钮亮着、服务端 400"。

## 二、钱要说在花钱的那一刻

- 弹窗（`GenerationSetupDialog`）里只能给**上界**（确切张数编完故事才知道），
  加一行"共读版会多画走不到的那一支（图约多一倍）"。
- **确切数字放闸门那一屏**：`plan-ready` 的 `nodeCount` 就在那儿，那一屏已经在显示
  "共 N 页"。改成说两件事：**这条路读下来是 n 页** 与 **一共要画 N 张图（含走不到的那一支）**。
- 「就按这个画」的代价因此看得见——与"出图是唯一真正花钱的一步、先停下来"同一动机。

## 三、画桌标出岔路

`frames.ts` 按 `pageNo` 归格、摆成一排，两支会被摆成"第 4 页第 5 页"。
最小改动：**岔路那几格挂一条窄色带 + 一句"这一支只有选了它的孩子才读到"**。
`via` 从 `plan-ready` 之外没有来源，所以要么让 `frames.ts` 从草稿里读，
要么在事件里带上 —— 二选一，实现时定，**别让它靠"第 N 格之后都算岔路"去猜**。
★ 不做树形可视化（另一个量级，W5 材料）。

## 验收

- [ ] 闸门改一个 `spoken` → 问题清单清空/更新正确 → 「就按这个画」真的按改后的走
- [ ] ★ 把某个 `spoken` 改空：闸门**当场**说清是哪一格（不是等服务端 400）
- [ ] 闸门显示的两个数（路长 / 要画的张数）与 `book.json` 里的真值相等
- [ ] 画桌上两支的格子看得出属于哪一支，且**不是**靠位置猜的
- [ ] 静止/`busy` 时那三个框只读（改到一半被自己的请求盖回去是最难查的一种坏法）
