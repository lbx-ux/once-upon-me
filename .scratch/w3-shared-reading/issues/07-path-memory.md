# 07 · 路径落盘：选了哪一支要记得住

Status: open
依赖：[04](04-reader-shared.md)

## 做什么

同一本书第二天再翻开，**上一次选的那一支要还在**（按下态还在、"上次你走的是这条路"）。
`StoryNode.pathFromRoot` 是静态的那一半，**孩子这一次选了哪一支是运行时状态**。

- 落点：`localStorage`，键 `xzj:path:<bookId>` → `'a' | 'b' | ''`，
  与阅读记录（`lib/reading-log.ts`）、阅读偏好（`lib/reading-prefs.ts`）同一族、
  同一套"认不出来的值一律退回默认"的解析纪律。
- ★ **不进 `book.json`**：产物是引擎写的，被阅读行为改写会让清单漂
  （`AssetRef.digest` 与"这本书是什么"的判据都建立在它不变之上）。
- 只存"选了哪一支"，**不存整条路径**——路径由树推得出来，存两份就是两个真相。

## 验收

- [ ] ★ **含一次真销毁**：选 b → 换一个标签页（或重挂 reader 组件）→ 回来，
      按下态还在、继续往下读走的是 b 支。
      （只改内存 state 的实现也能"刷新前一致"，所以判据必须跨一次真销毁。）
- [ ] 清掉 `localStorage` 后照旧能读：没有记录 = 没选过，不是"走到第一支"
- [ ] 坏值（手改成 `'c'`、半截 JSON）退回"没选过"，不抛、不锁死

## 边界

- 不做"走过的路"可视化（那是下一步功能的开场，见 spec §七）。
- 不做跨设备同步（与阅读记录同性质：只在这台设备的这个浏览器里）。
