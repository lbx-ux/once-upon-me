## 二、站得住的三条

**1. HTTP 那条路也认标签。** 文档那页是「实时语音合成」（WebSocket），我们走 HTTP。
标签在这条路上照样生效——文档没说，只能量。

**2. 标签是"被当控制符消费掉"，不是被念出来。**

| 输入                           | 时长      | 判读                         |
| ------------------------------ | --------- | ---------------------------- |
| `<句>`                         | 5.33s     | 基线                         |
| `[whispers]<句>`               | 4.70s     | **更短**——若被念出来只会更长 |
| `低声耳语。<句>`（字面量对照） | **7.18s** | 真把四个字念出来是这个量级   |

**3. 语速档的方向与文档一致**：`[very fast]` 4.37s（−18.0%）、`[very slowly]` 5.81s（+9.0%）。

## 三、★ 两条被数据推翻的假说（这一节是这张工单的重点）

### 假说 A：「这个厂商是确定性的」——**错的**

从 `tts-mood-probe3.mjs` 得到的结论是"同一入参 6 次，时长 SD = 0.00s，所以差值都是真的"。
**这个结论建立在一个恰好碰到稳定窗口的采样上。** 后来 `tts-mood-flaky.mjs` 连打 10 次：

| 输入                   | 10 连打的版本分布                 |
| ---------------------- | --------------------------------- |
| `<句>`（**不带标签**） | `2.69s×7` / `2.45s×2` / `2.78s×1` |
| `[excited]<句>`        | `3.02s×7` / `2.69s×2` / `2.78s×1` |
| `[amazed]<句>`         | `2.86s×9` / `2.54s×1`             |

**不带标签的那一档自己也抖。** 冷启动假说（"第一次不一样"）用两句全新文本 ×4 次
测掉了（`.out/tts-mood-cold.mjs`，4/4 相同），所以不是缓存冷热。

**后果**：任何"两次字节不同 → 标签生效了"的推理**不成立**。
判据 4 的第一版就是这么写的，而且它**自己撞出了反例**：
同一轮里 `joy` 与 `proud` 发的是同一个 `[excited]`，却出了两份不同的字节。

### 假说 B：「逐句贴标签是免费的」——**错的**

正文是 `body.join('')`（`narrate.ts` 规则 2），文档说标签"长句被自动切分时作用范围
以切分后的文本为界"，所以想逐句贴。`.out/tts-mood-place.mjs` 量出来：

| 输入                   | 时长      | 字节   |
| ---------------------- | --------- | ------ |
| `AB`                   | 8.21s     | 164251 |
| `[excited]AB`          | **7.01s** | 140251 |
| `[excited]A[excited]B` | 7.97s     | 159451 |

自反对照：`[excited]A` 比 `A` 长 **336ms**、`[excited]B` 比 `B` 长 **240ms**
——**贴一个标签本身就要花时间**。逐句贴比只贴一次多 960ms，其中 **0.36s 是开头的静音**
（`silencedetect`：`plain`/`tag-once` 开头都没有静音，逐句贴那一版有）。

→ **改成只贴开头。** 对一个"点一下就播"的控件，开头 0.36s 的死气是缺陷。

**顺带**：只贴开头时，两处停顿都从 0.58s/0.47s 缩到 0.36s/0.30s
——说明标签**跨过了第一个句号**，没有"只管第一句"这个毛病。

## 四、判决用的度量：先量噪声底，再比区间

`tts-mood-dist.mjs`（8 档 × 12 次，同一句）：

| 档              | 时长区间   | 与对照（2.45–2.69s）比 |
| --------------- | ---------- | ---------------------- |
| `plain`（对照） | 2.45–2.69s | —— **噪声底 0.24s**    |
| `[very fast]`   | 2.21–2.62s | ✗ 交叠                 |
| `[very slowly]` | 3.10–3.17s | **✓ 完全分开**         |
| `[whispers]`    | 2.54–2.69s | ✗ 交叠                 |
| `[excited]`     | 2.69–3.02s | ✗ 交叠（贴着）         |
| `[amazed]`      | 2.54–2.86s | ✗ 交叠                 |
| `[trembling]`   | 2.78–2.86s | **✓ 分开**             |
| `[empathetic]`  | 2.62–2.93s | ✗ 交叠                 |

**时长只判得动语速档**——这是对的：`[excited]` 这类**语气档本来就不该改语速**，
拿时长判它们是把尺子拿错了。

`tts-mood-f0.mjs`（读同一批文件，不重新合成）用**基频**判语气：

| 档                              | F0 区间             | 与对照（279–290Hz，宽 11Hz）比             |
| ------------------------------- | ------------------- | ------------------------------------------ |
| `[excited]`                     | **316–322Hz**       | **✓ 分开（+30Hz 以上，且聚得很紧）**       |
| `[trembling]`                   | **305–315Hz**       | **✓ 分开**                                 |
| `[whispers]`                    | **238–269Hz**       | **✓ 分开（明显更低）**                     |
| `[amazed]`                      | 282–319Hz           | ✗ 交叠（区间很宽，像"有时生效有时不生效"） |
| `[empathetic]`                  | 283–289Hz           | ✗ **整个落在对照区间里 —— 没测出效果**     |
| `[very slowly]` / `[very fast]` | 263–288 / 277–281Hz | ✗ 交叠（它们改的是语速，本来就该如此）     |

**"起伏"（相邻窗 F0 差的均值）所有档都交叠** → 这个度量在本场景**没用**，
不要拿它下结论。

## 五、判据 4 / 5 的结果

`.out/tts-mood-e2e.mts`（六页正文**逐字节相同**、只有 mood 不同，走真 `narrateAll`）：

| mood   | 标签           | 文件     | 时长  | F0        |
| ------ | -------------- | -------- | ----- | --------- |
| calm   | （无）         | `page-1` | 2.69s | 290Hz     |
| wonder | `[amazed]`     | `page-2` | 2.86s | 319Hz     |
| joy    | `[excited]`    | `page-3` | 3.02s | **322Hz** |
| tense  | `[trembling]`  | `page-4` | 2.78s | 305Hz     |
| tender | `[empathetic]` | `page-5` | 2.93s | **289Hz** |
| proud  | `[excited]`    | `page-6` | 3.02s | **322Hz** |

✓ 六份文件（mood 在去重键里）· ✓ joy 比 calm 高 32Hz · 每一页的 F0 都落在第四节量好的
那一档区间里（`wonder` 319 落在 282–319 的顶、`tender` 289 落在 283–289）
——**两次独立测量互相对得上**，这比任何单点数字都让人放心。

★ 但表里有两处要**明说**，不许含糊过去：

- `tender` 289Hz ≈ `calm` 290Hz：**这一档在度量上等于没加标签**。
- `joy` 与 `proud` 都是 322Hz：这两档**在听感上会重合**（同一个标签）。
