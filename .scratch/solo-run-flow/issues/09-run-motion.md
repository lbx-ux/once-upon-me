# 09 · 运行视图的动效与进度条

Status: done
依赖：[05](05-run-view.md)（运行视图先得有画桌）
上游：2026-10-16 用户"正在画怎么空拉拉的，来点交互效果，比如加个进度条这些的"

## 一、为什么改口

`Desk.tsx` 文件头第 1 条原来写的是**反对**进度条："一根 35% 的进度条是**编出来的数**"。
那句话反对的**不是条**，是**编出来的分母**——当时引擎没有任何一条事件说得出一页画了几成，
所以任何一根条都只能自己估。今天也不是估的：条的长度就是 `drawnCount / total`，
与那排空画框**是同一个数**。所以这单是"加上一根本来就成立、只是没画出来的条"。

**空画框留着**：它说的是"哪几页"，条说的是"走到哪儿了"，两个问题不一样。

## 二、加了什么（四样，每样一条判据）

| 加的                                  | 说什么                                         | 不说什么                                 |
| ------------------------------------- | ---------------------------------------------- | ---------------------------------------- |
| `.dk__bar`（画桌上方那条）            | 已经画好的格数 / 总格数，一格一格有刻度        | 不说还剩多久                             |
| `.dk__bar-beam`（条上那道走光）       | "这条流还开着"                                 | 不随画好的格数变宽变窄，所以它不表示进度 |
| `.dk__frame::after`（格子上的扫光）   | "这一格正在被画"                               | 同上                                     |
| `.dk__art` 的淡入 + `::before` 那圈闪 | "这一格的图刚换过"（点完「重画」要看的就是它） | 不表示画得好不好                         |

★ 三处**刻意不加**的东西，理由写在 `desk.css` 文件头第 3 条：没有 spinner、没有进度环、
没有"还剩多久"。转圈转的是**一个未知的剩余量**，而我们确实不知道（引擎不报）。

★ 走光用 `--beam`（冷的那一支）而不是 `--accent`：令牌表里那句"冷的是光，暖的是物件"——
一道光是装饰（"这一块是活的"），不是"要你看见"。顺带它让**橙色只表示一件事**：
已经画好的页数。

★ 条与光的开关是 `Desk` 的 `live`，由 `GenerationRun` 给：**只有拿着连接的那一方**
知道"服务端这一轮还在不在跑"——画桌上的事件只说明走到哪儿了，一轮跑完与一轮卡住
在事件流里长得一模一样。

## 三、探针抓出来的一个真 bug（`live` 的判据写错了）

第一版：`live = phase === 'running' || (phase === 'replaying' && serverRunning)`。
在**重跑一本已经存在的书**（同一个书号、清单还在盘上）时，`bookReady` 为真 →
phase 判成 `'ready'` → 光不扫。而那时屏幕上明明有一格在画、条也在长。

探针报的就是这一格：`条 1/3 宽比 0.333`（**没有**"有走光"），而 `忙: drawing`。
改成 `live = phase === 'running' || serverRunning` 之后再跑同一本，那一行变成
`条 1/3 宽比 0.333 **有走光**`，动画表里也多出 `dk-scan`。

★ 教训：**"清单在盘上"与"这一轮跑完了"是两件事**，`phase` 把它们合成了一件。

## 四、验收（真帧，不是静态读数）

```bash
node scripts/chk-run-motion.mjs http://127.0.0.1:3321 --pages=5 .out/run-motion.png   # ① 走用户那条路
node scripts/chk-run-motion.mjs http://127.0.0.1:3321 --book=<bookId> --limit=40000   # ② 盯着别人发起的一轮
node scripts/chk-shelf-draft.mjs http://127.0.0.1:3321                                # 另一单（10）
```

实测（`xiaoyu-r1-ad302036256f`，3 页，`--probe-env=1` 关掉比对）：

```
[ 8s] 格 1/3 · 条 1/3 宽比 0.333 有走光 · 忙 drawing
      动画 gr-ping@5518 dk-scan@5518 dk-land-ring@1100 dk-land@500 dk-sweep@5518 dk-breathe@5518
[43s] … dk-scan@39767 …                      ← currentTime 一直在走
落格那一瞬： {"透明":"0.445","缩放":"matrix(0.9889…)", "动画":["dk-land"]}
静止模式下还剩的动画：[]
```

- 条的长度（0.333）与阶段轨上那个 `1 / 3` **对得上**——它有分母，不是另算的百分比；
- **在动**这件事是拿 `document.getAnimations()` 的 `currentTime` 判的，不是"元素在不在"：
  只看元素在不在是测不出动没动的（`preview-pane-hidden-freezes-raf-and-transitions` 那条）；
- 落格动画被**抓到了中途**（透明 0.445、缩放 0.9889），说明它真的从 0 播到了 1；
- `prefers-reduced-motion` 下那几条**一条都不在**，而图仍然是完全显形的（终态，不是起点）。
