# 10 · 「退出」与书架上的「正在编辑」那一栏

Status: done
依赖：[03](03-draft-and-published.md)（草稿/成品两态）、[05](05-run-view.md)（运行视图）
上游：2026-10-16 用户"这改为退出……用户点击退出之后，这个待编辑就放到书架上，
状态设为「正在编辑」，然后用户可以选择是删除还是制作为绘本；书架应该增加一栏，
用于存放编辑的书籍"

## 一、改了什么

| 原来                                          | 现在                                                |
| --------------------------------------------- | --------------------------------------------------- |
| 运行视图底部那颗「改故事，重做一本」→ `/home` | 「**退出**」→ `/shelf`                              |
| 书架那一栏叫「还没做完」                      | 「**正在编辑**」，多一行说明它在说什么              |
| 一张卡上两个出口（继续做 / 不要了）           | 三个：继续编辑（整张卡）/ **制作为绘本** / **删除** |

★ **那句话原来在骗人**：这一本已经写进盘上了（草稿态），点它并不会"丢掉"什么，
而"改故事＝重做一本"的说法让人以为要重新开始。现在这一颗说的是它真正做的事：**离开这一屏**。
去 `/shelf` 而不是 `/home`：用户接下来要处理的是**这一本**，而它在书架那一栏里
（`/home` 是"另起一本"的地方，那是第二件事）。

★ `title` 分两句，因为这两件事真的不同：还在跑的时候这一本**还没有**落到书架上
（清单是收尾那一刻写的），跑完了才出现——说成一句就是假的。

★ 磁盘上那个状态字仍然是 `draft`，**没有**跟着改成 `editing`：它是迁移判据
（`engine/domain.ts` 的 `Book.status`：缺省 = 成品），改它等于让所有老书重新分堆。
改的只是**这一屏叫它什么**。

## 二、「制作为绘本」是同一个动作，不是第二条路径

它打的是运行视图那颗「确定生成」**同一个接口**（`POST /api/books/<id>/publish`，幂等）。
两条路径的差别只在于用户在哪儿按的那一下，而"一本书什么时候从草稿变成成品"只该有一种答案。

★ **不问"确定吗"**：这一步不销毁任何东西（书还在，只是换了那一栏），
而删除那一边要问——两边都弹框会让"要不要紧"这件事失去区分度。
★ 成功之后 `router.refresh()`，那一本从这一栏挪到下面的书架上，用户看得见后果。

★ 两颗按钮摆在这张卡**外面**（卡片本身是一个去 `/create` 的链接）：
做成链接里的按钮，点"删除"会先跳走再问，那是这一屏最不能出的错。
顺序与轻重也有讲究：「制作为绘本」在前、用实心（那一栏里唯一往前走的动作）；
「删除」在后、只用描边——它把一本书从盘上抹掉，不该长得像主按钮。

## 三、验收

```bash
node scripts/chk-shelf-draft.mjs http://127.0.0.1:3321 .out/shelf-draft.png
```

它自己造一本 `chk-draft-fixture` 来验（真跑一本要 Key、要几分钟、还要花钱，
而这里要验的是界面与那**一个**接口），跑完删掉它。

实测：

```
这一栏长这样： 标题「正在编辑」· 说明「在运行视图里点过「退出」的书放在这里。可以接着编辑，也可以直接制作为绘本。」
              卡上三个出口：["制作为绘本","删除"] + 链接 /create?book=chk-draft-fixture
盘上那份的 status：published          ← 判据是**盘上那个字段**，不是按钮变没变
网络： [ '200 /api/books/chk-draft-fixture/publish' ]
判据小结：那一栏在、标题对 ✓ · 三个出口 ✓ · 真的写盘了 ✓ · 刷新之后它离开这一栏 ✓ · 出现在成品架上 ✓
```

★ 第一版的判据写错了：它问的是"**这一栏**还在不在"，而栏里可能还有别的书（真书），
于是"刷新之后它离开这一栏"被一个不相干的邻居答成"还在"。
按**本**判（书名在不在这一栏里）之后才是真判据。**假的和比没有和更危险**。
