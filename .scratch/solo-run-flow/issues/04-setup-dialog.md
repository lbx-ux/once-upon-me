# 04 · 弹窗「这一本要怎么做」（在 /home）

Status: done
依赖：[02](02-wire-narration.md)（朗读开关要能真的落到请求里）
上游：spec §三

## 一、要什么

`/home` 上点「开始创作」**不再直接跳走**，先浮一个弹窗：

```
这一本要怎么做
  这一本做多少页      [5 页] [8 页] [12 页] [20 页]
  要不要朗读          [ 开 ]
                     用「天真男童音」朗读 · 换音色
  ────────────────────────────────────────────
  [再改改故事]                      [开始创作 →]
```

确认后带着 `pages` / `voice` 跳到 `/create`（工单 05）。

## 二、页数

沿用今天创作流里那四档（`CreateFlow.tsx` 的 `PAGE_CHOICES = [5, 8, 12, 20]`），
默认 `8`。★ 产品定义的独读版是 20 页，但演示要能缩小规模，所以它是**可选的入参**，
不是写死的常量（`book-api.ts` 已经这么校验：3–30 的整数）。

## 三、朗读开关

- 默认值取 `canNarrate`。
- `canNarrate` 为假时**禁用**，说明缺什么，点它打开设置抽屉（工单 [02](02-wire-narration.md) §四）。
- 开着的时候显示**当前音色名**（`voices.find(v => v.id === settings.speech.voice)`）。
  没选过音色就如实说"还没选声音"，**不预填一个默认音色**——
  那会让"我还没选"看起来像"已经选好了"（`CreateLanding` 那颗药丸就是这么判的）。

## 四、★ 弹窗不做第二份状态（这条是本单最容易犯的错）

| 值             | 家                                        |
| -------------- | ----------------------------------------- |
| 页数           | 弹窗自己的 `useState`（只属于这一次生成） |
| 要不要朗读     | 弹窗自己的 `useState`（只属于这一次生成） |
| **用哪个音色** | `settings.speech.voice`——**唯一那一份**   |

★ 「换音色」不要在这里再摆一个下拉：`/home` 那颗声音药丸已经是同一个字段的下拉，
弹窗里再摆一个是**两个下拉写同一个值**。做法是那一行给一条路过去（关弹窗、开那颗药丸），
或者干脆只显示名字。**本单选后者**：弹窗只说"用哪一个"，改音色回那一屏改。

## 五、无障碍与惯例

- `role="dialog"` + `aria-modal="true"` + `aria-labelledby` 指标题。
- Esc 关、点遮罩关（与 `CreateLanding` 那两个下拉、`SettingsDrawer` 同一套习惯，不另发明一套）。
- 打开时焦点进弹窗，关闭后回到「开始创作」那颗按钮。
- ★ 页数那四档用 `aria-pressed`，不是 radio（与仓库既有的分段控件一致，见 `CreateLanding` 的 `.cl__form`）。

## 六、验收

- `/home` 点「开始创作」→ 弹窗出现，焦点在里面；Esc 关得掉，焦点回主按钮
- 选 5 页 + 关朗读 → 确认 → `/create` 上跑的是 5 页、`book.json` 的 `narrations` 为空
- 选 20 页 + 开朗读 → 确认 → `/create` 上摆 20 个空画框，跑完之后 `narrations` 非空
- 设置里清空语音 → 弹窗里开关是禁用的、点它打开的是设置抽屉

## Comments

- 2026-10-16 做完了。`GenerationSetupDialog.tsx` + `generation-setup-dialog.css`，
  挂在 `CreateLanding` 上；`submit()` 改成开弹窗，`startRun(choice)` 把
  `pages` / `voice` 挂到地址上交给 `/create`。

**实现时改掉的一条自己的写法**：开关的初值原来写成 `useState(canNarrate)`，
那会把**打开弹窗那一刻**的读数钉死，而设置是挂载之后才从 `localStorage` 读回来的
（`SettingsProvider` 文件头第 2 条）——配好了语音的人可能看到开关是关的。
改成 `voiceChoice: boolean | null`，`null` = 跟着 `canNarrate` 走。

**还补了一条**：Esc 关掉之后焦点要**还给**那颗「开始创作」。
不还的话焦点落在 `<body>` 上，读屏从文档开头重念、键盘用户按 Tab 回到侧栏第一项——
模态最常被漏掉的那一半。

**没做**（刻意）：弹窗里不放"换音色"的下拉。音色的家只有一个
（`settings.speech.voice`，`/home` 那颗药丸是它的下拉），再摆一个就是两个下拉写同一个值。
