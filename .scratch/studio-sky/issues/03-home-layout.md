# 03 · `/home` 版式与 CTA

Status: done（2026-10-15）
依赖：01、02

## 一、主 CTA 换成首页那颗墨色药丸

原来是**第二套 CTA 语言**：首页是黑药丸白字，工作台画了个橙色圆圈 `↑`。
现在连高度（52px）、圆角（999）、底色（`#1a1a20`）、hover 位移（`translateY(-2px)`）
一起抄，只把横向 padding 收到 26px。

实测确认：选中一个主题之后 `.cl__go` 的背景是 `rgb(26, 26, 32)`、文字 `rgb(255, 255, 255)`，
与首页 `.btn` 同色。禁用态走 `--surface-soft` + `--ink-muted`
（`--muted` 在合成后的 244 底上是 4.85:1，过线）。

## 二、字阶

原来 44 / 15 / 13.5 / 12.5——四个数之间没有关系，所以标题不像标题。
改成约 1.35 一档：54 / 17 / 15 / 13 / 11.5。

中文标题**不加负字距**：那一套是给拉丁大写字母用的，压在中文字上只会让笔画糊在一起。

## 三、装饰压到正文上

标题右下方那笔叶子（`.cl__doodle--leaf`）原来写 `bottom: -22px`，而标题框
`margin-bottom` 只有 16px——**真机截图里它正好横穿 `.cl__sub` 那行字**。
现在标题 `margin-bottom: 26px`、叶子 `bottom: -8px`（笔高 40 + 浮动 ±2px），留 18px。
实测两个矩形不相交（`leaf y 178–218` / `sub y 237–294`，x 也不重叠：`1112–1152` / `396–783`）。

★ 装饰压到正文上，再好看也是错的。

## 四、★ 竖向预算重排（这一单最实的一处）

原来 900px 高的窗口里：标题在 y=144，主题墙从 y=678 开始，
**墙上 12 格里只有 5 格可见**——用户为这一屏选的正是这面墙，它 82% 在首屏之外。

省下来的（每一笔都有出处）：

| 改                                                                        | 省   |
| ------------------------------------------------------------------------- | ---- |
| `.cl` padding-top `clamp(56,11vh,132)` → `clamp(48,9vh,116)`              | 18px |
| textarea `rows=3` → `rows=2`（一句话不需要三行，`resize: vertical` 还在） | 31px |
| `.cl__sub` margin-bottom 34 → 28                                          | 6px  |
| `.cl__wallhead` margin-top 46 → 36                                        | 10px |

合计 65px：墙从 y=678 提到 y=613，可见 287px = **第一行完整 + 第二行 96%**。
"下面还有"这个抓手出来了，而顶部仍留 126px 的天。

## 五、破线的一行

`.cl__sub` 原来是 `--ink-muted`，压在天空带第 3 段上，那里灰字只有 **4.14:1**（破线），
而第 3 段的安全横向区间是 x 55–62%，`.cl__sub` 从 x=396（27%）开始。
改成 `--ink-on-sky`：同一段 6.90:1，层级仍靠字号（54 vs 15）撑住。

## Comments

- 主题墙的图**必须去掉 `loading="lazy"`**。实测：干净的 1440×900 加载下，
  12 张里 11 张停在 `naturalWidth: 0` 没被触发——而墙的第一行（y≈613…756）
  本来就在**首屏里**。对首屏内的图用 lazy 没有收益只有风险。总量 132 KB，
  LCP 不受影响（LCP 是标题那行文字，它在 DOM 里排在图片前面，且文字不阻塞于图片）。
  ★ 这条是**只有开浏览器才看得见**的那一类：`tsc` / `eslint` / 单测全绿。
- 手动 `.click()` 能填字、能选中（`el.click()` → wish 变成"用纸箱做的一枚火箭，数到三就出发"、
  主题卡 `data-active=true`、按钮变墨色）；`preview_click` 在这个被缩放过的面板里点不到，
  是工具坐标的问题、不是产品的问题。记在这里免得下次又排查一遍。

  选中项写着"小满 · 第 1 版 · wan2.7-image 画的"）、Esc 关、点外面关。
