# studio-sky —— 工作台换掉那层米色：与首页共用同一片天空

2026-10-15。用户的原话：**"现在的这个主页真的好丑啊，能不能高级，大气一点"** +
**"前端的这个主页能不能和首页联动起来，看起来是两个毫不相关的网站"** +
**"是不是可以把主页的背景也弄成这个蓝色的背景"**。

## 起点

`/home` 是一整块 `#faf5ee` 平涂 + 一条纯白侧栏 + 一枚实心橙胶囊。首页是三张水彩场景靠
长交叉溶解连起来的满屏世界。两屏放在一起，配色、字体、按钮、图标语言**没有一处相同**。

## 四个已定的决定（用户 2026-10-15 选）

1. 天空满屏 + 实测纸光，**四屏共用**同一个背景层
2. 范围 = 外壳 + 四屏（`/home` `/shelf` `/character` `/voice`）
3. emoji → 从现有 12 张封面**裁**小图（不新出图、不花钱）
4. `/home` 加真实内容：**12 个主题的封面墙**

## 一句话结论

背景不是"整屏铺蓝"，而是**一条按 WCAG 量过的天空带 + 一条 governing rule**：
压在天空上的文字只允许两种深墨色，灰字与橙字必须待在纸里。
这条规矩让纸光可以铺得**薄**——天空真的看得见（用户要的"大气"），
而不必为了兜住灰字把整屏盖成米色。
