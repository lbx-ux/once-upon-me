# 02 · 第二屏：整个阅读器被当前页染一层色

Status: done
Spec: ../spec.md
创建：2026-10-12（用户第 1 条要求）

## 要什么

从当前跨页插画里取主色，做成很淡的渐变铺在书后面（例：云的白 + 草坡的黄绿 +
天空的淡蓝），整体透明度压到 10–20%，翻页时柔和过渡。

## 怎么做的

- 新增 `scripts/sample-tints.py` → 生成 `src/components/book/spreadTints.ts`
  （每一面三朵主色）。**不手挑颜色**：手挑的东西下一次换图就没人重挑，
  于是背景色与画面悄悄脱钩。
- 新增第三层 `.storybook__tint`，与点阵、光斑同挂 sticky 满屏的 stage。
  五面各铺一张 `<i>`，`data-on` 跟着 `page` 走，**靠 opacity 交叉淡入 0.78s**。
  不用 `color-mix`、不用 Houdini 注册属性：老浏览器只是没有这层色，不会渲染出错。
- 三朵按**彩度从高到低**排，所以 CSS 固定读法 = 前两朵做有色的两团、最后一朵做外圈。
- 整层 `opacity: .18`（在用户给的 10–20% 区间里）。
- 静止模式下与另两层一起去掉。

## 两次取色取错了，都是实测抓出来的

1. **缩到 64px / 量化 8 色 → 三朵全是灰褐**（`#b29a7a`、`#b88467` 那种）。
   原因是草坡与天空在缩略时被平均到同一颗像素里。
   改成 **200px / 16 色**才交出 `#eae49d`（草坡黄绿）/ `#bbc687`（草绿）/ `#d7eef3`（天蓝）。
   → 教训：**给"取主色"降分辨率，取到的是平均色而不是主色。**
2. **没有亮度下限时，spread-3 的第一朵是 `#837666`** —— 那是铅笔线稿的褐色，
   不是"这一页是什么颜色"。加一道"最亮通道 ≥ 150"的过滤（水彩暗部在 150 以上，
   线稿全在 130 以下）。占比仍然按**全图**算，过滤放在算完 total 之后，
   否则那三个百分比会虚高，而百分比是这张表唯一的可核对证据。

## 生成物自己也曾是坏的

第一版脚本把对象键裸着写出去（`/book/cover.webp: [...]`）—— 不是合法标识符，
整个模块语法错误。而它逃过了当轮的 `pnpm typecheck`，因为**那次跑的时候这个文件还不存在**。
是浏览器的 500 页抓出来的。与"GSAP 插件 import 只有浏览器能抓"是同一类：
**闸门跑在新增文件之前 = 没测。**
