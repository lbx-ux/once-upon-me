## 要做什么

用户 2026-10-16 定的：**不做上传，系统给几个默认头像，用户在里面切换。**

- `src/lib/avatars.ts` + `public/avatars/*.svg`：6 个手写 SVG（`id` / 名字 / 文件）。
  配色取 `globals.css` 里那几枚令牌的值——`<img>` 里读不到 `var(--x)`，
  所以色值写死在 SVG 里，**在 `avatars.ts` 文件头注明出处**（改配色要一起改）。
  不进 `scripts/make-webp.py` 那条流水线：它是矢量，没有重编码的必要。
- 后端只存一个 id（`^[a-z0-9_-]{1,32}$`，见 `AccountRules.requireAvatarId`），
  **两边不各存一份白名单**：前端认不出的 id 一律退回"头像空着"那个圈
  （`ProfileHome` 里现成那个图形），语义上诚实的兜底。
- `/account`：占位换成**挑一个**——一排缩略图 + 当前那个描边，点一下即存
  （`pickAvatar`），`aria-pressed` 说给读屏。
- 侧栏底部那一格：已登录时显示挑的那个（`AppShell` 的文件头早就预告过
  "接后端拿到头像那天这里要长出一个 `img` 分支"）；没挑过还是那个圈。

## 怎么算做完

- 挑一个 → 个人主页与侧栏**同时**变；**登出再登进来还是那一个**（★ 这条才证明它进了库，
  而不是只在内存里）。
- `curl PATCH /api/auth/me/avatar` 送 `../../etc/passwd` 回 400（后端那条测试已有）。
- 未登录 / 认不出的 id：显示那个圈，不留碎图标。
