### 为什么反过来用**暖**色（与工单 15 那段"冷调"相反）

工单 15 让六张跟着那一屏转冷，判据是"别成为不在调子里的东西"。现在反过来了：

1. **冷底 + 冷记号在那一屏上等于看不见**：头像坐在那一屏的淡蓝里，而那一屏的底
   与次级文字也是同一族的蓝——用户说的"这个蓝色的不好看"，量出来就是

   ★ 这**不违背**"那一屏整体转蓝"：转的是**光**（页面底、描边、次级文字）。

## 二、改密码：按钮 + 弹窗

- 那一段原来横跨整宽坐在两栏下面（一张自己的纸），现在是身份卡底部两颗按钮之一：
  `修改密码`（静的）+ `退出登录`（danger，`flex: 1`）。
- `.pf__pw` **不再画纸**：装它的 `Dialog` 面板本身就是 `--surface` 的一张圆角纸
  （`dialog.css` 的 `.dlg`），所以 `margin / padding / border / background /
box-shadow` 五项全部撤掉，只留"三行之间隔 10px"。
- ★ **成功与失败的落点刻意不在一处**：失败留在弹窗里（要在那儿改输入），
  成功则关掉弹窗、在**那颗按钮旁边**说一句。合成一处的话，
  失败时那句"改好了"会先闪一下再被覆盖。
- ★ 焦点**还回那颗按钮**。`Dialog` 的文件头最后一条写着它**刻意不管**这件事
  （壳里猜一个落点就把它变成了一个默认值），所以这一条是调用方的责任。

### 顺手修掉的一个真 bug：输入框上两个焦点圈

用户按着截图问「点击文本款怎么是这样子的，出现了一个椭圆和长方形的框」。

**两个圈**：外面一个贴着 `.pf__box` 的圆角圈（`:focus-within`），
里面一个贴着 `<input>` 的**直角**圈（`<input>` 没有圆角，所以是长方形的）。

根因是**权重**，不是漏写：`.pf__input:focus-visible { outline: none }` 是 (0,2,0)，
而 `section.pf :focus-visible` 是 (0,2,1)（多一个类型选择器），后者赢
——与那段注释里为"圈的**颜色**"记的是同一场权重战，只是这一处的赌注一直没人发现。
所以那条 `outline: none` **从来没生效过**。

修法是**把选择器写到够重**，不是在 `.pf__input` 上加 `!important`：
`.pf__box .pf__input:focus-visible`（(0,3,0)，三个类压过两个类）。

判据是量出来的：聚焦后 `getComputedStyle(input).outlineStyle === 'none'`，
而 `.pf__box` 的 `box-shadow` 那一圈还在（它是**唯一**该在的那个）。
★ 量的时候要**先把 `transition` 关掉**：这个预览面板隐藏时 transition 冻在起点，
直接读 `box-shadow` 只会读到 `rgba(0,0,0,0) 0 0 0 0`，看着像"圈没了"。

## 踩到的坑（写给下一个人）

- **删掉一个 Next 路由会打断每一份**陈旧的 `.next*/types/`：`tsc --noEmit` 会报
  `Cannot find module '.../avatar/route.js'`，而那不是代码坏了。这些是**生成的**
  产物，`rm -rf .next-*/types` 即可（运行时不读它们，dev server 会重新生成）。
  ★ 本仓库的 `tsconfig.json` 的 `include` 里堆着七八条 `.next-*/types/**/*.ts`
  （每条隔离 dev server 加的），所以这个坑会**反复**出现。
- 这一屏所在的**共享工作区**里另一个会话一直在存盘，HMR 每几秒整页重载一次。
  「点了没反应」在这种环境下**先怀疑 HMR**：`preview_click` 派出去的那一下
  会落在一次重载上。可靠手法是**同一轮 JS 里** `element.click()`，
  判据取"`fetch` 有没有发出去"。

## 六、`yun-soft` 也被否了：这一次坏在**形状**（2026-10-17 当天晚些时候）

用户看了落地的那张说「这个默认头像我不喜欢，**想粑粑一样**，换一个好看的」。

★ **陶土橙 + 一朵三瓣的实心团块，形状与颜色合起来就是那个东西。**

这句话对**形状**是瞎的。这一轮因此加了两个数（`fill` 实心占比、`edge` 边缘密度）

### 这一轮踩到的一个**哑** bug：`--apply=` 是死代码

加 `--sheet` 那条分支时写的是 `if (arg('sheet') !== undefined)`，
而 `arg()` 没找到参数时返回的是缺省值 `''`——**不是 `undefined`**，
于是这个比较**恒真**：`--apply=` 与出图两条路一起走不到。
症状极难联想——**命令成功退出、还打印了一张对照表、文件一个字节没变**。
（`--apply=chuan` 就是这么白跑了一次，我是拿"落好了"那句没出现才发现的。）
修法：`env.mts` 新增 `flag()` 专门判"开关在不在"（`arg` 管带值的、`flag` 管不带值的），
并在两边都留了注释。
