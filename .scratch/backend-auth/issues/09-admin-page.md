# 09 —— 管理页 `/admin`

`Status:` **open**

## 要做什么

一屏最小管理页（用户 2026-10-16 选的方案）：**列出所有人 + 四个开关当场改**。

- `src/app/(studio)/admin/page.tsx` + `src/components/admin/*`：工作台的一屏（带侧栏），
  服务端取数（走 BFF → Java `/api/admin/users`），客户端那部分只负责勾选与提交。
- 侧栏**只在 `role=ADMIN` 时**多出「管理」那一格（`NAV` 是常量，所以这一格按角色算，
  与底部那两副面孔同一个写法）。
- 每行显示：账号 / 昵称 / 注册时间 / 上次登录 / 四个开关（全量提交，见
  `PermissionPatch`——增量在并发下会变成"我以为我关掉的又开了"）。
- 顶部显示：**今天发出去的短信条数 / 每日硬顶**（"237 / 300"），
  以及**注册开关的当前状态（只读）**——
  ★ 只读是刻意的：一个能改"钱从哪儿出"的开关不该是网页上一个按钮。
  要改就动服务器上的 `/etc/xiaozhujue/api.yml`。
- 演示账号那一行要**标出来**（后端给了 `demoAccount` 这个名字）：它的口令是公开的、
  四个能力全开，这一屏正是"谁在花我的钱"该被看见的地方。

## 怎么算做完

- 管理员进得去、普通人打 `/admin` 看到的是"这一屏只有管理员能看"（不是一片空）。
- 勾掉某个人的「图像」→ 他那边（不重新登录）点「开始创作」就被告知没有权限。
- 页面上能看到短信用量与注册开关状态。
