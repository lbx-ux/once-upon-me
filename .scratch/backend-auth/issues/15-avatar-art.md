# 15 —— 默认头像改成出图（工单 08 的后续）

`Status:` **open**（提示词已交，等图）

## 要做什么

用户 2026-10-17：「现在提供给用户的默认头像一点都不好看，你使用 `gpt-image-2-style-library`
来生成默认头像的提示词，**我来生成图片**」。

工单 08 那六个手写 SVG 仍然在跑（形状是对的：云与纸船取自本站演示书「小宇的云」，
其余四个是同一支笔下的日常物件），但它们**是矢量线描**，而这一站别的图全是水彩——
一排线描摆在水彩封面中间，是这一站唯一一处"笔墨不是同一支"的地方。

★ 2026-10-17 补：用户看过第一版提示词之后加了一条——**背景不要暖相纸米色**。
同一次他还要求个人主页那一屏整体转蓝（原话「这个个人主页的效果应该是蓝色的，
不要橙色的」），所以这一批头像跟着那一屏走**冷色**：底是淡蓝灰白、主体是石板蓝。
这不是"换个好看的色"，是让头像和它所在的那一屏是同一个调子。
★ 那六个 SVG 已经先按同一组色改过了（底 `#e8f0f6`、记号 `#427294`），
所以**现在就换掉它们也不会有色差**，用户出图的进度不影响前台。

所以这一份只做一件事：**把提示词交出去**。图片由用户出，回来之后我接手后处理与接线。

## 三条硬约束（决定提示词长什么样，不是口味）

1. **会被裁成圆形。** `profile-home.css` 里三个尺寸全是 `border-radius: 999px`
   （侧栏 22px / 挑头像那一排 44px / 个人主页 64px），配 `object-fit: cover`。
   所以主体必须收在画面**内切圆**里，四角的内容会被切掉。
   → 提示词里逐张写了"完整收在中心直径 76% 的圆内"。
   ★ 反过来的一个坑：**不要画边框、不要画底衬圆**。CSS 已经切了一刀圆，
   图里再画一个圆就是"圆里套圆"，而且那圈线会被切成一堆奇怪的弧。

2. **最小要能认的是 22px。** 侧栏那一格就那么点。所以是**单一主体 + 一块实心剪影**，
   没有细密排线、没有内部纹理——那些在 22px 下糊成一团灰。
   → 提示词里写了反面约束「不要细密排线」。

3. **六张必须是同一支笔，靠形状分开，不靠颜色。** 这一批只有五支颜料
   （`globals.css` 的 `:root`：**淡蓝灰白 `#e8f0f6`**、**石板蓝 `#427294`**、
   墨 `#17171d`、墨灰 `#6b6a74`、冷白 `#f4f8f9`）。给六张各配一个颜色的话，
   那一排会变成六个外来户——而头像要跟的是**它所在那一屏**的调子
   （个人主页那一组 `--pf-*` 令牌，理由写在 `globals.css` 那一段里）。
   → 六张共用这一套色，靠剪影区分：云（横向团块）、纸船（尖角折线）、太阳（圆 + 放射）、
   蒲公英（小球 + 细茎）、叶子（实心尖椭圆）、月亮（月牙）。
   **蓝的占比**刻意排成有节奏的一列：太阳 > 纸船 > 叶子/蒲公英 > 月亮 > 云。
   ★ 注意别把蓝当"更冷"来用：这五支里没有第二支彩色，深浅全靠**墨**与**冷白**拉，
   而不是靠把蓝调浅——调浅的那一档在两个尺寸下都只读成"一层脏灰"。

## 怎么交付

1. 出图规格：**正方形 1:1**（1024×1024 够用）。
2. 按 id 命名存到一个空目录里，比如 `E:\project\once-upon-me\.out\avatars\`，
   文件名就是 **`yun` / `chuan` / `taiyang` / `pugongying` / `yezi` / `yueliang`**
   - 原始扩展名（`.png` 或 `.webp` 都行）。
     ★ 放 `.out/` 是因为它 gitignored：1024px 的 PNG 一张可能好几 MB，
     六张直接进 `public/` 的话，这批**原图**会永远留在公开仓库的历史里。
     我会缩过之后再落 `public/`。
3. 我接手的三件事（图到了就做）：
   - 缩到 **256×256** 落 `public/avatars/<id>.webp`（最大显示 64px，2x 有余量），
     删掉现在的六个 `.svg`；
   - `src/lib/avatars.ts` 的 `avatarSrc()` 从 `/avatars/<id>.svg` 改成 `.webp`，
     并**重写文件头那段"色值写死在 SVG 里"的说明**——那段话的前提（矢量、不进
     `make-webp.py`）在位图来了之后就不成立了，这六个该进那条流水线；
   - `src/lib/avatars.test.ts` 整段重写（现在断言的是 SVG 内容、`aria-label`、
     写死的令牌色值——那三条对着位图都不成立，留着就是一条永远测不到东西的测试）。

## 怎么算做完

- 六个 id 仍与 `AccountRules.requireAvatarId` 那个正则对得上，**id 一个都没换**
  （库里的老数据还得认得出）。
- 六张缩到 44px 并排看：**一眼分得清是六个不同的东西**。
- 缩到 22px 看：每一个仍读得出是什么（这一条是那个最小尺寸的验收，
  拿 `scripts/` 里现成的缩放脚本量，不靠"我盯着看觉得还行"）。
- 挑头像、侧栏、个人主页三处同时换成新图；登出再登进来还是那一个。
- 闸门：`pnpm format:check && pnpm lint && pnpm typecheck && pnpm test`。

## Comments

- 2026-10-17：提示词按 `gpt-image-2-style-library` 的 **`illustration-art-style`
  （插画与艺术风格）** 模板写——它是那一份索引里唯一对得上"水彩 / 装饰画 / 风格实验"
  的那一格（Styles: Illustration，Scenes: Story/Creative），指导条目正是
  "定义构图、主体、配色、笔触材质、情绪和完成度"。六条**复用同一个模板、只换主体**
  （skill 里 "reuse one template and vary subject" 那条），所以它们会像一套。
