## 一、折叠（`src/components/admin/Fold.tsx` + `admin.css`）

★ **范围后来收窄了**：一开始按"两块都折"做（模型配置 + 权限申请），站长看了之后
说「算了吧，这个不这了，就模型那折就行」——原因是那两块折起来之后，权限申请里面
只有一行"读不到申请列表"（后端那个接口还没做），而**下面那张用户表在他眼里才像
「权限申请」的内容**：那张表在这份代码里**没有标题**（没有 `<h2>`、没有 `<caption>`、
没有 `aria-label`），紧贴在「权限申请」下面。所以他把这一块收回了，只留模型配置。
**`RequestQueue.tsx` 已经逐字还原**（那三个改动：`Fold` 包装、`</Fold>`、import 全撤）。
那张没有名字的用户表仍然是一个真问题，但**不在这条工单里**——留给他自己决定。

- `Fold` 一个组件管一块：`<h2>` 里是一颗真按钮（`aria-expanded` + `aria-controls`），
  收起用 **`hidden`**（孩子不卸载；Tailwind preflight 那条是 `display: none !important`）。
  ★ 一开始写的是"从 DOM 里拿掉"，理由是"那一块挂载时会去拉数据"——**那是错的**
  （列表是服务端当 prop 递进来的）。而照那个写法，`ModelConfig` 那四张卡一收就卸载：
  **改到一半的模型名/地址跟着没**，展开一次还会重拉四遍候选。
  理由与更正都写在 `Fold.tsx` 的判断 3 里。
- **默认展开**。收起是"我要看下面的"，不是"我看不见这些东西"。
- 收起的选择记在 `localStorage`（`adm.fold.models` / `adm.fold.queue`），
  **挂载之后才读**——与 `AppShell` 那条侧栏折叠同一个写法、同一个理由。
- 箭头是内联 SVG（`CreateLanding` 那颗同一个路径），不是 `⌄` 那种文字字符。
- 原来那两处的 id（`adm-queue-title` / `adm-models-title`）**原样保留**：
  `Fold` 的 `id` 参数拼出来的就是它们，`aria-labelledby` 不用改。

## 二、模型候选（`GET /api/admin/model-list?capability=<id>`）

实测（2026-10-17，`https://tokenrhythm.studio/v1/models`）：`200`，
`data[].id` 一共 **25 个**，文字/图像/视觉三个能力配的是同一个地址、回同一份列表。

三条判断，头两条是实测逼出来的：

1. **是 `datalist`，不是 `<select>`。** 这份列表里**没有**图像在用的
   `wan2.7-image`（这个网关的 `/models` 只列对话模型）——做成强制选择，
   图像那一格会当场丢掉它正在用的值。而且那份列表**不区分能力**
   （`kimi-k2.6` 文字与视觉都能用）。所以候选只是候选，手填照旧。
2. **拉不到不是错误**（HTTP 仍是 200，形状里是 `message` 而不是 `code`）：
   地址没配 / key 不对 / 那个地址没有 `/models`（语音那一路很可能就是），
   三种都只意味着"这一格没有候选"，手填照旧能用。界面上那句话**永远灰的**
   ——红在这个仓库里只有"这一轮真的坏了"一个意思（`globals.css` 的 `--danger`）。
3. **客户端只送能力名**，不送地址、不送 key：地址由服务端按 `CAPABILITIES` 取
   （`model-config.ts` 那一份清单，"哪个能力用哪两个变量"仍然只有一处）。
   让浏览器指定"服务端带着 key 去打哪个地址"是一个洞。
   ★ 唯一抄了一处引擎的规则：**视觉的 key 回落**（`VISION_API_KEY` 空 → `LLM_API_KEY`，
   `registry.ts` 规则 3）。那是**值的规则**、不在变量名表里，所以照抄了两行，
   并在那里写明了出处。

## Comments

- 2026-10-17 路径**没有**挂在 `/api/admin/model-config/` 底下：那底下已经有一个动态段
  `[capability]`，再放一个静态的 `models` 会让 `/model-config/models` 同时匹配两条路由
  （静态优先，但阴影里那一条永远没人走到，下一个人会以为它坏了）。平铺成
  `/api/admin/model-list` 没有这个问题。
- 2026-10-17 测试：`src/lib/settings/model-list.test.ts` 11 条（全是假 fetch）。
  其中一条顺手抓到我自己的一个坏断言：拿假 key `'k'` 去断言"返回值里没有它"
  会撞上 `ok` 里的那个字母——改用一把独一无二的假 key 才有意义。
- 2026-10-17 **界面验到了哪一步（我的预览会话不是站长，`/admin` 对我只渲染"这一屏只有管理员能看"）**：
  - 路由确实注册了、且闸门在解析之前（未登录 → `401 not-signed-in`，不是 404 也不是 400）。
  - `fetchModelIds` 对**真网关**实测：`200`、25 个 id（`data[].id`）。
  - 单元测试 11 条（假 fetch，含 401 / 404 / 连不上 / 非 JSON / 空列表五条失败路）。
  - **真 Next 编译器下渲染了一遍**（临时建了一页 `/zzsmoke`，渲染完就删）：
    `aria-expanded` / `aria-controls` / `adm__fold-body` / `list="text-models"` /
    `id="text-models"` / `adm__model-cand` / 箭头那个 `<svg>` 全都在 HTML 里
    ——**证明这一屏不会因为我的改动白屏**。
  - 折叠那一下在浏览器里点过：收起后 `aria-expanded=false`、孩子带 `hidden`、
    算出来的 `display: none`、localStorage 写 `0`；展开写 `1`。
    ★ 最关键的一条：**先往「模型名」里打一半的字、再收起来、再展开，那个值还在**
    ——这正是把"从 DOM 里拿掉"改成 `hidden` 换来的（判断 3 那条更正）。
    ★ 箭头那个 `rotate(-90deg)` 一开始量到的是 `matrix(1,0,0,1,0,0)`（恒等）：
    那是**面板隐藏时过场冻结**的老坑（计算值读到起点），把 `transition: none`
    注入之后再量就是 `matrix(0,-1,1,0,0,0)`——规则本身是对的。
  - 剩下没验的**只有**：带管理员会话点一次「模型名」看浏览器那 25 个候选弹出来。
    那需要站长自己刷新 `/admin`。
