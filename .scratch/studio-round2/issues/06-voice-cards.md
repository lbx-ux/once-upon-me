## 二、★ 换表之前：两个 id 各真打了一次

写 `.out/tts-voice-probe.mjs`（照 `.out/tts-probe2.mjs` 的形状，读 `.env.local`，
只打印状态码/字节/md5，**不打印 key**），语料用卡片上印的那一句（`PREVIEW_LINE`）：

| 音色                | 结果                                                                         |
| ------------------- | ---------------------------------------------------------------------------- |
| `longjielidou_v3.6` | **200** · 1,414ms · **41,371 字节** · md5 `a1b18194459c7c7fb315393209f1bda8` |
| `longanlingxi`      | **200** · 708ms · **50,971 字节** · md5 `cfd55a90282dd1203b46dc3ca65ba0d5`   |

- 两条 200 且字节不同 ⇒ `longanlingxi` 是**真的另一个声音**，不是回落到了谁身上。
- ★ `longanlingxi` **没有** `_v3.6` 后缀。`spec.md` §1.2b 早就记过这家 id 命名不统一
  （`longanxiaoxin` 无后缀、`longanhuan_v3.6` 有），所以后缀只能实测确认，不能照邻居推。
- ★ **第一次跑两个都 404，而那是路径写错了**（`TTS_BASE_URL` 本来就含 `/api/v1`，
  我又拼了一次）。这一条值得记：**只打一个有疑点的音色，就会把"路径错了"读成
  "这个音色不存在"。** 加一个已知能用的对照（`longjielidou_v3.6`）当场就分开了这两种情形。

再打一次**真路由**（`.out/preview-route-check.mjs` → `POST /api/voice/preview`，
走客户端那条路：env 从请求体来）：

| 音色                | 状态 | content-type | `Cache-Control` | 字节   | md5         |
| ------------------- | ---- | ------------ | --------------- | ------ | ----------- |
| `longanlingxi`      | 200  | `audio/mpeg` | `no-store`      | 50,971 | `cfd55a90…` |
| `longjielidou_v3.6` | 200  | `audio/mpeg` | `no-store`      | 41,371 | `a1b18194…` |

与直打 API 的字节、md5 **逐字节一致** ⇒ 卡片上那颗钮走的那条路是通的（真 mp3 头、不缓存）。

## 三、卡长什么样，以及四条刻意与角色卡不同

配方（值都从 `character-wall.css` 抄，不新发明数）：圆角 5px、`--surface` 卡身 +
1px `--hairline`、两层影子、一条胶带、静置角 ±0.7°（两张一左一右）、
悬停/键盘聚焦时**被按正 + 抬 10px + 影子散开 + 描边转 `--accent-rgb` 40%**。

四件**故意不一样**（理由写在 `voice-picker.css` 文件头）：

1. **没有人像，也不画波形、不摆 emoji 头像**——音色没有形象，画一个出来是给不存在的数据背书。
   于是"肖像位"裱的是**你要听到的那句话**（`PREVIEW_LINE`，与试听路由同一个常量）。
2. **暖相纸只留给那一格**（`--card-paper`）：判据"冷的是光，暖的是物件"照用，
   只是"物件"从一张照片换成了一句要被念出来的话。
3. **没有背后那张撑开的面板**（`.cw__card::after`）：两张卡本来就更矮不下来，
   再加一圈白边只是多一圈边。
4. **主要动作不在悬停层里**：角色卡藏起来的是次要动作；"听一句真的"是这一屏存在的理由，
   藏进 hover 等于在没有 hover 的设备上把它删了。

卡面四件事全是真事实：厂商给的名字与调性、机器名 id、**绑定模型**（读 `settings.speech.model`，
空着就说"模型名还没填"）——最后这条是"音色绑定模型，换模型直接 400"那条实测结论在界面上的落点。

## 四、顺手修掉的一处名不副实

`preview()` 的注释一直写着"换一段就 revoke"，而代码**从来没 revoke 过**
（`URL.createObjectURL` 后既不 revoke 旧地址、`onEnded` 也不 revoke）。
这一单补成真的：换一段 / 播完 / 离开这一屏各 revoke 一次，并且**先摘 `src` 再 revoke**。
同一处还补了一个**令牌**：连点两张卡时先发的那次响应可能后到，会把播放器改成上一个音色——
每次点击领号，回来对不上就整段丢弃（与 `CreateLanding` 那颗优化钮防双发同一类毛病）。
