# 04 · 四步砍成一屏

Status: **open**（本轮没做——理由在下面，不是漏了）
依赖：03（画桌）、以及 `/character/*` 那一批（另一会话正在做）

## 要做什么

用户的第 2 条前半句：「那这个第一，二，三不都没有保留的必要了呀，
应该是用户选好人物，声音以及要会话来提示词之后，系统就开始进行创作」。

也就是：`/home` 收齐**小主角 + 声音 + 那句话**之后按「开始创作」，
`/create` **直接就是生成**，不再有 ①②③④ 那条步骤条。
这一步计划里原本排在 03 后面，本轮**没有做**。

## 为什么没做

一句话：**现在砍掉前三步，会把"挑一张已有的角色卡"和"换一版形象"这两件事一起砍掉，
而且没有替代品**——它们的替代品（`/character/new`、`/character/[childId]`）
正是**另一个会话此刻正在写的那一批**（未提交，typecheck 在那批文件上还没绿过）。

具体一点：

| 现在住在哪                                                      | 谁在用                                     | 砍掉之后                                                                                   |
| --------------------------------------------------------------- | ------------------------------------------ | ------------------------------------------------------------------------------------------ |
| 第 1 步「孩子是谁」                                             | `/create` 自己 + `?child=` / `?card=` 回填 | `/character/new` 有同样的表单，但那是另一屏，且**本轮没验过它的回填**                      |
| 第 3 步「角色卡」（七条锚点 + 出一张形象 + **用一张已有的卡**） | 生成前唯一的选卡入口                       | `/character/*` 还没交付完；砍了就等于**这本书只能用 URL 里带的那张卡**，家长再没有换的入口 |
| 第 3 步的「换一版」（新 revision，ADR-0007 的核心）             | 家长觉得形象不像时唯一的动作               | 同上                                                                                       |

也就是说：砍掉它不是"少一屏"，而是**暂时拿掉两个已交付的能力**。
产品在那一刻会变成一个"只能按 URL 指定的卡出书"的东西。

## 所以这一单怎么收

- 与 03 一起**已经交付**的是：**画桌**（`/create` 第 4 步现在是那一整排画框）。
  也就是说用户抱怨的"创作页面不好看"这件事已经解决了，剩下的只是**流程变短**。
- 这一单**等 `/character/*` 落地并验过之后**再做，那时三步的内容各自都有家：
  - 选卡 / 换一版 → `/character/[childId]`
  - 新建一个 → `/character/new`
  - 主题与那句话 → `/home` 的输入框（已经在了）
- 做的时候要一起改的（先记下来，免得到时候漏）：
  1. `/create` 在没有 `?card=` 且没卡可选时**仍然要给一条路**——
     不能只是把三个面板删掉，否则直接访问 `/create` 会是一片空白。
  2. `state.step` / `STEPS` / `stepProblems` / `StepShell` / 底部那两颗
     「上一步/下一步」是一个整体（状态机），要么一起撤、要么一起留。
  3. `?child=` 与 `?card=` 的回填逻辑（`pickChild` 那一段）要跟着搬或删——
     它是"按 URL 选人"的唯一实现，别让它悄悄失效。
  4. 撤掉之后 `/create` 的初值只剩"主题 + 那句话 + 卡"，要确认
     `toBookBody` 需要的三个坐标（child / card / theme）都能从 URL 与卡里凑齐。
