# 02 · 首页两格：小主角 + 声音

Status: done（2026-10-15）
依赖：01（配色判据）

用户的第 1 条：「主页的水彩就不要了，然后换为'声音'」。

## 一、水彩那一格为什么撤

它是**只读**的（`title="这一版只有一档画风，所以这里不是下拉"`），撤它不只是腾地方：
产品只有一档画风，一个用户动不了的格子占着"可选项"的位置，只是在数这一屏还剩几个格子。
画风的事实仍写在**需要它**的地方——`/character` 那一屏的建卡说明。

★ 跟着改的一句实话：`.cl__sub` 原来写着"画风这一版只有{画风}一种"，药丸撤了，
那半句就没了着落。现在只陈述示例封面是谁画的。

## 二、声音那一格是真控件

- 选项来自 `DEFAULT_VOICES`（男童声 / 女童声，两个都**人耳听过**）
- 选中走 `patch('speech', { voice })` —— 与 `/voice` 那一屏 `VoicePicker.tsx` 是
  **同一个字段、同一个动作**，没有新造状态
- 因此**不需要往 URL 上挂 `voice` 参数**：`/create` 那一边本来就从设置里读 `env`。
  一个值只有一个家。
- 没选过时**不预填**一个默认音色：那会让"我还没选"看起来像"已经选好了"。
  `''` 是 `DEFAULT_SETTINGS` 里真的那个值，界面就把那个值念出来（"还没选声音"）。

## 三、试听：指过去，不在这里重做一份

`VoicePicker.tsx` 的文件头写着"选音色这件事**没法用文字判断**"——
本轮就是听了三段真音频才定下那两个默认音色的。那句判断没变，
所以不能在这里摆一个"看名字挑"的下拉就完事。做法是下拉底部给一条通到 `/voice` 的路
（那里每张卡都能"听一句真的"），**不是**把那 30 行 fetch + Blob 复制第二份：
一个行为两个实现，迟早有一份先烂。

## 四、没配语音要说出来，而且要说清缺的是哪一样

`speechReady` 为假有两半，两句话各自正好覆盖一半：

- Key/模型名缺 → "这样做出来的书**没有朗读**" + 一个**直接打开设置**的动作
- Key 齐、音色空 → "上面那颗里挑一个，想先听听看就去「声音」那一屏"（带链接）

★ 不用 `role="alert"`：这不是"这一轮坏了"，是一个状态说明，而且这一屏的语音只是
**可选项**（没有朗读照样能出书）。`/voice` 那一屏用 alert，是因为在那里"没配好"
意味着用户专程来做的事做不成——两处的语义不一样。

## 五、没卡时那颗跳 `/character/new`

原来是只读说明"还没有小主角——进去第一步就是定他"。那句在第 1 步撤掉之后就不成立，
而且它把人送进创作流再让他自己找。现在直接送到能建卡的那一屏。
`ChildFields` 留在 `fields.tsx` 不删（`/character/new` 还在用它）。

★ 顺带钉住一条：`submit()` 在没有卡时也跳 `/character/new`。
创作流从这一轮起不再有第 1 步（孩子在主页上就定了），带着一句没有卡的话进去，
创作流那边**没有任何一步能补上它**。

## Comments

- 两格共用**一个** `open: 'card' | 'voice' | null` 状态而不是两个布尔：
  两格同时开着是画不出来的。Esc 与点外面收那条 effect 也共用一条。
- 浏览器实测（真事件，逐条）：
  - 打开：两个选项 + 底部「先去听一句真的 →」；`aria-expanded` 跟着走
  - 选中男童声 → 胶囊文案变成"男童声（5 岁）"，且 `localStorage` 的
    `xiaozhujue.settings.v1` 里 `speech.voice` 变成 `longjielidou_v3.6`
    （**这证明它写的是 `/voice` 读的那一份**，不是自己攒的副本）
  - Esc 收、点外面收、两格互斥（开卡那格再开声音格，卡那格自动关）
- 语音警示两个分支都实测到：清空音色 id 之后那句话变成"还没选声音……"
  并带 `a[href="/voice"]`；指纹为空时是"Key 或模型名还没填"那一条。
- ★ **没做试听这件事有代价**：在两个都听不到的声音之间切换，仍然是在看名字选。
  这是明说的缺口，不是没想到——补它的正确位置是 `/voice`（那里已经有实现）。
