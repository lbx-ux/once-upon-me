# 工作台第二轮：冷白、首页两格、画桌

第二轮。上一轮（`.scratch/studio-sky/`）把工作台与首页并成同一片天，
这一轮处理它交付之后**用户在自己的前台浏览器里看见的问题**。

## 为什么有这一轮

studio-sky 交付后，用户在 `/home` 上提了六条。逐条读过代码之后，
其中三条是**同一个病根的三种表现**：

| 用户原话                                 | 实际的病根                                                                  |
| ---------------------------------------- | --------------------------------------------------------------------------- |
| 「侧边栏的颜色也太重了，和右侧好割裂」   | 侧栏那层纸 α=0.90，是照着**暖**纸定的档                                     |
| 「鼠标一向下滚下面的底色就又变成橙色了」 | 天空是冷的（R−B ≈ −19），`--paper` 是暖的（+12），纸光往暖混 ⇒ 中段必然换色 |
| 「前端的这个主页能不能和首页联动起来」   | 上一轮只联了**背景**，这一轮要联**内容**:两格真控件                         |

另外两条是产品流程的改动（主页收齐三件事、生成页改成画桌），一条是上一轮漏掉的
侧栏层序 bug（用户实测抓出来的，见 studio-sky 工单 02 的 Comments）。

## 四条已定的分叉（用户 2026-10-15 选定）

| 分叉           | 选定                                        | 代价                                     |
| -------------- | ------------------------------------------- | ---------------------------------------- |
| 底色怎么救     | **把 `--paper` 换成天自己的冷白**，不重出图 | 暖色换承担者（`--card-paper`），不是消失 |
| 生成页长什么样 | **一页一页画出来的画桌**                    | 撤掉文字日志（它的内容已经都在格子上）   |
| 提示词优化     | **这一轮真做**（工单 07）                   | 不做的话那颗按钮就是一个假控件           |
| 主页没卡时那颗 | **跳 `/character/new`**                     | `/home` 不再是一条进创作流的路           |

## 这一轮的规矩（沿用，不是新发明）

- **数字是量的**：`node scripts/check-scrim.mts` 直接读 CSS，改完 CSS 重跑；
  红了改 CSS，不改门槛。
- **冷的是光，暖的是物件**：页面（光）跟画面走，`--card-paper`（物件）才是暖的。
  这条是这一轮唯一新增的设计判据，落在 README §五。
- **一个值只有一个家**：音色写入 `settings.speech.voice`（与 `/voice` 同一个字段），
  不往 URL 上再挂一个 `voice` 参数。
- **没有的东西直说没有**：优化器不做本地兜底句子、超长不截断、试听不在这里重做一份
  （指路到 `/voice`）。
