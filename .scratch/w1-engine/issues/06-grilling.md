## 这一张单子的判据

`grilling` 的用法是"选题定稿前对自己的方案开炮"。它的产出**不是**一份"我们想清楚了"
的记录，而是一份**问题清单**：哪些我们已经能答（附证据）、哪些现在答不上来
（诚实标出来，别在答辩现场才发现）、哪些是**只有范同学能决定的**（那是决策不是事实）。

第三类全部列在下面，等回答。前两类先结清。

## 二、现在答不上来的，诚实记着

1. **新供应商的一致性没人验过**。首页 26 张图是 GPT-Image-2 出的，
   `wan2.7-image` / `qwen-image-2.0` 能不能跨页锁住同一张脸，**零证据**。
   判据 1 是一票否决。→ 见下面 Q2、Q3。
2. **参考图字段名不知道**。官方文档里没有图像接口，锁脸能力是"以为有"还是"真没有"
   要花钱测（一次成功 0.20 元）。如果**不支持参考图**，本项目的核心机制
   （角色卡 → 参考图条件生成）就要改设计，不是改参数。→ Q3。
3. **声音克隆没有供应商**。当前供应商只有对话 + 图像 + 视频，**没有 TTS**。
   而"用父母的声音朗读"是产品第一句话的一半。→ Q7。
4. **MP4 输出被灰度挡住**（403）。#4「多模态」那条的"视频"这一档现在没有着落。→ Q8。
5. **审核 Agent 的红线词库还没有**，只有 prompt 里那三行。适龄字表（#3 的 RAG）也没有。
   这两样是 W3/W4 的活，但答辩会问"你的安全审核具体拦什么"，现在答不出清单。
