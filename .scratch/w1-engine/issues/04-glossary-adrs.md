# 04 · 领域词汇表补齐 + 关键决策写 ADR（🧭 domain-modeling）

Status: done

## 补了什么词

`GLOSSARY.md` 原来 9 条（形态 / 独读版 / 共读版 / 故事树 / 角色卡 / 一致性分 /
预生成 / 能力适配层 / 供应商）。看板说 W1 还缺"节点 / 分支"与 RAG、审核那一档。
实际补了 7 条，其中两条是这轮设计**新造出来的词**——造词的判据是
"代码里已经有一个概念，但文档里没有名字，于是它会被讲错"：

| 新词            | 为什么非要有                                                        |
| --------------- | ------------------------------------------------------------------- |
| 节点 / 分支     | 看板点名的两条                                                      |
| 锚点（硬 / 软） | 角色卡的核心机制，不命名就会被说成"提示词片段"                      |
| 落盘资产        | 与"一次调用"相对；供应商的 URL 一小时过期，这两个词不分开就会出事   |
| 录制 / 回放     | ADR-0003 的演示路径需要动词                                         |
| 核对清单        | "一致性分"的判据从哪来，得有个名字                                  |
| 未核对          | `verdict: 'unavailable'` 的中文。没有这个词，人就会把它说成"通过了" |
| 重画率 r_redraw | 成本公式的变量，也是 #2 的硬证据                                    |
